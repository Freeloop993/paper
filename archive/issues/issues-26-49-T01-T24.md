- **A250 对 B300：整机读感分得开，臂根本身分不开。** B300 机身更窄、四臂露在机身外的长度明显更长，看起来更舒展；A250 机身相对轴距更大，更紧凑。但这里同时改了轴距（250→300）和臂根句。两张图的肩部都是从机身侧面中段开始收窄的无缝圆角；B300 的圆角沿臂多走了一段，大约一到两个臂宽，A250 大约一个臂宽以内。“达到臂宽”的那一点两张都只能估到一个范围，记待判。
- **A250 对 B250（轴距相同，只差臂根句）：** B250 的肩部是一大片外张的曲面，整个机身读成 X 形；A250 的肩部小，机身是一个独立的舱。这个差别看得出来。但 B250 的四个红点和蓝色 X 正好压在四个臂根和机身上，蓝线还贴着臂的中线走，臂根边缘和过渡终点都被干扰，所以 B250 的臂根记待判，不能拿来下结论。
- **能写的一句：** 在这批图里，轴距加大时整机读感更舒展；臂根句本身的作用还没有干净的对照。

## 2. 新 C 与旧 C

**作者的判断（原话）：** “现在的 C 看起来没有刚刚的好。”

**我自己看出的差别（我的推测，作者没有说原因）：**

| 部件 | 旧 C | 新 C | 建议 |
|---|---|---|---|
| 机鼻模组与壳前缘 | 云台夹在机鼻两侧的壳体之间，看得出是装进机身的 | 云台像一个单独的头叠在方盒上面，与机身的关系读成外挂 | 保留旧 C 的“两侧壳体夹持云台”。这就是规格卡里 C 的耳座方案 |
| 承座与机架 | 碳纹机臂插进深色套座，接口一眼可见 | 机臂细、与机身同色，接口几乎看不出 | 保留旧 C 的接口可读性。它靠的是臂宽和材质对比，见下面的取舍 |
| 顶盖分段 | 三块，分缝清楚 | 一个方盒，分缝很淡 | 保留旧 C |
| 桨叶数 | 四副双叶 | 四副三叶 | 新 C 是缺陷：服务端改写仍写双叶，是生成没有兑现 |
| 比例 | 机身相对轴距大，臂宽，整机结实 | 机身小、臂细长，整机显得单薄 | 旧 C 的比例更好。但长宽比和臂宽写在文字里都不受控，旧 C 的比例是碰出来的，不能保证复现 |

**一个需要作者决定的取舍。** 为了让盲读者分清“无缝”和“承座”，5.2.1 的参数响应实验把壳和臂改成了同色。可是旧 C 的接口好读，很大程度上靠的就是碳纹臂和哑光壳的材质对比。两件事要分开：

- 5.2.1 参数响应实验：继续同色，只看形状。
- 4.2.1 设计方向（E3）：是否允许设计者给 C 选“外露碳纹臂”，作为一个材质档位？这涉及“低调—醒目”留到 4.4 的规定，由作者定。

## 3. A、B 的相机写法

两张都在机头端，B300 机头顶上露一个小深色件，A250 露一小段深色顶面，都没有越出机鼻轮廓，都没有朝向观察者的镜面。顶视能支持的写法只有一句：“相机模组位于机头端，未越出机鼻轮廓”。镜头朝向、内部安装都写进规格，不从顶视判。
