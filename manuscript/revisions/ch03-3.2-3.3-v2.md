## 3.2 需求资料与产品样本分析

### 3.2.1 资料来源与样本筛选

本研究的需求资料来自消费级航拍无人机的公开用户评论。原始评论经去重与清理后得到 7,443 个非默认文本簇，作为需求语义的检索范围。评论语料只用于四旋翼日常随行航拍的案例；第 5 章的植保六旋翼案例面对的是农业作业人员，其需求依据改为作者的植保任务简报与三款植保机的官方手册，不借用消费评论。

早期曾对评论分词后绘制共词网络。网络的中心节点集中在“飞行”“操作”“稳定”“拍摄”“客服”等功能与服务词，描述外观的词极少〔图 3-x〕。这说明按词频归纳无法直接得到造型需求：用户在评论中谈外观的机会少，而且同一个“小巧”既可能指展开后的机身，也可能指收纳后的体积。另一幅网络取自商品详情页的参数文字，反映的是厂商的卖点而非用户的感受，本研究只用它说明产品宣传的重点，不作为需求证据。

因此，本研究不做词频统计，而是从文本簇中有目的地抽取与外观、尺寸、配件集成、配色相关的原句，逐条整理成证据卡。最终得到 36 张卡，来自 35 个不同来源（其中两张卡出自同一条评论，须一并阅读）；21 张来自补充语料，15 张来自早期语料。卡数、来源数与评论者人数是三个不同的单位，正文不把卡数当作需求的权重。

为检验整理过程的可靠性，另从 35 个入卡来源与 5 个随机干扰文本中组成 40 条匿名短引文，交由一名不了解研究方向的编码者独立编码〔待：一致与分歧的条数〕。

### 3.2.2 需求语义的整理与分类

每张证据卡记录原文片段、被评价的对象、整机是展开还是折叠、类别、极性和研究者的解释，并单独标注它是支持、反例还是有条件的表达。类别分为视觉目标、功能、使用情境、愿望与事实自述五种，一张卡可以同时属于两类。36 张卡中，有 16 张未见反例，12 张带有对象或情境的限制，8 张是反例或取舍。

在此基础上，本研究以语义差异法的双极词对作为需求语义的表达单位〔引文待核：Osgood 等的语义差异法；Nagamachi 的感性工学〕。词对的入选规则在看卡之前确定，共四条：

1. 至少两张来自不同来源的卡支持其中一极；
2. 至少登记一张反例或有条件的卡，找不到时写明“未见反例”；
3. 在正交顶视图上可以判断；
4. 能落到 3.3.2 节所列的四个可见部位之一。

按此规则逐组核对后，得到四组词对（表 3-x）。“紧凑—舒展”由机身小巧与嫌机型偏大的评论支持，同时有肯定较大机身的反例；“简洁—繁复”由五个来源的“简洁”评价支持，未见反例；“整体—拼凑”由希望把外挂件集成进机身、以及一体式桨保带来辨识度的评论支持；“低调—醒目”由配色鲜艳便于辨认与偏好朴素灰色两类评论构成，只在配色深化阶段使用。桨叶防护感有七张卡，是证据最多的主题之一，但它对应的护罩不在四旋案例的关注部位内，按第四条规则未入选。

词对的使用有三处限制须在正文写明。其一，“整体—拼凑”的支持卡谈的是配件与桨保是否与机身一体，把它落到臂根与相机舱是研究者的转译，不是用户原话。其二，多数卡没有说明整机处于展开还是折叠状态，而词对检验的是展开状态的顶视观感。其三，“简洁”的五张卡都没有指明是哪里显得简洁，把它落到“分件线与色块少”是研究者的操作化，需要用真实产品图上的评分来检验（见 3.2.3 与 5.3）。

### 3.2.3 产品造型特征与构型边界分析

四旋翼案例的构型边界取日常随行航拍机的常见做法：四个电机、X 形布局、每个电机一副双叶桨、机臂展开后飞行、前置相机水平朝前拍摄。厂家手册以不同编号标注前置云台相机、视觉传感器、桨叶与电机，并要求飞行前展开机臂〔引文待核：DJI Mini 4 Pro 用户手册，Aircraft 一节〕；这为区分相机与其他传感器、以及把折叠铰接作为一种臂根形式提供了实物依据。

正式观察统一采用正交顶视。顶视下能稳定看到的部位有四处：机身平面轮廓与比例、机臂到机身的过渡、机鼻（相机舱）的前缘轮廓、顶面的分件线与配色分区。镜片、机身厚度与镜头俯仰在顶视下常被遮挡，本研究把它们记为“不可见”，不由顶视图推断。

真实产品的顶视图用于两处：一是建立词对与可见形态属性的对应，二是在 5.3 节的评议中先让评议者对真实产品打分，再评生成的终稿。图片只取自厂商官网、官方手册或许可明确的图库，并逐张登记型号、来源与许可。目前已核实四个型号〔待：补足至 8—10 个〕。

## 3.3 设计意图转译与造型规格构建

### 3.3.1 设计意图与造型属性的关联

设计意图在本研究中以“词对上想靠近哪一极”表达。为了让意图能够进入生成并能被检查，本研究把每组词对对应到顶视可见的造型属性，再把造型属性对应到 3.4.2 节的参数档位（表 3-x）：

| 词对 | 可见属性 | 参数 |
|---|---|---|
| 简洁—繁复 | 顶面分件的多少 | 顶盖分件：单盖／多块 |
| 整体—拼凑 | 机臂与机身、相机与机鼻是连成一体还是各自独立 | 臂根过渡：无缝／外露承座／折叠铰接；机鼻外突：无外突／前伸云台 |
| 紧凑—舒展 | 部件之间收拢还是伸展、留白多少 | 无可控参数（见下） |
| 低调—醒目 | 是否有高饱和色或强调色块 | 配色，仅在 4.4 节深化时使用 |

“紧凑—舒展”原拟由机臂宽度、机身长宽比或对置轴距表达。三种做法在开发轮中都没有使成图出现可分辨的差别：写在文字里的臂宽和长宽比没有被兑现，加大轴距时生成模型把机身一同放大，整机比例几乎不变（见 4.1.3）。因此这组词对不报告参数响应，只在第 4 章的方案组合与作者取舍中讨论，并在 5.3 节由评议者判断它能否从方案整体读出。

对应关系是研究者提出的转译假设，而不是评论直接给出的结论。它是否成立，由两类证据检验：参数改动后图上是否出现对应变化（5.2 节），以及不知条件的评议者能否从终稿读出设计者意图的那一极（5.3 节）。

### 3.3.2 目标部位、可变项与保持项

造型规格以一张规格卡记录，字段如下（表 3-x）：

| 字段 | 内容 |
|---|---|
| 使用任务 | 日常随行航拍四旋翼 |
| 词对目标 | 三组词对各自想靠近哪一极，或不作要求 |
| 造型档位 | 机身平面形、臂根过渡、机鼻外突、顶盖分件各选一档；臂材质可选同色哑光或外露碳纹 |
| 构型（保持项） | 四电机 X 布局、横纵跨度比 1.00、对置轴距 250 mm、每轴静止双叶、桨径 5 英寸、无护圈 |
| 视图与相机（保持项） | 正交顶视、机头朝上；相机位于机头端，镜头水平朝前 |
| 配色（初稿阶段的保持项） | 壳体浅灰、电机深灰、桨叶黑色；配色在 4.4 节才改变 |
| 自由项 | 壳面曲率、机臂截面、电机座、桨叶外形、分缝的具体走向 |
| 依据 | 支持该方向的证据卡号；属于设计者判断的写“设计者判断” |

目标部位即 3.2.3 节的四处可见部位。可变项是设计者通过选档位主动改变的部分；保持项是所有方向共同、不允许改变的部分；自由项是设计者不作要求、留给生成模型探索、事后只记录的部分。这样划分有两个目的：一是让每次生成的差别能追溯到具体的档位，二是给设计探索保留空间，避免把壳体的具体外形写死在输入里。

一个设计方向就是一组档位的组合。例如，“紧凑、简洁、整体”的方向可以取流线舱、无缝臂根、无外突、单盖；“紧凑、繁复、拼凑”的方向可以取方正机壳、外露承座、前伸云台、多块顶盖，并选外露碳纹臂以加强部件之间的区分。各方向的具体取值由设计者在第 4 章的设计过程中决定。

### 3.3.3 造型规格的人工确认与修订

规格由设计者在配置器中填写和确认，配置器把它编译成条件图与文字（3.4 节）。设计者可以查看并修改编译出的文字；配置器同时保存编译原文、修改后的文本、实际发送的文本与条件图，三者不一致时提示设计者。

修订以改变档位进行：设计者从候选中选出一张作为父图，改变一个或几个参数的档位，在父图基础上重新生成。每次修订记录父图、改了哪个参数、原档与新档、修改理由，以及其余部位是否保住。修订至多两次；设计者可以在任一步停止，也可以回到之前的任一版本。这一定义使第 4 章的设计过程与第 5 章的验证使用同一套可追溯的记录。
