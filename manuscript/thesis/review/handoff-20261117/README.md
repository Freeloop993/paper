## 研究与设计决定

论文研究设计者如何将需求转成可调规格，用配置器形成输入，检查生成结果、选择候选、修订和回退。四旋任务为日常随行航拍，重点是相机舱与机身、臂根与机身的整合。六旋任务为农业植保，首案是带可见加注口的中央半嵌药箱、两侧喷杆与铰接机臂。喷杆与中间一对机臂在顶视投影中可重合。顶视看不到部件时，不能据此认定缺装。

- 几何量测采用正交顶视。双叶部件图配合 ControlNet 的比例试验，与 E 盘配置器红点蓝线图配合 Qwen 原生编辑的产品造型试验，各有独立输入、样本与结果。H3 的提示词和参考图小测属于方法开发。
- 作者选择第三轮 E3R3-B2。原实验规定画面上方为机头，按当时规则计分。深化阶段去除上端易误认作镜头的深色开窗后，作者偏好相机位于画面下端、由较宽壳缘遮住部分云台的版本，保留该方向呈现。镜头朝机头前方，正顶视允许看不到镜片。图像拼合与区域换色应标明人工操作。
- 每轴双叶指同一桨毂的两片桨叶相对。作者对连续曲肩、旧 C 的机械细节和功能性配色的取舍属于设计记录。作者提出评论涉及 CMF、便携性和功能配色，这是后续问题，只有编码或评议数据才能支持出现频率或群体偏好。
