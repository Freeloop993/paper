# 第四章 四旋翼无人机造型生成与方法应用

第三章提出了造型意图转译与人智协同可控生成方法。本章以日常随行航拍四旋翼为对象应用该方法：先说明设计任务、应用原型与条件选择的预试，再报告设计者在三个方向上的方案生成与筛选、以改变档位进行的修订，以及选定方案的深化与最终表达。

## 4.1 设计任务设定与应用原型

### 4.1.1 设计目标与构型边界

本章的设计任务是一架日常随行航拍四旋翼的概念造型。使用情境为个人外出时随身携带、展开后近距离跟拍；设计目标以 3.2 节的词对表达，即设计者在“紧凑—舒展”“简洁—繁复”“整体—拼凑”上各自想靠近哪一极，配色上的“低调—醒目”留到 4.4 节深化时再定。

构型边界沿用 3.2.3 节：四个电机、X 形布局、对置轴距 250 mm、横纵跨度比 1.00、每轴一副静止双叶桨、无护圈、前置相机水平朝前。这些作为所有方向共同的保持项，不随设计方向改变。设计者可以改变的是四处顶视可见部位的档位（表3.5），以及不设档位、留给模型探索的自由项。

### 4.1.2 原型组成与生成流程

应用原型由三部分组成。

**参数配置器。** 配置器沿用作者早期开发的 React／TypeScript 界面，设计者可在五组部件参数中设定构型、机身、机臂、桨叶与附件。本文在其几何模块上增加了两项功能：按 W/L 与对置轴距计算轴心并绘制 3.4.3 节的条件图；按造型字典把各参数档位编译为固定顺序的文字。

**设计工作簿。** 工作簿是一个本地网页，承担 3.5 节的记录职责：为三个方向分别填写词对目标、依据卡号与档位，查看编译文字；在“九图选稿”中逐张写取舍理由并选出父图；在“修订与锁稿”中选择一个参数与新档位、填写理由与其余部位的保留情况，记录父图与子图的哈希。工作簿导出时一并保存原图、条件图、规格快照、编译文字、实发文字与版本链，重新载入时重算图片摘要并核对版本顺序（图4.1）。

图：图4.1 设计工作簿的选稿与修订界面〔待截图〕

**生成后端。** 正式后端为部署在云端 GPU 上的 Qwen-Image 2.1，通过 ComfyUI 工作流调用。设计任务的初稿把点线条件图作为参考图、连同编译文字输入模型自带的图像编辑通路；修订以父图为参考、配合编辑指令。几何响应批次另用统一控制分支（3.4.3 节）。每次提交与回执按 3.5.1 节登记。

整体流程为：设计者在工作簿中确认规格 → 配置器生成条件图与文字 → 后端返回 3 张初稿 → 设计者逐张写取舍并选父图 → 改变档位修订（至多两次） → 锁稿并写明理由。

### 4.1.3 技术预试与条件选择

进入正式设计之前，本文用三组预试确定条件图的画法与造型参数的档位。预试的作用是选择条件，其读数都不计入第五章的正式分母。

**（1）只给轴心的条件不足以控制布局。** 早期诊断比较了纯文字与文字加轴位引导图两种输入，6 张图中没有一张的轴位落在目标容限内（5.2.3 节）。随后只在条件图中画出桨盘圆与轴心十字、不画机身与机臂，6 张输出中均找不到可定位为电机轴心的部件，24 个预期位置全部不可辨。另有部分输出把条件图上的标记直接画进了成图。由此，本文放弃“只画轴心”和“图上加标注”的做法，改用不含文字与标注的双叶部件图与点线图（3.4.3 节）。

**（2）双叶部件图能控制布局，但不保证产品造型。** 后端对照（E0）与参数响应实验（E1）使用双叶部件图，经边缘提取后以强度 0.7 贯穿采样。E1 中两项布局比值都随档位单调变化（5.2.1 节），但同批图中也出现了机臂在接近壳体处断开、相机画在机背等造型问题。因此，条件图能让二维几何比值响应，并不证明同一输出同时具备合格的产品造型；造型需要另外的参数与检查。

**（3）造型参数的档位经三轮开发彩排确定。** 为了在开 GPU 之前确定造型字典，本文在 MiniMax 图像接口上进行了三轮开发彩排。该接口不提供随机种子，每轮只有一名盲态 AI 读者，读数只作开发依据。各轮的设置、结果与据此作出的调整见表4.1。

三轮彩排确定的条件，即条件图 v1、造型字典（响应批用同色版，设计方向另加臂材质）与读法，在正式批次之前固定下来，作为正式批次的依据。彩排结果说明了哪些档位在一个闭源接口上可读，正式后端能否同样读出，由下面的小测检验。

### 4.2.2 参数条件配置与候选方案生成

三个方向共用同一张 250 mm 点线条件图，布局句写明每轴静止双叶；前伸相机句按设计者的意见，采用开发阶段机鼻前缘一轮的写法（“相机舱前缘略微越出机鼻，镜头水平朝前，俯视可能完全被遮住”）。9 份请求在出图前登记种子，各提交一次，9 张全部收回，没有重跑、更换种子或删图；回收的请求与登记逐字节一致，采样节点均未命中缓存，单张用时 80—95 秒（图4.2）。

图：图4.2 第一轮九张初稿（自上而下依次为 A、B、C 方向） | ../figures/fig4-2.jpg

九张都是四轴、每轴双叶的正交顶视，规格中的机身、臂根、顶盖与臂材质档位大体出现在对应方向上。同时也出现了规格之外的情况：A2、B2 机头附近多出一道横向盖缝；多张在机身前侧出现小的深色凸耳、在机尾出现深色窄条；C 方向三张的云台都位于机头并越出壳前缘，但镜片朝上、正对观察者，与“镜头水平朝前”不符。

### 4.2.3 候选方案比较与筛选

设计者对九张逐张写下保留什么、改什么（表4.4），结论是“都不合适”，没有选出父图。

表：表4.4 设计者对第一轮九张初稿的取舍（摘录原话）
| 图 | 保留 | 改动意见 |
|---|---|---|
| A1 | 无 | 机身太平整，没有分型线，不够有设计感 |
| A2 | 无 | 机尾一点黑色让人以为相机在那里，整机不协调；分型线太少，材质太统一，颜色太素 |
| A3 | 无 | 机身太整体、太素 |
| B1 | 无 | 桨叶不是 180°；圆润的一端会让人以为是机头 |
| B2 | 无，但机身开始有点设计感、开始有分型线 | 桨叶改为 180°，现在有夹角 |
| B3 | 无 | 机身太素，没有分型线，像一块塑料 |
| C1 | 碳纤维机臂 | 机身太方正、臃肿、略长；相机朝向错误；分型线过于方正 |
| C2 | 碳纤维机臂 | 相机朝向错误；桨叶有夹角（“不知道有没有这种夹角的设计”）；电机纯黑，可用颜色点缀；分型线好一些但不太对 |
| C3 | 碳纤维机臂 | 相机朝向与设计错误；机身太长，前后不协调 |

评语集中在四点。其一，A、B 的机身过于平整，分型线少，材质与颜色单一，只有 B2 的分型线被认为开始有设计感。其二，机头不易辨认：机尾的深色件会被读成相机，使整机前后关系混乱。其三，C 的相机朝向错误，机身过方、过长，但碳纤维机臂值得保留。其四，B1、B2、C2 指出每副桨的两片叶之间有夹角。折叠桨在静止时两叶可以停在任意夹角，飞行时由离心力展开成一直线；顶视设计表达一般按展开状态画成 180°，设计者的要求与这一惯例一致。局部认可不等于选中整机。

按 3.5.3 节，设计者否决全部初稿时，不进入以父图为起点的修订，而是修改规格后重出一轮初稿。表4.5 列出评语与第二轮规格改动的对应；第二轮另登记种子 2026112111—19。

表：表4.5 第一轮评语与第二轮规格改动
| 评语 | 第二轮改动 |
|---|---|
| 桨叶应为 180°（B1、B2、C2） | 布局句写明每副桨两片叶成一直线；负向词排除弯折或后掠的桨叶 |
| 机尾深色件被读成相机（A2）；看不出哪端是机头（B1） | 新增保持句“机尾为素壳、无深色模组或开口”；无外突的相机改为俯视在机鼻最前缘露出一条深色前窗 |
| 相机朝向错误（C1—C3） | 前伸相机句改为俯视只见云台灰色顶面、镜头水平朝前看不见；负向词排除朝上的镜头 |
| 机身太平整、像一块塑料（A1、A3、B3） | 新增“表面”参数：清晰特征线与侧面阶梯切面 |
| 分型线太少（A1、A2）；B2 开始有设计感 | A 改为一道弧形横向分型线，B 改为三块顶盖，A、B 不再同档 |
| 太方正、臃肿、太长（C1、C3） | C 的机身改为带切面的紧凑壳，只比宽略长 |
| 碳纤维机臂值得保留（C1—C3） | C 保留外露碳纹臂与承座 |
| 颜色太素（A2）；电机可用颜色点缀（C2） | 新增“点缀”参数：电机橙色细环，三个方向共用；配色原定 4.4 节深化，按设计者意见提前进入初稿 |

第二轮九张中，机头前窗、分型线与侧面切面按改动出现，但“180°”被研究者误转译为“各副桨水平成一直线”：模型为避开机身，把内侧叶画得细短，B2、B3 的四个电机只剩一片叶；C 的相机架在过长的颈上，机尾仍有深色件。设计者指出，“180°”指同一副桨两片叶之间的夹角，第一轮多数桨叶本是对的，只是个别两叶夹成锐角；并认为 C 的相机“完全错误”。这一误转译说明，设计者的形态语言在进入提示词之前需要被准确理解，评语与档位的对应本身也需要设计者确认。

第三轮撤回“成一直线”的写法，恢复桨叶的自然摆放，只约束同一副桨两片叶等长、方向正相反；C 的相机按真实折叠航拍机的结构改为挂在机头下方、俯视只露相机舱上沿；机尾写明为封闭素壳。正式出图前先以 4 张开发图检验这三处写法，开发图不作候选。第三轮九张中，8 张为自然角度下的正常双叶（A2 只剩单叶），C 三张相机舱贴在机头、无颈杆，机尾均为素壳（图4.3）。
