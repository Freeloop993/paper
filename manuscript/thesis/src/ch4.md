# 第四章 四旋翼无人机造型生成与方法应用

第三章提出了造型意图转译与人智协同可控生成方法。本章以日常随行航拍四旋翼为对象应用该方法：首先说明设计任务、应用原型以及用于选择生成条件的预试，然后依次报告设计者在三个方向上的方案生成与筛选、通过改变档位进行的修订，以及选定方案的深化与最终表达。

## 4.1 设计任务设定与应用原型

### 4.1.1 设计目标与构型边界

本章的设计任务是一架日常随行航拍四旋翼的概念造型，使用情境为个人外出时随身携带、展开后近距离跟拍。设计目标采用 3.2 节的词对表达，即设计者在“紧凑—舒展”“简洁—繁复”“整体—拼凑”三组词对上分别希望靠近哪一极；配色相关的“低调—醒目”留待 4.4 节深化阶段确定。

构型边界沿用 3.2.3 节的设定：四个电机、X 形布局、对置轴距 250 mm、横纵跨度比 1.00、每轴一副静止双叶桨、无护圈、相机前置且水平朝前。这些条件是所有设计方向共同的保持项，不随方向改变。设计者可以调整的是顶视可见的四处部位的档位（表3.6），以及不设档位、交由模型探索的自由项。

### 4.1.2 原型组成与生成流程

应用原型由参数配置器、设计工作簿与生成后端三部分组成。

**参数配置器。** 配置器沿用本研究前期开发的 React／TypeScript 界面，设计者可在五组部件参数中设定构型、机身、机臂、桨叶与附件。本文在其几何模块上增加了两项功能：一是按 W/L 与对置轴距计算轴心位置，并绘制 3.4.3 节所述的条件图；二是按造型字典将各参数档位编译为固定顺序的描述文字。

**设计工作簿。** 工作簿是一个本地网页，承担 3.5 节所述的过程记录功能。设计者在其中为三个方向分别填写词对目标、依据卡号与档位，并查看编译后的文字；在“九图选稿”页逐张写下取舍理由并选出父图；在“修订与定稿”页选择一个参数及其新档位，填写修改理由与其余部位的保持情况，并记录父图与子图的对应关系。工作簿导出时一并保存原图、条件图、规格快照、编译文字、实际输入模型的文字与版本链，重新载入时校验图像与版本顺序，从而保证每一版方案均可追溯（图4.1）。

图：图4.1 设计工作簿的“九图选稿”界面（载入开发样图时的状态） | ../figures/fig4-1.jpg

**生成后端。** 正式实验的生成模型为 Qwen-Image 2.1，通过 ComfyUI 工作流调用。设计任务的初稿以点线条件图为参考图，连同编译文字输入模型自带的图像编辑通路；修订则以父图为参考图，配合编辑指令。几何响应实验另使用统一控制分支（3.4.3 节）。每次生成的输入与结果按 3.5.1 节的方式记录。

整体流程如下：设计者在工作簿中确认规格后，配置器生成条件图与描述文字，模型为每个方向生成 3 张初稿；设计者逐张写下取舍并选定父图，随后通过改变档位进行至多两次修订，最后定稿并写明理由。

### 4.1.3 技术预试与条件选择

进入正式设计之前，本文通过四组预试确定条件图的画法与造型参数的档位。预试的目的在于选择生成条件，其判读结果均不计入第五章正式实验的统计。

**（1）只给轴心的条件不足以控制布局。** 早期诊断比较了纯文字与“文字加轴位引导图”两种输入，6 张图中没有一张的轴位落在目标容限内（5.2.3 节）。随后，条件图中只画出桨盘圆与轴心十字、不画机身与机臂，6 张输出中均找不到可定位为电机轴心的部件，24 个预期位置全部无法辨认；另有部分输出把条件图上的标记直接画进了生成图。据此，本文放弃“只画轴心”和“在图上加标注”的做法，改用不含文字与标注的双叶部件图与点线图（3.4.3 节）。

**（2）双叶部件图能控制布局，但不能保证产品造型。** 后端对照（E0）与参数响应实验（E1）使用双叶部件图，经边缘提取后以 0.7 的控制强度作用于整个采样过程。E1 中两项布局比值均随档位单调变化（5.2.1 节），但同一实验的生成图中也出现了机臂在接近壳体处断开、相机画在机背等造型问题。可见，条件图能使二维几何比值产生响应，却不能保证同一输出同时具备合格的产品造型，造型需要另设参数并单独检查。

**（3）造型参数的档位经三轮开发阶段试验确定。** 为在正式生成之前确定造型字典，本文在 MiniMax 图像接口上进行了三轮开发阶段试验。该接口不提供随机种子，每轮仅由一个 AI 判读者进行盲态判读，结果仅作为开发依据。各轮的设置、结果及据此作出的调整见表4.1。

## 4.2 多方向造型方案生成与探索

### 4.2.1 设计方向与初始造型规格

设计者在工作簿中为三个方向填写了规格卡（表4.3）。第一轮沿用工作簿中的既有规格：A 为基准组合；B 与 A 档位相同，作为同一造型语言的第二组变体，设计者希望保留的“连续曲肩”不属于字典中的档位，只能交由模型自由生成；C 取切角方壳、外露承座、前伸相机舱与多块顶盖，机臂选用外露碳纹。

表：表4.3 第一轮三个方向的造型规格
| 方向 | 词对倾向 | 机身平面形 | 臂根过渡 | 机鼻相机舱 | 顶盖分件 | 臂材质 | 种子 |
|---|---|---|---|---|---|---|---|
| A | 紧凑、简洁、整体 | 流线舱 | 无缝 | 无外突 | 单盖 | 同色哑光 | 2026112101—03 |
| B | 同 A（第二组变体） | 流线舱 | 无缝 | 无外突 | 单盖 | 同色哑光 | 2026112104—06 |
| C | 紧凑、繁复、拼凑 | 切角方壳 | 外露承座 | 前伸 | 多块 | 外露碳纹 | 2026112107—09 |

方向展开要给设计者留出可比较的差异。Dow 等在并行原型实验中将同时比较多个备选与沿单一原型连续修改加以区分[@DOW]。本文的 A、B、C 是一次设计应用中的备选；同一档位组合只换种子所得的外形差异，应记作组内变化。只有把顶盖等档位和其余保持项分别列出，才能解释设计者从哪一轮开始有理由把 A 和 B 分开讨论。

### 4.2.2 参数条件配置与候选方案生成

三个方向共用同一张 250 mm 点线条件图，布局描述句写明每轴为静止双叶桨；前伸相机的描述按设计者的意见，沿用开发阶段试验中的机鼻前缘写法（“相机舱前缘略微越出机鼻，镜头水平朝前，俯视可能完全被遮住”）。九组随机种子在生成前确定，每组各生成一次，九张结果全部纳入评价，未重新生成、更换种子或剔除图像，单张生成用时 80—95 秒（图4.2）。

图：图4.2 第一轮九张初稿（自上而下依次为 A、B、C 方向） | ../figures/fig4-2.jpg

九张均为四轴、每轴双叶的正交顶视图，规格中的机身、臂根、顶盖与臂材质档位大体出现在对应方向上。同时也出现了规格之外的情况：A2、B2 机头附近多出一道横向盖缝；多张图在机身前侧出现较小的深色凸耳，在机尾出现深色窄条；C 方向三张的云台均位于机头并越出壳体前缘，但镜片朝上、正对观察者，与“镜头水平朝前”的要求不符。

### 4.2.3 候选方案比较与筛选

设计者对九张初稿逐张写下保留之处与修改意见（表4.4），结论是九张均不合适，因而未选出父图。

表：表4.4 设计者对第一轮九张初稿的取舍（摘录原话）
| 图 | 保留 | 改动意见 |
|---|---|---|
| A1 | 无 | 机身太平整，没有分型线，不够有设计感 |
| A2 | 无 | 机尾一点黑色让人以为相机在那里，整机不协调；分型线太少，材质太统一，颜色太素 |
| A3 | 无 | 机身太整体、太素 |
| B1 | 无 | 桨叶不是 180°；圆润的一端会让人以为是机头 |
| B2 | 无，但机身开始有点设计感、开始有分型线 | 桨叶改为 180°，现在有夹角 |
| B3 | 无 | 机身太素，没有分型线，像一块塑料 |
| C1 | 碳纤维机臂 | 机身太方正、臃肿、略长；相机朝向错误；分型线过于方正 |
| C2 | 碳纤维机臂 | 相机朝向错误；桨叶有夹角（“不知道有没有这种夹角的设计”）；电机纯黑，可用颜色点缀；分型线好一些但不太对 |
| C3 | 碳纤维机臂 | 相机朝向与设计错误；机身太长，前后不协调 |

设计者的评语集中在四个方面。其一，A、B 两个方向的机身过于平整，分型线少，材质与颜色单一，只有 B2 的分型线被认为开始具有设计感。其二，机头不易辨认，机尾的深色件容易被误认为相机，使整机的前后关系不清。其三，C 方向的相机朝向错误，机身过方、过长，但碳纤维机臂值得保留。其四，对 B1、B2、C2 的评语指出同一副桨的两片叶之间存在夹角。折叠桨在静止时两叶可停在任意夹角，飞行时由离心力展开成一直线；顶视设计表达一般按展开状态画成 180°，设计者的要求与这一惯例一致。此外，设计者对局部的认可并不意味着选中整机。

按 3.5.3 节的规则，设计者否决全部初稿时，不进入以父图为起点的修订，而是修改规格后重新生成一轮初稿。表4.5 列出第一轮评语与第二轮规格改动之间的对应关系；第二轮另行设定了随机种子。

表：表4.5 第一轮评语与第二轮规格改动
| 评语 | 第二轮改动 |
|---|---|
| 桨叶应为 180°（B1、B2、C2） | 布局句写明每副桨两片叶成一直线；负向词排除弯折或后掠的桨叶 |
| 机尾深色件被误认为相机（A2）；看不出哪端是机头（B1） | 新增保持句“机尾为素壳、无深色模组或开口”；无外突的相机改为俯视时在机鼻最前缘露出一条深色前窗 |
| 相机朝向错误（C1—C3） | 前伸相机句改为俯视只见云台灰色顶面、镜头水平朝前且不可见；负向词排除朝上的镜头 |
| 机身太平整、像一块塑料（A1、A3、B3） | 新增“表面”参数：清晰的特征线与侧面阶梯切面 |
| 分型线太少（A1、A2）；B2 开始有设计感 | A 改为一道弧形横向分型线，B 改为三块顶盖，A、B 不再同档 |
| 太方正、臃肿、太长（C1、C3） | C 的机身改为带切面的紧凑壳体，长度只略大于宽度 |
| 碳纤维机臂值得保留（C1—C3） | C 保留外露碳纹臂与承座 |
| 颜色太素（A2）；电机可用颜色点缀（C2） | 新增“点缀”参数：电机橙色细环，三个方向共用；配色原定于 4.4 节深化，按设计者意见提前进入初稿 |
注：第二轮的随机种子为 2026112111—19。

第二轮九张中，机头前窗、分型线与侧面切面均按改动出现，但“180°”这一评语在转译中出现了偏差：设计者所说的“180°”指同一副桨两片叶之间的夹角，转译时却被理解为“各副桨水平成一直线”。模型为使桨叶避开机身，把内侧叶画得细短，B2、B3 的四个电机均只剩一片叶；C 方向的相机架在过长的颈杆上，机尾仍有深色件。设计者指出，第一轮多数桨叶的画法本无问题，只是个别图中两叶夹成锐角，并认为 C 方向的相机安排完全错误。这一转译偏差说明，设计者的形态语言在写入提示词之前需要被准确理解，评语与档位之间的对应也应先经设计者确认。

第三轮撤回“成一直线”的写法，恢复桨叶的自然摆放，只约束同一副桨的两片叶等长、方向正好相反；C 方向的相机参照真实折叠航拍机的结构，改为挂在机头下方、俯视只露出相机舱上沿；机尾写明为封闭素壳。正式生成之前，先以 4 张开发样图检验这三处写法，开发样图不作为候选方案。第三轮九张中，8 张为自然角度下的正常双叶（A2 只剩单叶），C 方向三张的相机舱均贴在机头、无颈杆，各图机尾均为素壳（图4.3）。

图：图4.3 第三轮九张初稿（自上而下依次为 A、B、C 方向） | ../figures/fig4-3.jpg

## 4.3 反馈驱动的造型调整与迭代

### 4.3.1 生成问题识别与修改目标

设计者选定第三轮的 B2 作为父图，理由是其整体造型已得到认可，问题集中在机头：内嵌的相机窗使相机看起来是固定的嵌入式相机，而常规航拍机应当是挂在机头下方的云台相机。修改目标因此只有一项，即把相机由“内嵌”改为“机头下挂云台”，镜头水平朝前、俯视时被舱体遮住，其余部位全部保持不变。

### 4.3.2 参数调整与人工决策

B2入选后，设计者希望改变机鼻下方相机舱的安装关系，同时保留侧面分件和臂根曲线。基于B2的编辑基本延续了原造型，但顶面出现了容易被读为镜窗的深色部件；从点线图重新生成时，机身轮廓和分区也随之变化。设计者决定保留B2作为形态基础。



第二次修订试用了更明确的遮挡描述，又以另一张候选图提示相机舱的位置。前者仍出现可见镜窗，后者改变了相机所在端。这使设计者重新审视了一个更早的决定：B2的哪一端更适合作为机头。两种写法均停留在开发验证阶段（附录E）。



### 4.3.3 迭代过程与设计取舍

进入深化时，设计者保留B2的机身、臂根和顶盖，把相机安装端作为可以单独比较的决定。为排除原有深色窗条对机头辨认的干扰，先从B2去掉窗条，再进行两端对照。实验曾约定画面上方为机头；后续方案的安装端由设计者依据造型选择。

这次回退保住了已经选定的造型，也使问题缩小为一处可观察的关系：相机是顶在壳体前端，还是部分藏在壳缘之下。下一节用同一相机舱比较这两种效果。

## 4.4 方案深化与最终设计表达

### 4.4.1 造型语言与形态细节深化

相机是 4.3 节遗留的唯一问题。深化阶段不再调用生成模型，而是将已有生成结果中的部件拼合到父图上：先用相邻壳面填平 B2 机鼻的深色窗条，得到去窗底图；再从与 5.2.1 节造型响应实验相同随机种子配对、按 v1.6 字典生成的一组图像中选取一个位于机头、云台两侧轴清晰的相机舱，按两图机身宽度之比缩放后贴在机身一端，并使机身壳缘压住相机舱的上部。每一步的改动都可以逐像素核对：去窗仅改动父图的 1305 个像素，安装相机再改动约 3100—3300 个像素，改动均局限在机身端部的一个小范围内，其余像素与父图完全相同（图4.4）。

相机最初按实验约定装在画面上端。随后，本文制作了相机分别装在上、下两端的对照图，设计者比较两端方案后，更倾向于相机装在下端的版本，认为装在上端可能不太合适。从两端的形态看，B2 的上端窄而圆，相机舱比端部还宽，像顶在鼻尖上的附加件；下端宽而平，壳缘恰好罩住云台的上半部，相机像是挂在机身前缘之下。因此，4.4 节以画面下端为机头继续深化。

两端对照固定了相机舱来源和机身轮廓。选择下端说明设计者在这架机身上更认可宽端与相机舱的衔接。早期生成图也曾把部件放在下端，但当时的输入条件不同，无法由此推断模型识别出了同一造型理由。

图：图 4.4 去窗底图与相机装在两端的对照（下排为端部等倍放大） | ../figures/fig4-6.png

设计者随后确定：4.4 节的图保持机头在画面下端，不作旋转；相机舱前沿的深色窄缝予以保留；接触阴影作为下一步的细节调整。接触阴影同样以确定性方法加入：选取相机舱区域的像素，按其到机身壳缘的距离逐像素压暗，越靠近壳缘越暗，共改动 3028 个像素，全部位于相机舱内。整机定稿留待深化完成后确定。

在方案深化中，先去窗再比较两端有具体作用。直接比较带不同相机、颜色和窗条的两张图，无法知道设计者响应的是舱体位置，还是把深色窗条识别成了镜头。以同一去窗底图和同一舱体作两端备选，就把判断缩小到端部宽度及壳缘覆盖关系。这也说明了参考图在发散与收敛阶段的不同作用。示例对设计构思的固着作用曾在设计实验中得到检验[@FIXATION]；此处以几何点线保留初稿空间，已有满意机身后才让完整父图参与局部编辑。

### 4.4.2 色彩、材料与表面处理设计

“低调—醒目”是唯一只作用于色彩与材料的词对，按第三章的设定在深化阶段引入。为使两档之间只相差这一项，色材深化不改变形状，只按区域换色：低调档将四副电机的橙环改为中性深灰，全机只保留中性色；醒目档保留前两副电机的橙环，将后两副改为深灰，并在前两臂靠近电机的一段加入信号橙色带（图4.5）。橙色集中在机头一侧，用意是让前后方向更易辨认，并提高落地后的可见性。实际飞行中的辨向和寻回效果尚待验证。两档相对底图的改动分别只占 0.11% 与 0.37% 的像素，造型轮廓保持不变。

深化方案的两种配色均保持浅灰机臂。碳纤维机臂等材质纹理无法通过区域换色获得，只能借助生成式编辑实现，而设计者在第三轮评阅时认为碳纤维宜在深化中逐步引入；因此，本文将材质纹理的引入作为后续的材质深化，先以少量开发样图检验以父图为起点的材质编辑能否保住其余部位，再决定是否纳入终稿。

图：图 4.5 色材两档：左为加接触阴影后的底图，中为低调档，右为醒目档（下排为前两臂与机头局部） | ../figures/fig4-7.jpg

两档均予保留，作为同一锁定造型的两种配色进入最终表达。设计者认为两种配色都应呈现，而不应只按个人喜好取舍。因此，哪一档更能传达“低调—醒目”的意图，交由独立评议者判断（5.3 节）。第5.3节报告了两种配色并排观看时的实际选择。配色对其他词对的影响另待逐图评分检验。

### 4.4.3 最终方案呈现与设计说明

深化后的方案以 B2 为造型基础，机头位于画面下端，以低调、醒目两种配色并列呈现（图4.6）。本文的方案表达限于正交顶视（1.4 节），以下按顶视可见的部位与配色说明设计。

**机身。** 机身为流线舱形，轮廓连续圆润，壳面带有特征线与侧面阶梯切面，回应了设计者在第一轮中“像一块塑料”的批评。顶盖由中央主盖与两侧侧条组成：两条纵向分型线沿机身两侧展开，在机头一端向外扩开，形成罩住云台的前缘；在机尾一端，中央主盖以一道带斜角的横向分型线分出尾盖。分型线把机身划分为可辨识的几块，但不切断整体轮廓，对应设计者在“简洁—繁复”“整体—拼凑”上的取向，即分件可见而整体连续。

**臂根。** 四根机臂从机身两侧肩部无缝伸出，臂根处没有接缝或承座，前后机臂对称外伸。这一档位自第三轮初稿直接继承，深化阶段未作改动。

机头相机。 相机舱安装在画面下端的壳缘之下。正俯视可见舱顶、两侧云台轴和前沿的窄缝；壳缘处的接触阴影交代了舱顶与上壳的前后层次。镜头水平朝前是安装意图，单张顶视图不足以验证实际光轴。

**桨叶与电机。** 每个电机配一副静止双叶桨，两片叶等长、相对呈 180°，按自然角度摆放；电机为深灰色。

配色。 低调档保留浅灰壳体、深灰电机和黑色桨叶。醒目档把信号橙集中在机头一侧的两处电机环和邻近臂段，为前后辨认提供色彩线索。两张图用于比较观察者感到的醒目程度。

图4.7记录了B2从候选到终稿的主要决定。去窗、两端安装比较、接触阴影和区域换色均由人工处理；机身与臂根延续设计者选定的版本。两种配色保留为同一形态方案的不同表达。

## 4.5 本章小结

本章以日常随行航拍四旋翼为对象应用了第三章的方法，结果可归纳为以下四点。

几何试验和造型探索使用不同的图像条件。需要检查轴距与桨径的比例时，双叶部件图提供可测量的叶尖；探索机身轮廓和臂根过渡时，点线图给出安装位置，让这些部位保有设计空间。“紧凑—舒展”尚未找到能使输出稳定变化的单一参数。

第二，规格卡使设计者的评语能够落实到参数上。三轮初稿共 27 张，设计者逐张写下的取舍被逐条对应到规格改动（表4.5）；其中“180°”一处出现转译偏差，说明评语在写入提示词之前需要向设计者回述确认。

第三，机身与臂根已获得认可后，继续整机生成会重新打开原本已定的设计决定。B2回退后的深化固定这两处，集中比较相机安装端和壳缘遮挡。

第四，深化阶段由设计者掌握取舍。机头装在哪一端由设计者在两端对照中选定；配色以低调、醒目两档并存，交由独立评议判断，而不按设计者的个人偏好二选一；深化各步均不调用生成模型，改动范围逐步可查。

第五章分别考察布局参数的响应、局部改变与保持、方案感知、协同过程和六旋翼的适用条件；已完成的图像量测与有待取得的真人判断分项报告。
