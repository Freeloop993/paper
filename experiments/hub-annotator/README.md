# S1 真人轴心复测
只把 [human-pack](../../evidence/s1-axis-repeat/human-pack) **整个文件夹**或其单独压缩包交给读图人。不要给仓库、映射、首次/第二次标注、目标点、既有结果或其他人的读数。解压后双击 index.html；普通桌面浏览器即可，不联网、不装库。每位各自完成，分配不同匿名代号。先交回并封存 JSON，再向分析员揭盲。请另记是否事先看过图或结果；不满足独立条件时单列。包内仅包含随机编号、去元数据且 RGB 像素相等的 6 张 PNG、页面及显示顺序。记录顺序是画面左上、右上、左下、右下，坐标由原图像素取得；4× 局部放大、撤销和逐轴不可判均可用。
分析员从完整仓库运行 `python compare_human.py <返回文件>`，按人输出与两份 AI 的逐轴欧氏差；缺点保留 null，六图全部可判才回答“该读者是否也为 0/6”。真人读数是量测一致性/对目标偏差证据，不等于物理真值或美学评议。不要提交原始答卷。尚无本批真实人员提交。


软件验收：Windows Edge 以 file:// 打开整包；4×放大后偏心点击映射到已知 (576,448)，撤销、拒绝未填项、逐轴不可判、六图真实 JSON 下载及比较脚本均通过。另用已知首次坐标作软件对照，24 轴到首次读数之差均为 0；上述输入不计真人。另一台机器尚未独立回执。
