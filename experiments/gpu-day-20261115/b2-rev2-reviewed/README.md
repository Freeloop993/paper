基于 e2dd53b 的 6 份请求。回退到作者选定的第三轮 B2。相机位于画面上方机鼻前缘下方，舱顶略外伸，镜头水平朝机头，在正俯视投影中被舱体遮挡。支架形状、数量、露出方式由模型处理。原保持项、负向词、Qwen 管线、种子及采样设置沿用原登记。请求另取输出名以区分实际提交。

2. 顶视看不到镜片或镜窗。暗部与玻璃难分时记“无法确认”。此项只反映顶视可见性。
