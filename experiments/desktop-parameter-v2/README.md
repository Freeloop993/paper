# 桌面参数原型 · 需求、结构与可测布局

对应第 3 章 3.3.2、3.4.2–3.4.4 及第 4 章 4.1.2–4.1.3。日常随行航拍四旋的任务重点是前摄与机鼻、臂根与机身；植保六旋的任务重点是药箱及喷洒组件与机架的整合。需求、目标部位、保持项和自由项由设计者编辑。定位 PNG 和完整提示词共用同一份已应用参数，PNG 省去画面上的文字与刻度。导出结果见 [exports](exports)，几何与提示词生成逻辑见 [designLayout.js](designLayout.js)。

径向布局顺时针累加相邻的夹角，总和为 360°。比例模式设定机头前后跨度与左右跨度之比，再按最大电机中心距等比缩放。H 型以两排轴位与中间横梁表达；实际夹角从轴心坐标反算。可选桨盘直径表示扫掠圆的设计范围。

四种配置通过浏览器的应用与下载入口运行，从 PNG 的红色像素质心独立反算最大轴距、相邻夹角或跨度比，并与同名 JSON 对账。[离线界面检验](export-checks.json) 的尺寸换算使用原型的设计比例尺。

Codex 在知道输入条件下估读输出的四个转轴，以画面中心为角度原点，约为 69.7/108.3/69.8/112.3°。仅按画布大小等比换算，四轴平均位置误差约 9.9 px（1024²）。这是单个接通样例。没有独立评议、增益对照或该版六旋的模型运行。[输入来源、估读位置与摘要](receipt.json)。
