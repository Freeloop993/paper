# G3 父图是否留下可辨痕迹（出图前判据；未执行）
两份请求只差参考分支及输出文件名，同一 B1-T 真实父图、修改句、种子 2026111101、顶视、40 步、1024²；有图侧把相同字节以请求内 parent-摘要.png 名导入。无图侧不接父图。用顶视避免 S1 父图到斜视呈现的视角混杂；即使成功也只证明这一对输入有可辨信号，不证明斜视、所有风格或真实设计者修订有效。运行 python build.py 可复现两份 JSON 并校验差异。待单独核价授权（最多 2 次），不自动补图。

**揭盲前固定的判读表：**操作者随机化两张结果次序，将父图与匿名 A/B 原图同时给各一名真人、一名独立 AI。先分别封存读数再揭盲；对每张结果逐项标 保持 / 改变 / 不可判，并指出部位。① 中央壳体外轮廓和肩部宽窄关系；② 上盖主要分件边界的数量、位置和走向；③ 臂根与机身交界形式。另标前摄过渡修改是否可辨、有无直接复制父图。每项保持记 1；不把不可判算作改变。

若两个读者分别都能判断三项、有参考侧各至少保持两项、且各比无参考侧多保持至少一项，才记“本对出现参考保持信号”。修改意图也各读者皆可辨且非原图像素复制，才建议两组同等开放此修订路径。两图同分、读者分歧、缺图/缺人或任一关键项不可判，记证据不足；不挑图、不加试。正式采集前若无充分证据，两组同样使用纯文字修订。模板 [reading.csv](reading.csv)，空表不计评审。
