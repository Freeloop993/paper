# 四旋翼概念改稿台

这是工单 #2 的本机离线演练入口。两种方法共用日常随行航拍简报、任务 A/B、模型参数、版本选择以及初稿加一次修订的机会。自由文字可以完整表达自己的指令，结构化输入分部位、改变和保持三栏。初稿和文字修订都由操作员决定机身外形。也可选择把初稿原图送入修订请求的图像参考节点。

在本目录用 Python 3.10 或更高版本、Pillow 运行 `python -B workbench.py`，打开终端给出的本机网址。默认使用 127.0.0.1:8726。换数据库或端口可用 `--db 路径 --port 端口`。每次从首页新建场次，刷新带场次编号的网址能恢复已保存记录。图和输入保存在本机 SQLite 文件中。

1. 选择任务与方法，输入自己的目标，保存初稿请求。在版本记录展开实际请求，查看编码器文字和节点。
2. 在本机登记已有的 1024 × 1024 单帧 PNG 作演练样图。两种方法都可以停止，或选一次文字修订或带初稿参考的修订。在失败或未知分支填原因，系统停止修订。
3. 选初稿、修改稿或均不交，写明理由并锁定。锁定写入服务端，刷新及旧页面重复操作均不能覆盖。导出 ZIP 包含版本、事件、实际编译的请求、原图及锁稿选择。样图均为演练导入，真实生成和后端受理仍需另行验证。

**复核软件行为。** `compiler.py` 沿用 B02 自由外形 v1 的编译逻辑。随附历史模板按原字节的 SHA256 校验。浏览器核对脚本需要 Node.js、Playwright 和可用的 Chromium 浏览器，使用系统浏览器时可设置环境变量 `QA_BROWSER` 为其可执行文件。启动服务后运行：

```text
node browser-check.cjs http://127.0.0.1:8726 初稿样图.png 修改稿样图.png 新的验收目录
python -B verify_receipts.py 新的验收目录
```

选择字节不同的两张原图。验收脚本操作桌面及窄屏界面、刷新后尝试改写锁稿、下载七份 ZIP。独立脚本按内容摘要核对每个请求、选中原图与参考原图。仓库存放的验收摘要仅供复核软件。图像设计质量、参与者操作、真实后端参考能力和正式采集条件分别由研究工单继续核验。
