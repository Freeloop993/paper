# 第 5 章局部编辑与单参数评议材料

相机的底图采用已经去掉开窗、尚未加装相机的 B2。机头位于画面下端。分件和臂根采用已有下端相机的低调配色稿。三个区域和全部种子均在出图前固定。

每项先运行 3 张开发图。相机须见略越出下端轮廓的舱顶，机身遮住部分舱体；顶视不应出现朝观察者的镜片。顶盖须见完整盖板，原来横穿盖板的内部接缝消失，周边仍有合理分界。四处臂根须分别出现可辨的承座和台阶，明暗边界单独不足。所有图额外检查合成边缘是否突兀，以及保留区是否协调。任一目标不清即不计通过，逐张保留理由。

开发图有至少 2 张满足本项全部条件才运行该项确认批。相机 8 个此前未用的确认种子，顶盖和臂根各 4 个。第一张达到判据的确认图进入评议材料，完整结果保留。每张同时保留 Qwen 原图与遮罩合成结果。合成输出遮罩外逐像素保持属于程序性质，不能作为模型保持能力的证据。

题目所检验的是设计图上的可见关系。目标部位与其余部位分别报告。单参数评议须由独立真人判断语义，开发图本身不能回答是否更简洁或更整体。
