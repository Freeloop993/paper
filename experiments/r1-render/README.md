# R1 渲染设置选择 · 出图前冻结单

研究问题是调节渲染设置后，在保留目标布局的同时，能否从顶视图看清相机与机身、臂根与机身的关系。旧图扁平的成因仍是待检验的解释。R1 固定提示词，仅能比较本次设置组合。结论限于这一张条件图、这一段文字和两个种子。

[Claude 的设计理由](https://github.com/Freeloop993/paper/issues/19#issuecomment-6822354814) · [作者决定及两张规则的更正](https://github.com/Freeloop993/paper/issues/19#issuecomment-6822414347) · [#3 登记](https://github.com/Freeloop993/paper/issues/3#issuecomment-6822470466)

## 输入、顺序与分母

E0 → E1 → R1 → E2。固定 E1 中档、白底正交顶视、W/L 1.00、d/D 0.50，采用 E1-control-wl1.00-r1、r2 的原图条件、文字、模型和两个配对种子 2026111211、2026111212。此处 0.50 为实验设定值。

| 因素 | 两档 |
|---|---|
| 文字引导系数 CFG | 1、3 |
| ControlNet 强度 | 0.7、0.5 |
| ControlNet 作用区间 | 0 至 1.0、0 至 0.6 |

8 格各 2 个位置。CFG 1、强度 0.7、结束于 1.0 的两份请求与 E1 原请求字节一致。待 E1 回收后，凭请求摘要、prompt_id、history、原图摘要引用该两张。其余 14 个位置各提交一次。用 R1 格号建独立回收目录；冻结请求内的 SaveImage 前缀仍是 E1 的原值，按本次 history 指向的文件和 SHA 收图。逐位置记录来源、新提交、返回、缺失与不可读。清单的 16 项不是 16 个独立新样本。

## 盲读问法

两名独立盲态 AI 和一名真人各自看随机编号的原尺寸 RGB，独立填以下三题。评者看不到设置、种子、来源阶段或其他人的回答。全部收齐后才揭盲，单列每位读者的分数及简短图像依据。缺图或无法打开记缺失；图已打开但看不到部件时按题中的 0 级记录。

| 问题 | 0 | 1 | 2 |
|---|---|---|---|
| 从这张俯视图看，它在多大程度上像一件完整的航拍产品？请指出一处可见依据。 | 只能辨认布局与零件符号 | 能看出整机体积，局部的连接或层次还看不清 | 能看出机身体积、部件前后层次和连成整机的关系 |
| 你能指出前摄的位置，看出它怎样装进机身吗？ | 找不到相机 | 能指认疑似窗口，连接方式不清 | 能指认窗口和周围壳体的包覆或安装边界 |
| 你能指出机臂从哪里接入机身，看出接合处的形态吗？ | 接合处无法辨认 | 能指出接入位置，过渡形态不清 | 能从连续曲面、截面变化或清楚的接头看出怎样过渡 |

沿用几何盲读方法，记录四电机、四副双叶桨及轴心像素。按对应位置逐点保存目标与读数，保留缺失。选取按 #19 的更正：格内两张均几何可读且轴心归一偏移 ≤0.05，才进入产品感比较。产品感对应第一题；相机与臂根单列，用于解释选择。

以下计算细节提交 Claude 出图前复核，供复算：每图用四个轴心到对应目标点的欧氏距离均值除以条件图对置轴距 600 px，分别列出盲态几何读者读数，再对两读者的同图值取均值。每图第一题取三位评者的中位数，再对同格两图取平均。产品感并列时，以相对 E1 改变的因素数较少者为近；仍相同时列为并列并交回，不事后按图选。真人评议缺失时保留评分空位，等待收齐后选取。若没有一格满足几何要求，E3 延用 E1 并报告局限。若 E3 使用新设置，E1 的几何结论限定在原设置内。
