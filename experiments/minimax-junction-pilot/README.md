# 相机舱与臂根的 MiniMax 配图预试

输入 PR #66 的 P2-R1 全部九图及其实际请求。本批单独记录为开发样本，采用作者今天授权的 MiniMax H3-Image。按 [manifest](manifest.json) 固定三种造型简报 × 两张定位图，共六次独立请求。每格一次，无种子；编辑端自动改词。保持同一幅面、机头、轴位、材质与光。原卡的 127/250=0.508，此处为使尺寸和目标 d/D=0.50 严格相符，写 125/250。二维投影与文字中的毫米值分别记录。与上轮相比，短语、光照、部位规格和桨径文字都变了，跨轮差异只能归于整份简报。轮内同一方向仅参考图变化，灰条和大圆换成同位置的细线和小点；不能把线宽和点径的贡献拆开。

| 方向 | 机鼻可见证据 | 四处臂根可见证据 |
|---|---|---|
| A 一体 | 双侧壳肩包住机鼻，内侧露窄月牙形舱冠 | 宽圆肩与机身连续过渡至臂段 |
| B 舒展 | 纵向双脊夹持齐平的窄舱罩，上缘呈 U 形 | 长形臂根沿机身侧面一段再向外渐收 |
| C 分件 | 窄舱嵌在鼻端两耳之间，接合缝与端盖可见 | 四根臂均嵌入承座，以贴合套环收口 |

图前记录的人工查看顺序为四轴与四副等长双叶、机头是否明确朝上、镜头是否误朝观察者、接合是否连续或有意分件、舱体线索和桨叶是否可见，以及有无参考标记。每个部位写可见、相反或不可判。沿用 P2 对 W/L 1.00±0.10 与双叶长度差约 15% 的描述，只有实际量测后才登记数值。开发阶段只看三方向是否值得交给作者评图，P2 的九图盲读门槛不套用到六格。若两种局部关系可辨、基础结构可信，交作者选；若有具体重复缺陷，先归因再局部修订。全部失败与原件保留，不自动重试请求。本批不计入 E3、E5，不触发 GPU。
