# G2 · 相对轴位随控制图变化吗？
这是一份可复算的**出图前候选包**，不含调用器。三档目标、两种子、六份完整请求见 [manifest.json](manifest.json)；`python build.py` 从[六份实际执行图](../../evidence/s1-decomposition/executed-graphs.json)的 L 路线重建。1024²、40步、Euler/simple、CFG 1、全程 0—1，模型与正负编码节点继承 S1。新控制图为白底黑线桨盘圆与轴心十字，直接送至控制分支，不再做 Canny；强度由 0.35 改为 1.0。无机身边界或臂线。文本对三档一致，不给数值；同种子内只改控制图、输出名。不能把 G2 对 S1 的差异单独归因为强度、引导图、文字或种子。H2 不存在同种子 S1 对照，只能跨批描述。

[原始输入靶标](paired-layout-targets.json)固定画幅中心、对置轴径 600 px、拓扑各自基准横/纵比，目标 0.85 / 1.00 / 1.15。r = (最大横跨度 / 最大纵跨度) ÷ 原拓扑未变形时的横纵比；按**名义目标**判误差，另留舍入值。编号种子 2026111001 / 2026111002。原三档坐标表未指定桨盘半径：本候选承接旧主实验协议中桨盘直径/对置轴径 0.23，即固定半径 69 px，不把它说成既已批准的 G2 参数。

**读数和判据。**按规格给两位独立 AI 与至少一名真人准备匿名材料，各自封存再揭盲。将某读者每图四轴（UL/UR/LL/LR）录入 [reader-template.json](reader-template.json)，不可判留 null；运行 `python measure.py reader.json`。逐读者报告严格单调、6 个绝对误差 ≤0.10、可辨分母；不同读者不由多数投票冲成通过。另记机身是否可见、是否把桨盘误画成环件。质心位移、尺度、残差、直接坐标容差另列；脚本同时保留原 S1 固定正方靶标的原门、以及随本档靶标变化的同型门。非正方档不应被要求命中旧正方。不可判或分歧未满足完整通过，分项保留。单种子单调/仅部分满足按规格作部分证据；两种子均非单调或≥2图四轴不可判即失败；其他边界（如只缺1图）列证据不足。
