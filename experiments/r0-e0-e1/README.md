## 逐次文件与复验

[请求索引](manifest.json)登记各格、重复号、输入文件和 SHA-256。[基准环境](hardware-reference.json)登记四个权重、四份源码、节点与旧环境实际版本。[原始 R0 请求存档](L2S1C1-request.original.json)取自旧结果 ZIP，对照归档执行图逐节点相同。R0 第一次原样发送该 4119 字节文件，第二次只替换一次十位种子，使用独立结果目录保留两次的原输出名。线上以提交字节、服务返回的 prompt_id 和 history 回执为准。

从仓库根目录执行以下命令可离线复编与核验。

```sh
python -B experiments/r0-e0-e1/build_guides.py
python -B experiments/r0-e0-e1/compile.py 5ec145398674ebc771211662681f84885594ee75
python -B experiments/r0-e0-e1/verify.py
```

开源 KSampler 40 步、cfg 1、Euler/simple、1024²；Canny 0.4/0.8，Fun Union 强度 0.7 全程。服务实际 GPU、驱动、显存、加载精度、内存卸载和缓存行为随批登记。闭源拟由执行者调用 Runway 图像接口，显式模型标识 `gpt-image-2.5-flare`，1:1、1K、每次一张。该托管接口无可固定种子、负向词、ControlNet 或权重摘要；额外参考图说明按输入规格 §3.5。请求使用同一公开提交上的原 PNG。部署前的只读账号核验返回需重新授权。闭源执行前核账号额度、当次计价及服务实际模型；若接口不可用，在 #19 报告，改模型须在首次生成前重新登记。

仅执行 #3 明确覆盖的费用与张数，运行前记录含磁盘、闭源调用的剩余额度和停机时间。R0、E0、E1 分列计划、实际请求数、成功返回、失败、缺失及不可判；全量留存原图、原始请求、服务回执、缓存情况与费用。知条件 AI 初读另列；独立量测助手不知道档位，W/L 点击轴心、d/D 同时读取叶尖。人体评议、读数误差或 GPU 峰值需实测，当前没有这些结果。
