## 逐次文件与复验

[请求索引](manifest.json)登记各格、重复号、输入文件和 SHA-256。[基准环境](hardware-reference.json)登记四个权重、四份源码、节点与旧环境实际版本。[原始 R0 请求存档](L2S1C1-request.original.json)取自旧结果 ZIP，对照归档执行图逐节点相同。R0 第一次原样发送该 4119 字节文件，第二次只替换一次十位种子，使用独立结果目录保留两次的原输出名。线上以提交字节、服务返回的 prompt_id 和 history 回执为准。

从仓库根目录执行以下命令可离线复编与核验。

```sh
python -B experiments/r0-e0-e1/build_guides.py
python -B experiments/r0-e0-e1/compile.py 5ec145398674ebc771211662681f84885594ee75
python -B experiments/r0-e0-e1/verify.py
```

开源 KSampler 40 步、cfg 1、Euler/simple、1024²；Canny 0.4/0.8，Fun Union 强度 0.7 全程。服务实际 GPU、驱动、显存、加载精度、内存卸载和缓存行为随批登记。E0 闭源六次使用 OpenAI Images Edits 接口 `POST /v1/images/edits`，显式传入 `gpt-image-2.6-flare`。每次输出一张 1024² PNG，提示词和档位图沿用原冻结字节；质量与复杂度使用服务默认。每百万 token 的美元单价为文字输入 5、缓存 1.25，图像输入 8、缓存 2，图像输出 30。记录原请求、响应、请求 ID、usage、费用及原图；若响应缺少模型字段则记缺失，请求模型标识另存。官方 API 账户访问待验证。[官方模型与定价](https://developers.openai.com/api/docs/models/gpt-image-2.6-flare) · [接口](https://developers.openai.com/api/reference/resources/images/methods/edit)。

## 独立量测与真人抽读

首次读数前固定种子 2026111219，按 SHA-256 字典序分层抽取 E0 开源 4 张、E1 条件 6 张与纯文字 2 张。缺图位置保留缺失。两名新建且相互隔离的 AI 评者各自读取全部实际验收图，一名真人抽读这 12 张。每位评者仅接收自己的随机编号 PNG 和坐标说明。图像按原尺寸重存，核对 RGB 相等并清除元数据；条件表、请求、原文件名和仓库留在协调者侧。知条件 AI 初读单列。[抽样清单](human-sample-plan.json) · [打包脚本](blind_pack.py) · [评者说明](reader-instructions.txt)。

按图计算 W/L、d/D；对每项分别取两名 AI 绝对差的中位数、两名 AI 平均值与真人绝对差的中位数。读数误差用两者中较大值。分别列实际有效配对、缺失及原因。12 张抽读的 W/L 人机绝对差中位数若 >0.05，则转为真人全读，AI 读数作并列参考。缺失使误差校准不完整时报告缺口。E1 相邻档均值差与两倍误差的判据照旧。

真人包取得全部 12 张后自带离线点选页。请把整个参与者包交给独立读者。界面允许逐点放大、撤销、记录不可判及原因、刷新后接续。导出包含自己的点位与既往曝光记录。已看过带标签材料、读数或分析的答卷另存。

从仓库根目录运行 `python experiments/r0-e0-e1/summarize_e1.py evidence` 可按冻结档位分别计算两种比值与样本标准差。加入 `--human 独立点选答卷.json` 会校验抽样身份、原图摘要及曝光情况，并按已登记规则计算误差。两副对角电机距离取均值；四副桨各取两个叶尖之间的距离，再求均值。单图 W/L 仅需四个可辨轴心，d/D 还需全部对应的叶尖。按两名 AI 的逐图均值汇总，两者任一缺点则该项配对缺失。并列给出命中数、全部位置和可读位置的分母。原始几何记录保留每个点和缺失说明。

仅执行 #3 明确覆盖的费用与张数，记录算力、磁盘小时费率、闭源调用费用与实际起止时间；作者选择按量保持实例运行并自行充值。R0、E0、E1 分列计划、实际请求数、成功返回、失败、缺失及不可判；全量留存原图、原始请求、服务回执、缓存情况与费用。知条件 AI 初读另列；独立量测助手不知道档位，W/L 点击轴心、d/D 同时读取叶尖。人体评议、读数误差或 GPU 峰值需实测，当前没有这些结果。
