# 紧凑感评议包（S5）

发给评议者的只有一个文件：[participant/无人机外观评议.html](participant/无人机外观评议.html)（2.3 MB，离线运行，不联网）。评议者打开它，一次看一款真实的多旋翼产品，评它紧凑还是舒展，最后把结果发回。大约 15 到 20 分钟。现行版本 5.0。

样本是 44 款真实产品，来自 22 个品牌：四旋翼 32 款，六旋翼 8 款，八旋翼 3 款，共轴 1 款，[总览图](real-overview.jpg)带机型名，只给研究者看。读法和限度见[方案](protocol.md)。

## 怎么发

1. 找没有参与过这个设计、也没看过这些图的人。设计背景有无都可以，页面会问。
2. 把 `无人机外观评议.html` 这个文件发给对方（微信、邮件都行）。建议对方用电脑上的 Chrome、Edge 或 Safari 打开。
3. 对方做完后有两种交回方式：点“下载结果文件”把 JSON 文件发回；或者点“复制结果”，把一长串文字粘贴到聊天里发回。
4. 不要告诉对方研究想验证什么，也不要告诉哪张图是哪一档。

可以直接用的邀请语：

> 想请你帮忙做一个 10 分钟左右的小评议，是我学位论文的一部分。附件是一个网页文件，用电脑浏览器打开就行，不用联网。里面是一些无人机的图，按你自己的感觉回答，没有对错，做的时候不要和别人商量。最后页面会给出一份结果，下载文件发回给我，或者点“复制结果”把文字粘贴给我都可以。结果里没有你的姓名和联系方式。谢谢！

## 收回之后

把收到的文件按日期放进 `responses/<日期>/`（粘贴回来的文字每份存成一个 `.txt`）。作者 2026-11-19 决定答卷原件入库；文件里没有姓名和联系方式，有自由留言。评议者发回的原件另外留一份，上传途中丢过字符。

```sh
node qa/verify_returns.mjs responses/<日期>     # 先核对：文件是不是页面原样产出的
python3 summarize.py responses/<日期>/*         # 再汇总
```

汇总按所看的图分组：评议者自报的背景、逐款逐人读数和中位数、评议者之间的一致程度、按构型和类型的汇总、评分与图上读数的等级相关。同一个编号重复发回的只算一份，少于 3 份的组不报告。

**一律发 `participant/` 里的原页面，不要改图单。** 七点量表是相对着用的，图单不同的答卷分值不在同一把尺子上，不能合并。

## 这个包现在的状态

- 样本靠图片检索取得，逐张筛过，每张的来源页、原图地址和摘要记在 [real/samples.json](real/samples.json)；筛选经过见[审查记录](stimulus-review.md)第十节。
- 软件走查通过：`node qa/walkthrough.mjs` 用三个合成评议者把页面从头做到尾，共 27 项检查，包括必答拦截、刷新后接着答、下载与复制结果一致、桌面宽度下图和三组量表同屏、手机宽度下滚动时图仍在屏内。
- 回件到齐（2026-11-20）：13 份答卷文件，四旋翼 32 款有 10 名评议者，44 张混排有 7 名。结果和读法见 [responses/README.md](responses/README.md)；只有 3 人时的记录在 [responses/2026-11-19](responses/2026-11-19/README.md)。合成答卷不是研究数据。
- 44 张图的规格比例由两位判读者各量了一遍（[geometry](geometry/README.md)）。标点时发现 6 张图有瑕疵，汇总时单列。
- 手机上只在浏览器的手机宽度下检查过排版。聊天软件里直接点开附件能不能正常作答没有测过，建议用电脑。
- 4.0 版发出过，收回 3 份；1.0 到 3.0 各版都没有发出。

## 文件

| 文件 | 用途 |
| --- | --- |
| `participant/无人机外观评议.html` | 发给评议者 |
| `real-overview.jpg` | 全部样本的总览，带机型名，只给研究者看 |
| `protocol.md` | 样本、流程、读法、限度 |
| `real/samples.json` | 每款样本的品牌、机型、类型、来源页、原图地址、摘要和图上读数 |
| `real/stimuli/` | 处理好的评议用图 |
| `real/web/` | 检索脚本、两轮检索的全部候选、入选记录、下载记录、被筛掉的图 |
| `real/prepare_web.py` | 抠白底、去色、转正、统一占幅 |
| `real/render.mjs`、`real/prepare_real.py` | 两款用官方 3D 模型渲染的样本所用的脚本 |
| `build.py`、`template.html` | 生成评议页面和核对键 |
| `researcher-key.json` | 匿名图号对应的机型和读数。研究者自留，不发 |
| `freeze.json` | 冻结时方案、页面和核对键的 SHA-256 |
| `summarize.py` | 汇总回件 |
| `responses/` | 按日期存放的回件、核对表、汇总和读法 |
| `geometry/` | 44 张图的电机中心、机壳和桨尖读数，规格四项比例，与评分的对照；给第二位判读者的取点页面在 `geometry/annotator/` |
| `qa/walkthrough.mjs` | 软件走查 |
| `qa/verify_returns.mjs` | 用答卷里的种子核对回件是否出自页面 |
| `stimulus-review.md` | 评议用图换过几次、每次为什么换 |
| `qwen/`、`h3/` | 此前各版的材料和几何编辑脚本，留作下一步的对照和过程记录 |

原图和官方 3D 模型体积大，没有入库，可按 `real/web/downloads.json` 和 `real/samples.json` 里的地址重新取得。
