## 二、这次要改正的两处方法问题

1. **局部编辑第一版三组开发图都未过，失败多出在合成。** 整图生成后用紧遮罩裁切，把原图里完整的舱体切断，接缝发白。第二版改为在生成时就限定重绘区域：父图经 VAE 编码，加 `SetLatentNoiseMask`，模型只在遮罩内重新采样。遮罩放宽并羽化。解码后再按同一遮罩合回父图（[composite.py](composite.py)），遮罩外逐像素不变。遮罩位置见 [mask-preview.jpg](mask-preview.jpg)，由 [build.py](build.py) 从底图逐行量得。
2. **E2R 的指令写成了整机重新描述**，不是“只改一处”的编辑写法。一位真人与四次 AI 判读一致认为非目标部位大面积变化。第二版 E2 改用编辑写法。同一种子下每格各跑“整图编辑”与“遮罩编辑”两种，另加按点线图重新生成的对照，三者分开报告。
