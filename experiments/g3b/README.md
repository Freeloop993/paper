# G3b 改稿力度，离线准备

沿用 G3 已核的父图 S1-B1-T、种子 2026111101、40 步、1024²、相同顶视和呈现条件。G3 的父图通过参考编码分支输入。本批另外考察直接从父图的 VAE 潜变量开始采样。两种渠道可单独核对。[四份请求及父图摘要](manifest.json)

|配置|图像参考条件|去噪的起点|去噪值|文字|
|---|---|---|---:|---|
|i|有|原文图编码器的空白潜变量|1.0|按部位、改变、保持三项指定前摄嵌入与壳面收拢|
|ii|有|同一父图经 VAEEncode|0.8|G3 原修改句|
|iii|有|同 ii|0.65|G3 原修改句|
|iv|无|同 ii|0.8|G3 原修改句|

ii 与 iv 的负载均包含真实父图，两者仅在文字编码器的图像参考条件及输出名上有差异；ii 与 iii 仅改去噪及输出名。i 的直接对照是已生成的 G3 带父图条件。四个条件各一张，适用范围为这一父图与种子。

**兼容性证据。** 上批实际运行的 ComfyUI 源包 SHA-256 为 9277cf32e608a2fa72367e01a9f560070ca4050274a7df82aa447df9295159d0。已将本地 nodes.py 与包内字节比对。标准 VAEEncode 接收 IMAGE 与 VAE，把 vae.encode 的输出交给 LATENT.samples；KSampler 接收该 LATENT 及 denoise。ii—iv 由节点 15 的像素和原节点 3 的 VAE 接到节点 16，再接到采样器。核验器从锁定的 nodes.py 执行两个节点的原始包装代码，通过测试替身核对三个请求的实际传参。本机完整加载节点服务缺少 comfy_aimdo；新路径的带权重实机执行和画面效果均待测。[可复核的接口检查](check_backend.py)

**判据。** 两位独立 AI 各自对同一父图和匿名改稿先封存读数，人工到位时逐人追加。[评审表](reading.csv)对轮廓与肩部、上盖分件、臂根形式各记保持／改变／不可判。编辑项看可见的相机嵌入与壳面连续收拢，仅新增相机不足以满足。每位对每个配置计算已判保持项数；至少两项明确保持且修改明确可辨，记为该读者判可用。未知项保留。四个实际结果交齐后再按规格办理 X11；出现多候选或读者分歧时保留逐项结果，由协调方在正式采集前记录取舍。G3b 当前受托范围为离线准备。
