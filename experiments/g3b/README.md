**G3 真人反馈后的出图前用语修订。** AI 与真人使用同一组追问。先完成观察题，再完成目标题。保持项沿用原三项。

1. 对照原图，改稿里哪些部位有看得出的变化？请写出部位和看见的差别。也可以填写“未见变化”或“看不清”。回答记入 observed_changes_and_locations，供解释用。
2. 这次要求让前摄嵌入机鼻、周围壳面连续收向相机。对照原图，能否从改稿中看到这种过渡成形？选择“可辨／不可辨／不可判”，并指出依据所在的部位。壳体与相机的交界能显示上述过渡，记“可辨”；交界看得清、仍欠缺这种过渡，记“不可辨”；视角或遮挡使交界看不清，记“不可判”。判断与依据分别记入 camera_embedded_shell_tapers 和 integration_evidence。

筛选沿用“保持至少两项且目标修改可辨”。观察题只记录可见变化，看到新增零件本身不足以满足目标题。此前 G3 的选择按原题解释。这版问法的理解程度仍待后续使用核查。
