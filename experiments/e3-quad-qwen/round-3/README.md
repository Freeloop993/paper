## 为什么有第三轮

第二轮把作者说的“180°”误写成“所有桨水平成一直线”，结果内侧叶细短、B2/B3 单叶；作者更正：180° 指同一副桨两片叶之间的夹角，第一轮多数桨是对的，只是有的两叶夹成锐角。作者另指出第二轮 C 的相机“完全错误”。
