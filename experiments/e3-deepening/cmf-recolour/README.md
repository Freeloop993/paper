# 4.4 色材两档：低调—醒目（Claude，2026-11-15）

**两档都保留。** 作者在 #3 说“应该都有，而不只是去按照我的喜好”。L 与 H 作为同一锁定造型的两种配色进入终稿；哪一档更能传达“低调—醒目”，由 E5 独立评议判断，见 [E5 补充登记](../../../docs/protocols/e5-cmf-addendum.md)。

**设计意图。** “低调—醒目”只在色材上起作用（见第 3 章词对表），其余造型不变，两档之间只差功能色一项。醒目档的橙色只放在前臂和前电机上，起两个作用：飞行中从远处辨认机头，以及让设备在草地、沙地上容易找到。低调档去掉全部彩色，接近日常随身携带时“不显眼”的取向。

**做法（[recolour.py](recolour.py)）。** 橙环按色相 0.02–0.12、饱和度大于 0.35 识别。机臂走向取电机周围 45–130 像素内朝机身一侧的浅灰像素的平均方向，左前臂为 (0.789, −0.614)，右前臂为 (−0.785, −0.619)。换色时按原像素亮度缩放，保留明暗。

**已知不足。** 色带两侧的机臂边缘留有一圈原来的浅灰描边，没有一起换色；色带是纯色，没有材质纹理。若作者要碳纤维臂（材质档 M），只能用生成编辑，须走开发 3 张的流程，并在 #3 授权。
