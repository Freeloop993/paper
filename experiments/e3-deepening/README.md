# 4.4 方案深化：内容与方法（Claude 草案，2026-11-15，待作者定）

**前提：** 作者确认以 E3R3-B2 锁稿。确认之前，4.4 不出任何生成图。

## 一、原则

1. **循序渐进。** 一步只改一类：先形态细节，再色材，最后表达。每一步都留版本，作者选定后才进入下一步。依据是作者第三轮对 C1 的评语：“会不会循序渐进的修改，慢慢的才会加入这些cmf的碳钎维啥的”。
2. **确定方法优先。** 能用像素级可控的方法（拼合、按区域换色）完成的，就不用生成。生成只用在确定方法做不到的地方，例如材质纹理和透视表达。原因是今天的结果：只用文字的父图编辑 6 张里有 1 张改了机尾，加参考图的 3 张全部改了尾部（两次隔离 AI 盲读）。
3. **每一步都量非目标保持。** 和上一版逐像素比较，报告改动像素的比例与范围；生成步骤另做盲读。
4. **照常执行防错清单。** 新措辞先开发 3 张再正式；请求过 preflight；输入登记进白名单；GPU 批次由作者在 #3 授权，由 Codex 的调度器执行。

## 二、第一步：形态细节（4.4.1）

**相机（草案已交）。** 做法是人工拼合，详见 [camera-composite](camera-composite/README.md)。相机舱取自 v1.6 平行批 S16-S4。这一批从点线图生成，按“前伸云台”档的写法，4 张相机都在机头（知条件目测）。拼合后的改动像素只占 0.34%—0.38%，全部在机鼻框内，其余像素与 B2 相同。作者可以选 r01、r03、r04 中的一张，也可以提出修改，例如涂掉舱顶窄缝、缩小相机舱或加接触阴影。

**其他细节。** 第三轮作者对 B2 只提了相机一项，并认为它的分型线开始有设计感，因此其余部位不改。作者若还想加细节（如机臂末端指示灯、散热口、电池仓分件），逐项列出，每项按同样方法做，一次只改一项。

## 三、第二步：色材（4.4.2，“低调—醒目”在此进入）

| 档 | 内容 | 方法 |
|---|---|---|
| 低调 L | 保留现有浅灰壳臂、深灰电机、黑桨；电机的橙环改为深灰，全机只用中性色 | 按区域换色（确定方法，形状像素不变） |
| 醒目 H | 壳臂不变；功能色只用在辨识与安全部位：前两副电机环和前臂末端用信号橙，便于远处分辨机头，后两副用灰；相机舱保持深灰 | 按区域换色 |
| 材质 M（可选） | 机臂改为碳纤维纹理，壳体细磨砂 | 生成编辑（纹理只能靠生成）：只改材质的指令，开发 3 张，按“机臂纹理到位、改动范围外轮廓与锁定稿一致”判定 |

L 与 H 只差功能色一项，可以直接对比“低调—醒目”。M 只在作者想引入碳纤维时做。

## 四、第三步：表达（4.4.3）

同校四篇论文的最终方案多配以下几类图：最终设计方案图、细节展示图（邓家乐图 5.21—5.24）、产品效果图与使用场景图（何彦图 5.11—5.14）、逐轮方案效果图（厉茜茜图 6.9、6.13）。本文拟配：

1. **终稿正交顶视**：锁稿 + 相机 + 所选色材。
2. **细节展示**：从终稿裁取机头相机舱、臂根过渡、顶盖分型三处，注明放大倍数。
3. **便携（折叠状态）**：改折叠构型对生成模型风险大，建议用配置器按铰接点画折叠示意，或由作者手绘或建模。
4. **透视效果图**（3/4 视角）有两条路线，请作者选：
   - (a) 作者用 Rhino/KeyShot 建模渲染。这是工业设计论文的常规做法，细节可信。
   - (b) 用编辑通路由终稿顶视生成透视图，只作表达、不作证据，图注写明“模型生成、细节未经核对”。
5. **使用场景图**（可选）：随身携带、展开跟拍。
