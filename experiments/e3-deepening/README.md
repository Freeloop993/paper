# 4.4 方案深化：内容与方法（Claude 草案，2026-11-15，待作者定）

**2026-11-15 作者看图决定。** 第 4.4 节使用去窗、无相机舱的 B2 作深化父图；上下两版中，作者更偏好画面下端带相机的方案，作为后续深化起点。整机最终锁稿另记。第 4.3 节仍依原 B2 和当时约定解读。[父图、两版原图与逐步对照](end-comparison/README.md)

**机头方向。** 4.4 以画面下端为机头（作者选定），下文的“前”“后”都按这个方向。终稿表达图是否旋转 180° 让机头朝上，由作者决定。整机锁稿之前，4.4 不出任何生成图。

## 一、原则

1. **循序渐进。** 一步只改一类：先形态细节，再色材，最后表达。每一步都留版本，作者选定后才进入下一步。依据是作者第三轮对 C1 的评语：“会不会循序渐进的修改，慢慢的才会加入这些cmf的碳钎维啥的”。
2. **确定方法优先。** 能用像素级可控的方法（拼合、按区域换色）完成的，就不用生成。生成只用在确定方法做不到的地方，例如材质纹理和透视表达。原因是今天的结果：只用文字的父图编辑 6 张里有 1 张改了机尾，加参考图的 3 张全部改了尾部（两次隔离 AI 盲读）。
3. **每一步都量非目标保持。** 和上一版逐像素比较，报告改动像素的比例与范围；生成步骤另做盲读。
4. **照常执行防错清单。** 新措辞先开发 3 张再正式；请求过 preflight；输入登记进白名单；GPU 批次由作者在 #3 授权，由 Codex 的调度器执行。

## 二、第一步：形态细节（4.4.1）

**相机（作者已选下端安装，见 [end-comparison](end-comparison/README.md)）。** 做法是人工拼合，详见 [camera-composite](camera-composite/README.md)；我最初只做了上端安装的草案，是按实验约定预设了机头方向，Codex 补做了两端对照，作者据此选了下端。相机舱取自 v1.6 平行批 S16-S4。这一批从点线图生成，按“前伸云台”档的写法，4 张相机都在机头（知条件目测）。最初三个上端拼合稿的 0.34%—0.38% 使用灰度差大于 8 的统计口径。图 4.6 两端对照另按 RGB 任一通道变化逐像素计数：去窗底图相对原 B2 改动 1305 像素，上端与下端安装分别相对去窗底图改动 3286、3114 像素。[逐版记录](end-comparison/comparison.json)。两端对照在制作时统一取 r01 相机舱。作者看图后选的是下端安装方向；本次没有比较 r01 与 r02 或其他相机舱款式。舱顶窄缝按作者决定保留不涂（#3）；接触阴影已作为细节一完成，见 [detail-shadow](detail-shadow/README.md)。

**其他细节。** 第三轮作者对 B2 只提了相机一项，并认为它的分型线开始有设计感，因此其余部位不改。作者若还想加细节（如机臂末端指示灯、散热口、电池仓分件），逐项列出，每项按同样方法做，一次只改一项。

## 三、第二步：色材（4.4.2，“低调—醒目”在此进入）

| 档 | 内容 | 方法 |
|---|---|---|
| 低调 L | 保留现有浅灰壳臂、深灰电机、黑桨；电机的橙环改为深灰，全机只用中性色 | 按区域换色（确定方法，形状像素不变） |
| 醒目 H | 壳臂不变；功能色只用在辨识与安全部位：前两副（画面下方两副）电机环和前臂末端用信号橙，便于远处分辨机头，后两副用灰；相机舱保持深灰 | 按区域换色 |
| 材质 M（可选） | 机臂改为碳纤维纹理，壳体细磨砂 | 生成编辑（纹理只能靠生成）：只改材质的指令，开发 3 张，按“机臂纹理到位、改动范围外轮廓与锁定稿一致”判定 |

L 与 H 只差功能色一项，可以直接对比“低调—醒目”。两档草案已做，见 [cmf-recolour](cmf-recolour/README.md)。作者在 #3 说“应该都有，而不只是去按照我的喜好”：两档都保留为终稿的两种配色，哪一档更能传达意图由 E5 独立评议判断，见 [E5 补充登记](../../docs/protocols/e5-cmf-addendum.md)。M 只在作者想引入碳纤维时做。

## 四、第三步：表达（4.4.3）

同校四篇论文的最终方案多配以下几类图：最终设计方案图、细节展示图（邓家乐图 5.21—5.24）、产品效果图与使用场景图（何彦图 5.11—5.14）、逐轮方案效果图（厉茜茜图 6.9、6.13）。本文拟配：

1. **终稿正交顶视**：锁稿 + 相机 + 所选色材。
2. **细节展示**：从终稿裁取机头相机舱、臂根过渡、顶盖分型三处，注明放大倍数。

4. **透视效果图**（3/4 视角）有两条路线，请作者选：
   - (a) 作者用 Rhino/KeyShot 建模渲染。这是工业设计论文的常规做法，细节可信。
