# B2 相机：人工拼合草案（Claude，2026-11-15）

**状态：草案，待作者选定；未调用生成模型；不进入任何实验分母。**

B2 的相机经三次生成修订都未达到目标（4.3 节）：修订一 3 张、修订二文字版 3 张都露出朝向观察者的镜窗，双参考 3 张把相机放到了机尾。按登记规则，相机停止生成修订，转入 4.4 由人处理。

拼合所用的相机舱取自同日已经生成的 v1.6 平行批 S16-S4（“前伸云台”档，从点线图生成）。按知条件目测，这 4 张的相机舱都在机头，云台两侧有轴。放大后，舱顶前沿仍可见一条深色窄缝。正式读数以 Codex 安排的盲读为准。

## 做法（[composite.py](composite.py)）

1. 在 B2 机鼻顶面找出深色窗条，用正下方的壳面逐列向上填平。
2. 在 S16-S4 原图中，取机身壳面上缘以上、亮度低于壳面且与中心相连的相机舱像素。
3. 按两图机身宽度之比缩放，贴到 B2 机鼻前缘，只覆盖 B2 的背景像素，使机身压住相机舱下缘。

## 已知不足

- 舱顶前沿有一条深色窄缝。r03 的窄缝最明显，像镜头微微朝上；r01 的最小。若作者要求俯视完全看不到镜头，可以把窄缝涂成舱体灰色。
- 相机舱与机鼻的交界是硬边，没有接触阴影。
- 机鼻填平后，原窗条两端的分型线在顶端各留下一个小刻点。
