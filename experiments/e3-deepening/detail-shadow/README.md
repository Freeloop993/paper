# 4.4 细节一：相机舱接触阴影（Claude，2026-11-15）

作者 2026-11-15 在 #3 决定：舱顶窄缝保留不涂；接触阴影“可以作为下一步细节调整”。

**做法（[shadow.py](shadow.py)）。** 相机舱像素取 [B2-lower](../end-comparison/B2-lower.png) 与 [去窗底图](../end-comparison/B2-no-window.png) 之间的差异像素。对每一列，先找到机身壳缘在端部的最外一行；相机舱上离壳缘 d 像素处的颜色乘以 1 − 0.35·e^(−d/5)，模拟壳缘对云台上部的遮挡阴影。全程确定计算，没有调用生成。

**结果。** [B2-lower-shadow.png](B2-lower-shadow.png)，SHA-256 `5429224595f10dbe8220795b978d5abc5ba174a4a3d4de5fe365d021ca7f9f28`。按 RGB 任一通道有变化逐像素计数（与图 4.6 两端对照的口径相同），相对 B2-lower 改动 3028 个像素（0.29%），范围 x 452–562、y 673–716，全部在相机舱内；明显变暗的部分集中在靠近壳缘的十余像素内。阴影强度和衰减距离是参数，作者觉得太淡或太重都可以调。
