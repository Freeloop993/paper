# B2 配对评图（第 5.3 节补充研究）

三份答卷的内部编号均不同，六个选择的显示顺序、图像编号和所选图彼此一致。三人均同意参与，自述独自填写且事前未接触图像和相关判断。两人有设计背景，一人没有。一人认识研究者，三人均未报告参与方案设计。

| 比较 | 版本一 | 版本二 | 两张差不多 | 无法判断 | 缺答 |
|---|---|---|---:|---:|---:|
| 整机醒目感 | 含局部橙色 3 | 中性色 0 | 0 | 0 | 0 |
| 顶盖简洁感 | 原版、少两道横缝 3 | 人工增加两道横缝 0 | 0 | 0 | 0 |

三人均提及橙色，一人区分了醒目和好看。分件题的三份理由均涉及线条，一份评语明确认为差别很小。其单选仍是原顶盖，须保留两种信息。三份答卷均先评配色；橙色版在左两次、在右一次。这些结果只描述相同机身在并排比较时的选择。每题分母均为三人。不能套用原E5逐图七点评分的通过阈值或推断飞行辨向、审美偏好及总体效应。

问卷材料、版本核对键和汇总计数随稿归档，含逐人原文、答卷内部编号和填答时间的原始文件由研究者本地保存。
