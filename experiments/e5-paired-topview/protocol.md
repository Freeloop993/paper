# 第 5.3 节补充配对评图

只发单文件 HTML，个人独立打开、看图、导出 JSON。预览和设备测试答卷另放，勿计为研究数据。建议先收至少 3 份未接触相关判断的独立答卷；用于描述这两对图上的判断。若后续实施原附录 C 小图辨向与逐张七点评分，同一评者已看过本次材料，记录为既有接触。

配色用锁定 B2 两种版本。顶盖两版来自同一低调配色底图，在中央盖板已有边界之间用矢量绘制两道接缝，比较相对少分件与相对多分件。后者是为隔离因素制作的人工对照。两组均使用 1024 平方原尺寸，PNG 已去元数据。页端不显示研究者档位。顺序与位置独立随机，翻页、返回和同标签页刷新保留。原图、生成接缝的程序、逐像素差异和与答卷对应的编号在本目录。

收件后先按 response_id 对重发答卷去重，重复内容有变动时核对后保留相应版本，另留原件。以 image_1 和 image_2 解码原始选项；p 的预期是 H，q 的预期是 L。分别报告每组选择各图、两图差不多和无法判断的人数、依据原话，以及参与者背景、既有接触与独立填写情况。说不出依据与没有投票各自保留，不以答案排除参与者。共享底图、先后效应与局部放大皆需结合解读；各组不合成一个总分，原 E5 逐张量表的通过阈值不能挪用于此。
