# 文献资产及使用范围

| 集合 | 条目数 | 用途 |
|---|---:|---|
| [历史全文复核库](reviewed-100.csv) | 100 | 编号、题名、DOI、页数、原件摘要、历史核读和引用判定。按原记录保留其限定条件。 |
| [工业设计核心库](industrial-design-100.csv)及 [BibTeX](industrial-design.bib) | 100 | 作者、刊物、题名、来源和原 PDF 入口、章节映射。与上一表有 69 个相同文件摘要。 |
| [本地去重论文索引](archive-references.csv) | 467 | 历史归档中列入论文池的文件题名、集合、页数和原件摘要，用于找回更广的候选资料。 |
| [飞书文献库快照](feishu-100.csv) | 100 行 | 11 月 7 日读取的条目与附件名称，留原始空标题和重复记录。用行链接在原表回查。 |
| [Obsidian 项目卡片与核验笔记](obsidian-cards.csv) | 242 个笔记条目 | 用原编号、题名、既有状态及可提取的用途/限制定位材料。 |
| [新增台账](additions.csv)与[11月候选](november-candidates.json) | 7 / 4 | 记录追加文献的身份与当时阅读状态。 |

各表有重叠，统计时按研究问题、具体版本和 DOI/原件摘要复核。题名、卷期、章节与历史质量判定沿用相应日期的记录。论文论证优先从[R01–R14](../reading-map.md)追到具体版本与原页；材料收集范围包含背景和排除项。

本次从 472 份不同字节的可定位 PDF 检查了版权及作者许可页线索。保留明确载有适用于本研究共享的许可声明的 [102 份原件及逐件索引](licensed-files.csv)，原字节共 806,457,013 B。文件单列在同一私有库的 [reference-fulltexts-20261109 分支](https://github.com/Freeloop993/paper/tree/reference-fulltexts-20261109/fulltexts)，便于正文分支保持轻量。单文件超过上限的一篇提供无损分片，按该分支说明还原并核对摘要。没有核实到再分发许可的 PDF 以书目及已有的出版/原表入口提供；部分历史记录只有题名和摘要值。

[R01—R14 一键原文入口](priority-fulltexts.md)逐份标出文件版本、页数与完整摘要。
