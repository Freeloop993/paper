# 当前接手顺序

**跨设备交付约定。** Claude 在另一台电脑上工作。每次完成一批，交付者在 GitHub 留下版本固定的任务说明、输入及来源、逐项结果、脚本、判据、分母、结论与限制，并回读核验远端。已有大包可链接到已核对的原件，新增原件或答卷保留摘要。受限原文、未揭盲的对应键和参与者材料通过已有私有阅读库交付；评者只收到自己的题面。只有本机路径、聊天摘要或工具已跑通，均不足以让下一位研究者接手。若仍有材料只在本机，须逐项标出。

1. **Claude** 在[作者原配置器](../prototypes/drone-configurator/README.md)优化五页签交互，按[界面交接](../prototypes/drone-configurator/claude-interface-brief.md)演示一次从选择参数到导出图文的操作。
2. **Codex** 维护[实验索引](../STATUS.md)，交付[数据及复算材料](../evidence/20261117-research-update/README.md)。真实机型、生成图几何、需求语义分开处理。
3. **作者** 可分发 S2 的单文件盲态核查表；从[私有阅读库](https://github.com/Freeloop993/paper-reading-room)查收正式版本后，逐人发送专属题面。界面可用后按[配对预试材料](../evidence/20261117-research-update/method/paired-pilot.md)完成两种方式。事先做过设计的作者不计入三位正式设计者。
4. **论文交付** 当前为导师阅读版前三章。按[逐处核对清单](../evidence/20261117-research-update/method/chapters-1-3.md)修订语料、样本与变量定义。正式生成、招募和正文结论分别凭实绩登记。

任务与作者决定在[总清单](https://github.com/Freeloop993/paper/blob/b3b6fca0dfa1ebcf8f0a249c311330d8d2aae9d0/planning/2026-11-17-direction-and-todo.md)和[协作工单](https://github.com/Freeloop993/paper/issues/1)继续更新。以前的全局交接可在[整理前的固定版本](https://github.com/Freeloop993/paper/blob/6b22143c39f7bc0969b616f43704cb4d24a20310/docs/handoff.md)查到。
