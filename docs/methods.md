# 一次正式采集比较方案（讨论稿，未冻结）

**2026-11-12 六章执行入口**　[打开24项任务、逐节对照、思维导图及验收条件](../docs/execution-playbook.md)。语义编码、SD评分、参数条件、独立量测、D/S配对与终稿盲评各有操作和原件。


这不是启动授权。B02四旋方向已确认；样本量、两卡难度、实际边界、六旋子任务和付费未确认。P4布局/拓扑比较与P5人智协同的单位不同。

## 两种方法到底差什么

- D 强直接使用：真实设计师拿到完整简报、同款模型/工作台、相同原始参考与可用编辑工具，自拟、修改提示、检查、保留或放弃。允许写长提示、自制标记、复用前图；不故意削弱基线。
- S 结构化方法：在相同条件上，增加可编辑的“需求→部位→属性→保留项”记录和必要约束/自由造型标记，依次预览、判断、改或停。记录里填写了“保留”不代表图里真的保留。两边均由人选终稿，不由助手代操作或代判。
- 自变量是**整套工作方式**。不能从两组差异归因为单条提示词、自动检查或某一种控制图。两组获得同等训练、同一任务的全部需求和参考、同一视角/分辨率/后端及可用动作；若一组能局部改图而另一组只能重新生成，先修正对照，不能直接开跑。

## 3｜任务卡与实际操作（具体操作安排拟议）

共同简报 B02：个人日常外出航拍，四旋翼，紧凑、简洁、精整。保留四个旋翼、一体可辨的主体、连接与前部相机；主体轮廓、截面、表面语言由设计师决定，不指定八边形、品牌、色号、牌号或未经论证的尺寸。便携与简洁来自原评论；过渡及相机整合是设计者要检验的解释，不是用户给出的几何真值。

| 卡 | 给操作者的设计任务 | 两种方法共同的检查问题 |
|---|---|---|
| A | 做一个日常随行航拍概念。重点处理前部相机与机身体量的关系：能认出拍摄方向，又不像临时挂上一块附件。机臂连接仍须清楚。 | 人能指出视觉前端和相机吗？为突出相机，有没有破坏机臂连接或整机紧凑感？ |
| B | 同类日常航拍概念。重点处理机身到机臂的过渡：展开后是连贯的整体，而不是四根杆粘在壳上。前部相机仍须可辨。 | 能看清过渡关系吗？修臂根后，相机或必要旋翼是否丢失？ |

角色：操作者亲自完成设计；评议者只看同简报、匿名成图；几何复测者先独立标注再核对。卡A/B是平衡任务的草案，不是两条已获用户确认的需求；以中立说明先验明可理解性和难度，若明显不等价先修订。不要向评议者透露前一人的黑线判断或两组预期。

每场流程：作者确认简报版本 → 操作者写本场目标/保持项 → 产生初稿并保存原始输入、请求和图 → 人指出实际图上的问题，自行选择停止或指定一次修改 → 记录目标/保持项、真实操作与结果（真局部编辑、以上图作参考、重新采样三者必须区分） → 在看评议结果前，操作者锁定初稿、修改稿或“均不交”，记录理由。两组均可回选初稿；初稿已达要求不强迫制造无效修改。未发生修改的场次只能说明“选择停止”，不能证明修正有效。

## 4｜一次采集不是一张图：工作量及边界

按参与者做配对：一人做两个不同任务，每种方法一次。以下四种顺序按预先抽定的分配表成组使用：A-D→B-S，B-D→A-S，A-S→B-D，B-S→A-D。每个四人块中，各方法与任务的组合在前/后位都出现一次。两场间休息、不给对方组的答案；记录先后、工具熟练度和跨场学习，不能声称已消除学习效应。

建议**目标8位操作者、最低4位**，对应两块/一块完整顺序。这是配平与可行性规模，并非证明充分统计功效。每场拟≤20分钟（含活动和等待）、初稿1次＋可选修改至多1次。四人=8场/最多16次；八人=16场/最多32次。最低/目标分别最多160/320场内分钟；不是付费GPU时长或报价。新种子按任务配对、跨平衡块换新，开始前登记；不得使用S1看过结果的种子选赢家。S1已用的6次不算这里的新机会，也不能拿余额当授权。P4技术验证、准备、保留、缓冲要**另列并纳入总预算**，不得把32次写成全项目预算。

正式采集只组织一个已冻结批次，不边看结果边定人数、删人换人或增加轮次。若只能招到4位，以探索性配对描述为限；不满一块按设计案例和过程记录呈现。要做一般性优效推断，须在冻结前另定最小有意义差异、配对变异与精度/功效依据，不能用多图或多名评议者虚增操作者人数。

## 5｜视觉与布局用不同材料，不挑漂亮图改变分母

**正式造型评议**统一用能看清相机、机臂过渡和壳体厚度的斜前上视概念图，两种方法统一取景尺度、背景、光照和分辨率；允许不同造型语言。**参数验证**只在正交顶视/可核验的同一设计对象上量测。不同次独立生图不能冒充同一对象的多视图。若只有斜视，则只评可辨的必要构型，不能声称终稿还满足某个精确顶视参数；主张确需二者同一对象时，没有原型/多视图一致性证据就不启动相应比较。

**同一方案怎样对应两种视图。** 顶视骨架是开题第 6 页的参数设计入口。设计时修改目标轴位，复测时在输出图上独立点击可见电机转轴；每项保存目标值和实测值。现阶段验证问题集中在横向与前后轴位跨度之比。桨径还要桨尖或桨盘边界，臂角要有角度基准和臂方向，臂宽要有约定截面及两侧边界，机身长宽比要有机身边界；物理长度还需比例尺。用[同一组四轴目标的投影示意](figures/motor-centers-two-views.png)解释视角带来的缩短。示意使用已登记的 G2 输入点、共面正交投影，未对生成图估计相机姿态。

若某个深化案例要同时说明参数与造型，建议让同一版参数模型导出两张图：正交顶视复测轴位，固定斜前上视展示壳体、相机及臂根。保留模型版本、部件编号与两台相机的设置。若让生成模型进一步绘制造型，逐项记录可见轴心相对已知投影目标的位置偏差及遮挡；设计师在 CAD 中固定的尺寸只能支持该 CAD 方案。这个环节目前是待验证的案例路线。现有六张 GPT Image 斜视图只输入了文字，无法与某一组顶视目标建立这种对应关系。

分开记录两件事：①能否看清要评的部位；②看得清时设计得好不好。黑线、草图感、相机不协调不是自动删图理由；能判断就如实评分、记缺陷，确实遮挡就注明哪一项不可判定。所有尝试留原件，包括未选、无输出和未受理的不确定请求。视觉评议的终稿按操作者事先锁定的选择收取，不是研究者事后挑片。分析中并列报告全部尝试数/可判读数，以及每场最终候选；这两个分母不能互换。

**主指标候选：**场次是否同时满足需求贴合、设计质量、必要构型。自编评分拟分别保留吸引力、整体协调/完成度、任务契合、新颖性和是否值得深化；新颖不补偿其他门。正式阈值须用与正式样本分开的材料校准，分别规定人数下限、各项中位数、深化票多数、不同评议者意见不一致/缺项的处理，冻结后不改。首份S1答卷不能校准正式阈值，更不能拿来填新场次。盲评记录曝光，不宣称完全双盲。

以实际指派的参与者×任务为计划分母，区别未开始、无候选/已知失败、评议缺失和撤回（依同意条款处理，不保留不得保留的个人数据）。并列计划/实际覆盖；不交候选记未达成，不把评议缺失当满意或中性。对可依法纳入的场次，若总数n、已知达成k、未知u，报告界限[k/n,(k+u)/n]，分母为0则不算。方法差报告配对达成/未达成及不一致配对、任务和顺序；不足规模不作优效推断。修改效果另看目标是否改变、哪些保持项意外改变；同步报端到端耗时、主动操作/等待、调用机会和真实选择，不把节省点击当成质量提升。

## 6｜下一项技术验证与准入

P4候选变量仅一个：四旋翼展开布局的横向/纵向轴距比（无量纲），而非机身外轮廓。候选目的是允许设计师调布局时仍能自由处理机身，不从“便携”反推精确比值。先用离线构型验证多个输入水平在画布内且可区分；比值定义须与S1旧纵/横指标明确区分。对独立原图双人复测明确的电机转轴、遮挡、标记与前后，不用旋转/拉伸配准制造命中。作者旧8点校准只测已知圆心点击误差，不是成图轴心标注误差。下一版本须解释输入如何表示**轴心而非表面圆点**，不带默认机身轮廓。三个水平、重复数、新seed、容差和最小有用变化以任务需要与独立复测误差确定；没依据不扩样。未证实响应且概念仍不可用，收窄为方法失效边界或设计案例，不跳到P5优效主张。

开跑前缺一不可：作者确认B02及任务；相同工具可完成的人为初稿—修订—回退离线演练；不泄露方法的可判读材料；P4响应/质量所需证据；招募与院校伦理/同意核对；时间/请求/全费用上限另获授权；版本、种子、分配、分析和停止规则实际冻结。系统错误/OOM/请求状态未知/超时停后续、留痕，不自动重复计费。不能因为某张不好看临时补图。未达到正式研究规模时保留失败并缩小结论，不修改题名/目录或既有协议。
