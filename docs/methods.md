# 正式采集与方法比较（待冻结）

**2026-11-12 六章执行入口**　[打开24项任务、逐节对照、思维导图及验收条件](../docs/execution-playbook.md)。语义编码、SD评分、参数条件、独立量测、D/S配对与终稿盲评各有操作和原件。


依据[研究地基](foundation.md)第2、5、6节。以下为待执行方案；招募、伦理与费用由作者在 #3 登记。

## 两种方法到底差什么

- D 强直接使用：真实设计师拿到完整简报、同款模型/工作台、相同原始参考与可用编辑工具，自拟、修改提示、检查、保留或放弃。允许写长提示、自制标记、复用前图；不故意削弱基线。
- S 结构化方法：在相同条件上，增加可编辑的“需求→部位→属性→保留项”记录和必要约束/自由造型标记，依次预览、判断、改或停。记录里填写了“保留”不代表图里真的保留。两边均由人选终稿，不由助手代操作或代判。
- 自变量是**整套工作方式**。不能从两组差异归因为单条提示词、自动检查或某一种控制图。两组获得同等训练、同一任务的全部需求和参考、同一视角/分辨率/后端及可用动作；若一组能局部改图而另一组只能重新生成，先修正对照，不能直接开跑。

## 3｜任务卡与实际操作（具体操作安排拟议）

正式材料采用正交顶视。四旋重点为机身平面轮廓与比例、臂根过渡、机鼻（相机舱）前缘轮廓、分件线与配色分区。A卡调整机鼻前缘，保持臂根连接；B卡调整臂根过渡，保持机鼻端可判。两卡在同一简报中注明T05确定的词对目标，保留外形自由。

设计者亲自操作；独立评者只见统一顶视终稿与中立简报。A/B须先核措辞及难度。提前看过过程图者不能作独立终稿评者。

每场流程：作者确认简报版本 → 操作者写本场目标/保持项 → 产生初稿并保存原始输入、请求和图 → 人指出实际图上的问题，自行选择停止或指定一次修改 → 记录目标/保持项、真实操作与结果（真局部编辑、以上图作参考、重新采样三者必须区分） → 在看评议结果前，操作者锁定初稿、修改稿或“均不交”，记录理由。两组均可回选初稿；初稿已达要求不强迫制造无效修改。未发生修改的场次只能说明“选择停止”，不能证明修正有效。

## 4｜一次采集不是一张图：工作量及边界

按参与者做配对：一人做两个不同任务，每种方法一次。以下四种顺序按预先抽定的分配表成组使用：A-D→B-S，B-D→A-S，A-S→B-D，B-S→A-D。每个四人块中，各方法与任务的组合在前/后位都出现一次。两场间休息、不给对方组的答案；记录先后、工具熟练度和跨场学习，不能声称已消除学习效应。

设计者至少4人，目标6—8人，排除作者本人。培训10分钟，每场约25分钟，每人含休息与场后问卷共约75分钟。每场初稿1次、可选修订≤1次。费用和实际时间窗由作者另在 #3 确认。

E4只作配对描述。招募不足4人，改报作者案例加1—2人试用。每场锁稿后分别询问：你的设计意图表达到了什么程度？你对修改有多大控制感？完成任务的负担多大？下次是否愿意再用？还有什么想补充？前四题沿预先冻结的量尺逐项记录，第五题留自由意见。

## 5｜同一顶视材料的量测和评议

至少一位不知目标档位的助手在全部E0、E1、E6匿名原图上标注实体轴心及可见叶尖，封存后才揭盲。按同量纲独立读数估计误差，记录估计方法、覆盖及不可判；知条件 AI 初读单列。

独立评者先对8—10张真实产品顶视图作词对评分，再评E3、E4、E6锁定终稿。3.2的3—4组双极词写进3.3规格，原样用于5.3。四旋和植保六旋均以顶视可见部位为限，六旋喷头被挡可记不可判。仅4.4的一案表达可以附斜前上视，不进入量测或盲评。

分开记录两件事：①能否看清要评的部位；②看得清时设计得好不好。黑线、草图感、相机不协调不是自动删图理由；能判断就如实评分、记缺陷，确实遮挡就注明哪一项不可判定。所有尝试留原件，包括未选、无输出和未受理的不确定请求。视觉评议的终稿按操作者事先锁定的选择收取，不是研究者事后挑片。分析中并列报告全部尝试数/可判读数，以及每场最终候选；这两个分母不能互换。

r3逐项收词对评分、任务契合、协调和是否值得深化。阈值、缺项与跨评者聚合在评前冻结；至少3位独立评议者、目标5位，不足3位只报逐人原判。

以实际指派的参与者×任务为计划分母，区别未开始、无候选/已知失败、评议缺失和撤回（依同意条款处理，不保留不得保留的个人数据）。并列计划/实际覆盖；不交候选记未达成，不把评议缺失当满意或中性。对可依法纳入的场次，若总数n、已知达成k、未知u，报告界限[k/n,(k+u)/n]，分母为0则不算。方法差报告配对达成/未达成及不一致配对、任务和顺序；不足规模不作优效推断。修改效果另看目标是否改变、哪些保持项意外改变；同步报端到端耗时、主动操作/等待、调用机会和真实选择，不把节省点击当成质量提升。

## 6｜下一项技术验证与准入

E0、E1、E2依次开展，每步未过即停在对应工单报告。用同一顶视条件图和提示词，开源 Qwen-Image 2.1＋ControlNet Union、闭源 API 各做 W/L＝0.70、1.00、1.30，每档2次，共12张。逐臂报告四轴四桨可读率、W/L 档均值是否同向、是否像产品图。开源未达到可读且同向时停在本单，保留负结果，交作者裁定。

开源主线一次只改 W/L 或 d/D，各3档×4次，共24；同信息量的纯文字臂关闭 ControlNet，各3档×2次，共12。E1计划36张。d/D 三档须按桨盘不相交计算并在出图前登记。各因素档均值单调且相邻均值差大于独立读数误差的2倍。逐图±0.10命中率、同档四次离散分别报告。闭源只引用 E0 六张，计数归 E0。未通过写不可控或部分可控及适用条件，停止后续。

2张父图分别接受2种修改指令，另为每种指令做1张无父图对照，共6张。以实体部位可辨改动、三项保持项至少两项保持为判据。未过先停并回执；如后续获准开展 D/S，两组都仅用纯文字修订。

每个实验出图前另交冻结文件，写明单一改变因素、档位、每档次数、判据及不通过处置；记录实际模型标识、权重摘要或接口版本。原图、实际请求、失败和缺失按E号独立留档。禁止单张预试。 系统错误、OOM、未知或超时即停、不自动重试。
