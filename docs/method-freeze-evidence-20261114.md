# PR #68 第 2 节的实测填写依据

PR #70 已合并，方法冻结单第 2 节已按下表的开发证据填写。第三轮最初按 v2.1 回答两个登记问题；v2.2 要求每批核读全部通用项。[八图补读](../evidence/form342-h3-dev/round-3-common-v22/)独立归档。第 3 节待作者签署。

| 冻结项目 | 证据与建议写法 |
| --- | --- |
| 3.4.1、3.4.3 条件图 | 采用常规标记。第二轮的低对比图未通过预定比较；真实设计任务用轴心点线，几何响应的 E0/E1 用双叶部件图。常规 S0 250 mm 的轴心横跨 41%，按同一像素比例改变轴距时占比会变。 |
| 3.4.2 造型档位 | 以 v1.2 单项结果填写。第二轮机身方正、外露承座、折叠铰接、多块顶盖、前伸档达到各自开发门槛，S0 的无缝和单盖也达到。S0 无外突合并复测 4N/1P/2U，H3 判读不稳。单项达标不等于字典全通过。 |
| 紧凑—舒展 | 臂宽 W 未过。K 250/320 mm 仅为轴距探索；本轮标准差判据未过，维持三组语义目标中的设计讨论地位，正式 5.2.1 不加 K 两档。5.2.1 六个 S 条件与感知词对的独立验证分列。 |
| 读法 v2.1 | 机鼻 N/P/U、相机错位与遮挡分开；无缝/承座/铰接逐根判，颜色不能单独证明承座。开发轮盲态 AI 分母和正式评议分列。 |
| 初稿色材 | 第 3 节的通用同色约定加上作者例外。E3 设计的臂材质可用 v1.3 的同色哑光／外露碳纹；5.2.1 保持同色。外露碳纹在 C 上是可选设计材料。 |
| 下一步 | 作者待签署规格字段、词对与参数的对应、修订定义。签署后同一窗口核验实际环境，跑 E2 六份及 Qwen 造型小测十二份；后端选择、E3 与真实评议各按后续门槛执行。 |
