## B. E0—E2 技术冻结

每个实验出图前另交冻结文件，写明单一改变因素、档位、每档次数、判据及不通过处置；记录实际模型标识、权重摘要或接口版本。原图、实际请求、失败和缺失按E号独立留档。禁止单张预试。

| 实验 | 预定设计与判据 |
|---|---|
| E0 后端对照 | 用同一顶视条件图和提示词，开源 Qwen-Image 2.1＋ControlNet Union、闭源 API 各做 W/L＝0.70、1.00、1.30，每档2次，共12张。逐臂报告四轴四桨可读率、W/L 档均值是否同向、是否像产品图。开源未达到可读且同向时停在本单，保留负结果，交作者裁定。 |
| E1 参数响应与纯文字对照 | 开源主线一次只改 W/L 或 d/D，各3档×4次，共24；同信息量的纯文字臂关闭 ControlNet，各3档×2次，共12。E1计划36张。d/D 三档须按桨盘不相交计算并在出图前登记。各因素档均值单调且相邻均值差大于独立读数误差的2倍。逐图±0.10命中率、同档四次离散分别报告。闭源只引用 E0 六张，计数归 E0。未通过写不可控或部分可控及适用条件，停止后续。 |
| E2 父图修订能力 | 2张父图分别接受2种修改指令，另为每种指令做1张无父图对照，共6张。以实体部位可辨改动、三项保持项至少两项保持为判据。未过先停并回执；如后续获准开展 D/S，两组都仅用纯文字修订。 |

条件图用轴心＋双叶＋机架线、机体横跨约占画幅50%；画幅占比、中心偏移只作描述。至少一位不知目标档位的助手在全部E0、E1、E6匿名原图上标注实体轴心及可见叶尖，封存后才揭盲。按同量纲独立读数估计误差，记录估计方法、覆盖及不可判；知条件 AI 初读单列。

**逐实验待填：** 冻结版本、日期、唯一因素、各档与次数、固定项、种子或重复编号、后端标识/权重或API版本、实际输入摘要、误差估计、判据与失败处置、费用上限及授权链接、执行回执。
