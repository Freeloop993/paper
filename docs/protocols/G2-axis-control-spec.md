# G2 科学规格：空间控制能否让输出布局跟随输入（草案，待冻结）

**状态：** Claude 起草的研究设计，Codex 按 X03 实现离线请求与冻结包。**未授权提交**：任何模型调用须作者在 #3 批准 D6 中的 G2 额度（≤6 次）。冻结后不得因结果改变指标、阈值或水平。

## 1. 为什么要做

S1 两次独立 AI 读图均 0/6 达到轴位门槛（[复测](../../evidence/s1-axis-repeat/README.md)）。Claude 对首次读数做了相似变换分解（**事后探索，不改判 S1**；X02 负责用两次读数正式复算）：

| 图 | 质心 px | 输出/目标跨度（尺度） | 扣除尺度后残差 px |
|---|---|---:|---:|
| B1-T | (507, 506) | 1.358 | 4.6 |
| B1-L | (510, 508) | 1.311 | 6.5 |
| B1-F | (511, 506) | 1.239 | 10.3 |
| B2-T | (513, 480) | 1.238 | 17.1 |
| B2-L | (511, 487) | 1.205 | 26.5 |
| B2-F | (510, 484) | 1.190 | 18.3 |

读法：失败主要来自**均匀放大 1.19—1.36 倍**（模型倾向让机体填满画面），质心基本居中；两个种子块里尺度超出都按 T > L > F 递减。但 S1 的 L/F 路线**没有 ControlNet 节点**，而 S1 所有目标都是正方 X（比值 1），所以还不知道输出比值会不会随输入水平变化。新近发布的 Qwen-Image 2.1 Fun ControlNet Union（[N01](../literature-update-2026-11.md)）与现行后端同族，且对应开题第（2）项“ControlNet Canny/Lineart 强约束”的原文。

## 2. 研究问题与假设

- **G2-Q：** 在不约束机身外形的前提下，空间控制图能否让输出的相对轴位跨度比随输入水平单调变化，并落在容差内？
- **H1（主）：** 输出比值随 3 个输入水平单调变化，且每个水平 |r_o − r_t| ≤ 0.10。
- **H2（次）：** 空间控制使尺度超出小于 S1 同种子块的 T 路线（仅描述，S1 不是同期对照）。

## 3. 设计

| 项 | 规定 |
|---|---|
| 后端 | 现行 `qwen_image_2.1_bf16` ＋ Qwen-Image 2.1 Fun ControlNet Union；步数、采样器、CFG 沿用 S1 模板 |
| 控制图 | 1024×1024 白底黑线：只画 4 个旋翼桨盘圆与轴心十字，**不画机身、不画机臂**（机身与臂根是 B02 的设计自由与任务 B 的研究对象）。控制类型首选 Lineart，强度 1.0（发布说明口径），起止 0—1 |
| 自变量 | 相对轴位跨度比 r_t，3 档。**数值沿用 STATUS 已定义的四旋 3 档**，不在此重定；桨盘半径与总跨度按既有输入定义固定 |
| 视角 | 正交顶视（参数只在顶视量测）；斜视终稿不在 G2 范围 |
| 文本 | B02 简报＋顶视呈现句，三档完全相同；负向词沿用模板 |
| 重复 | 2 个新种子，事先登记，不复用 S1 种子；3 档×2 种子＝**6 次** |
| 缓存 | 每次请求须为采样器未命中缓存；命中缓存的结果不计入，也不补跑 |

## 4. 测量

- **读数：** 2 个互不继承上下文的 AI 会话＋至少 1 名人工（X06 工具），均在匿名随机编号的原图上先独立标 4 个轴心并封存，再揭盲。
- **主指标：** r_o（由轴心计算，定义与输入一致）；单调性；|r_o − r_t|。
- **次指标（只报告，不作门槛）：** 尺度 s（输出跨度/输入跨度）、质心偏移、原 S1 绝对坐标门结果、相似变换后残差、四轴可辨与连接可见性。
- **三种“精度”分列：** AI 读数一致性、人工与 AI 的差、对目标的偏差。生成图无外部真值，“真实几何精度”只以人工读数近似并注明。
- **设计可读性：** 每图记录机身是否出现、是否被控制图“画成圆环构件”等退化现象，供后续评议，不作 G2 门槛。

## 5. 判定与后续

| 结果 | 条件 | 后续 |
|---|---|---|
| 通过 | 两种子均单调，6 图均 \|r_o − r_t\| ≤ 0.10，四轴可辨 | 此控制路线进入共同对照（X05），并作为 D/S **两组同等可用**的可选控制层 |
| 部分 | 单调但有水平超容差，或仅一个种子单调 | 共同对照只报相对响应；RQ2 写“部分可控”及条件 |
| 失败 | 不单调，或≥2 图四轴不可辨 | 不再调参开新批；RQ2 收窄为失效边界；共同对照只报可控性描述。如需另试其他控制类型，另立批次、另行授权 |

**停止规则：** 系统错误、OOM、提交状态未知、超时即停后续，不自动重试；回读实例结束状态。软件可运行不等于 G2 通过。
