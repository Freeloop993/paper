## 3. 规格与修订的定义（待作者签署）

**一张规格卡由以下字段组成。** 方向由作者在 E3 里作为设计者填写；E4 的 S 组设计者用同一套字段。

| 字段 | 内容 |
|---|---|
| 使用任务 | 日常随行航拍四旋翼 |
| 词对目标 | 三组词对各自想靠近哪一极，或不作要求 |
| 造型档位 | 机身平面形、臂根过渡、机鼻外突、顶盖分件各选一档；机臂宽度若第二轮通过则一并选 |
| 构型（保持项） | 四电机 True X、W/L 1.00、对置轴距 250 mm、每轴静止双叶、5 英寸、无护圈 |
| 视图与相机（保持项） | 正交顶视、机头朝上；相机在机头端、镜头水平朝前 |
| 配色（保持项，初稿阶段） | 壳和臂同一浅灰、深灰电机、黑桨；配色从 4.4 起才改 |
| 自由项 | 壳面曲率、机臂截面、电机座、桨叶外形、分缝的具体走向 |
| 依据 | 支持该方向的证据卡号；属于设计者判断的写“设计者判断” |

**词对与参数的对应（随字典冻结）。**

| 词对 | 参数 | 若参数没通过 |
|---|---|---|
| 紧凑—舒展 | 机臂宽度（宽＝紧凑，细＝舒展）；机身长宽比只作描述量 | 只作 4.2.1 的组合展示，正文照实写 |
| 简洁—繁复 | 顶盖分件 | 同上 |
| 整体—拼凑 | 臂根过渡、机鼻外突 | 同上 |

**修订。** 修订就是改档位：以作者选中的那张图作父图，改一个或几个参数档位，用同一条通路重出。每次修订记录父图、改了哪个参数、原档与新档、为什么改、结果是否保住了其余部位。至多 2 次；作者可以在任一步停止，或回到任一版本。
