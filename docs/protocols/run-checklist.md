## 二、每一批出图前（缺一项不出图）

1. **输入血缘**：每张输入图在白名单内；父图写明“作者何时选了哪张”；旧批次重用要复核。
2. **措辞**：新的或改过的句子，先开发验证；作者评语的转译先回述。
3. **任务匹配**：四旋与六旋的正负提示词分开；负向词不得压掉该任务应有的部件。底图机头在画面下端（如 4.4 的 B2 深化稿）时，负向词不得带任何“tail”类词（preflight [6]）。
4. **预登记**：请求、种子、判据在出图前提交到 GitHub；同种子配对写明。
5. **打包与上传**：`COPYFILE_DISABLE=1`；服务器上 `python3 -B experiments/preflight.py …` 通过；文件数与摘要一致。
6. **调度**：只有 Codex 的调度器提交；Claude 不暂停、不并行提交。
7. **空转**：调度器停机时在 #1 留言；Claude 本地监视超过 15 分钟无新图即报告作者。
