# 正式采集材料包（草案 v0.1，供作者与伦理核查）

**用途：** D/S 正式采集（第5.4节）与独立评议（第5.3节）所需的对外材料与现场脚本。**状态：** Claude 起草的模板。人数、报酬、时间窗与伦理核查结论须由作者填写并确认；本文不构成伦理审批，也不是法律意见，须按所在院校规定核对。**启动前提：** G3b 与 X11 确定修订机制，冻结单 C、D、E 段实填。

> 我们正在研究设计师如何与图像生成工具协作完成产品造型。你将用一个本地网页工具，为“日常随行航拍四旋翼”完成两个短设计任务。

> - **方式：** 〔线下／远程〕；记录你在工具中的输入、选择和用时，不录制面部或声音。
> - **报酬：** 〔作者填写〕。
> - **自愿：** 可随时退出，退出不影响报酬〔按作者规定〕。
> - **数据：** 只以匿名编号用于研究与论文，原始记录保存在本地，不公开可识别信息。

## 2. 知情同意书要点（草案，须按院校模板改写）

1. 研究目的：比较两种使用图像生成工具进行造型设计的工作方式。
2. 你将做什么：两个任务各一次；每个任务先生成初稿，可选择修改一次，最后锁定你认可的一张或选择“均不提交”。
3. 记录内容：你输入的文字与结构化字段、生成的图像、版本选择与理由、各步骤时间戳；结束后两道简短问卷。
4. 风险与不适：预期为最低风险；如对任务或工具感到不适，可随时停止。
5. 保密：以随机编号保存，图像与文字可能以匿名形式出现在论文中；不记录姓名以外的身份信息，姓名与编号对照表单独保存〔作者确认保存期限〕。
6. 退出：任何时候可退出；退出前已产生的数据〔保留／删除〕按你的选择处理。
7. 评议：你的终稿可能由其他设计相关人员匿名评价，评价者不知道你是谁、用的是哪种方法。
8. 签署：参与者签名与日期；研究者签名与日期。

## 3. 场次脚本（主持人逐字使用）

**通用规则：** 两种方法的讲解时长、示例数量与语气相同；主持人不评价图像好坏，不提示“应该怎么写”，被问到时只复述任务卡。

**开场（统一，约 3 分钟）**
> 今天请你完成两个短任务。每个任务你先写下目标，生成一张初稿；看完后可以停止，也可以修改一次；最后锁定你认可的一张，或者选择都不提交。工具会记录你的输入和时间。没有标准答案，我们关心的是你实际怎么做决定。

**方法讲解（按分配表，只讲本场要用的方法，约 3 分钟）**
- **D 直接使用：** “请用你习惯的方式写提示词，可以写长写短，可以描述想改的地方。”
- **S 结构化：** “请分三栏写：要改的部位、想怎么改、哪些地方要保持。三栏都要填。”

**练习（统一，约 4 分钟）：** 用一张练习任务卡（与正式任务无关，例如“改变机身配色分区”）走一遍生成、修改、锁定的流程。练习结果不计入。

**正式任务（每场 ≤20 分钟）**
1. 发任务卡 A 或 B（按分配表）。
2. 参与者写本场目标与保持项（两组都写，作为过程记录）。
3. 生成初稿，等待计入时间。
4. 参与者决定停止或修改一次；修改须写明想改什么。
5. 锁定：选初稿、修改稿或“均不提交”，并写一句理由。
6. 到 20 分钟未锁定时，主持人提示还剩 2 分钟；超时记为“未锁定”，不延长。

**场次后问卷（每场，约 2 分钟）**
- 这个方案在多大程度上是“我的”设计？（1—7）
- 我对最终结果的控制感如何？（1—7）
- 这一场的脑力负担有多大？（1—7）
- 一句话：工具哪里帮到你，哪里妨碍你？

**两场之间：** 休息 2 分钟，不讨论上一场结果。

## 4. 任务卡

两张卡共用同一简报：个人日常外出航拍四旋翼，紧凑、简洁、精整；保留四个旋翼、一体可辨的机身、机臂连接与前置相机；机身轮廓、截面与表面语言由你决定。

- **任务 A：** 处理前置相机与机身的整合。要让人看得出拍摄方向，相机又不像临时挂上去的附件；机臂连接仍须清楚。
- **任务 B：** 处理机身到四臂的过渡。要让机身与机臂连成一个整体，而不是四根杆粘在壳上；前置相机仍须可辨。

## 5. 分配表

- 每 4 人为一块，四种顺序各一：A-D→B-S，B-D→A-S，A-S→B-D，B-S→A-D。
- 块内顺序由作者在招募前用随机数抽定并封存。抽签方法与结果入 `evidence/`，种子事先登记。
- 不按到场先后或能力调整分配；退出者不补位换人，按冻结规则计入分母。

## 6. 独立评议表

**评议者须知：** 你将看到若干匿名无人机概念图，以及同一份设计简报。请独立作答，不与他人讨论；看不清或无法判断时请选“不可判”。

**每张图先答观察题，再答评价题**（G3 真人反馈显示，“看到新增零件”与“达到设计目标”容易混淆，故分开）：

1. **观察：** 这张图里，机身、相机、机臂各是什么样子？写出你实际看到的。
2. **构型：** 图中是否画出了以下**实体部件**：四个旋翼（有桨叶或电机，不是圆圈、十字等线条标记）、一体机身、与机身相连且有粗细的机臂（不是细线）、前置相机？（每项：是／否／不可判）只有线条或符号、没有部件形体的，选“否”。
3. **细节充分性：** 这张图的细节够不够判断卡上的重点？（够／只够判断一部分／不够）
4. **任务契合：** 针对卡上的重点（A：相机与机身整合；B：机身到机臂过渡），是否达到要求？（1—7，并写依据所在部位）
5. **整体协调与完成度：** 比例、体量、部件关系是否协调完整？（1—7）
6. **外观吸引力：** （1—7）
7. **新颖性：** （1—7）
8. **是否推荐沿当前造型继续深化：** 是／否／不可判，一句理由。（第 3、8 题的分题来自 X12-r2，见[表单预读记录](../../evidence/x12-calibration/r2-return.md)。）

**锚点**（4、5、6、7 题共用）：1＝明显不成立或有严重问题；4＝可以接受但有明显不足；7＝出色，几乎无需修改。

**联合合格**（出图前冻结阈值，以下为建议）：第2题四项均为“是”，第3题不为“不够”，且第4、5题评议者中位数 ≥5。新颖性与吸引力单独报告，不进入联合合格。第3题为“不够”的图留在分母里，记为未知，不删除。

> **为什么加第3题这道门（11/10）：** 表单预读中，G2b-a 是一张控制图标记被照抄的失败输出（两位 AI 读者均判 0/4 轴心可定位）。同一位读者两次都把它的构型四项全选“是”，任务契合与协调完成度为 6/5 和 5/6，按原建议会判为联合合格；复填时该读者同时选了“细节不够”。这是一人两次作答，不作推断，只用于修订题目：构型题改问实体部件，并把细节充分性列为联合合格的前置条件。阈值仍须在斜前上视概念图校准批上试评后由作者冻结。

**风格稳定性评议（共同对照与六旋使用，D4）：** 对同一风格意图下的成对图，逐项判断“表面分件语言”“机臂—机身连接语言”“相机或载荷整合方式”是保持、改变还是不可判，并写出所在部位。

**评议者背景记录：** 设计背景与年限、与作者的关系、此前是否见过带条件标签的图。

## 7. 校准与盲法

- 阈值用校准材料先试评：现有六张历史图只作表单预读。另设 B02 纯文字斜前上视概念图校准批，首批计划 6 张，使用新种子，全批留存，和正式样本分开。按部位分别登记可判性，材料不足则不据此定阈值。S1 的那份正式答卷不得用于校准。
- 两种方法的正式造型终稿均用斜前上视，统一取景尺度、背景、光照与分辨率，随机编号，不显示方法、任务顺序与操作者。正交俯视另用于量测布局；不把另一张独立生成的图当作同一设计的第二视图。
- 考虑到渲染图会让人偏好常规、对称的方案（N07），评议须知中不提示“对称”或“常规”。
