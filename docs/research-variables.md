# 重做研究的变量与测量口径 · 2026-11-11

研究对象为设计师在给定多旋翼构型边界内对产品造型的表达与修订。设计任务、几何可控性与人智协同分别验证。下列新建议供正式采集前冻结；旧预试保留当时的输入、判据和分母。

## 每个问题实际改变什么

| 研究环节 | 主动改变 | 共同条件 | 观察与统计单位 |
|---|---|---|---|
| 3.2–3.3 需求转译 | 将评论或作者简报中的需求对应到部位、可变属性与保持项，由设计者确认 | 保存来源、采用理由和实际发送的文本，区分消费者原话、研究者解释与工程假设 | 每条需求能否追到证据与操作，保留冲突、未采用项 |

## 参数字典

| 参数 | 操作定义及角色 |
|---|---|
| 旋翼数与拓扑 | 本轮对象为单层、每轴一副桨的四旋与六旋。分别记电机数、旋翼盘数、实际机臂数。Y6、X8 等共轴构型另定义上下层；不从俯视重叠点推断个数。 |
| 机架构型 | 记录 X、十字、H、前后不等臂等布局族，并保存轴心坐标和连接图。同样四个轴位可以有不同的 H 形横梁或径向连接。购得或宣称的商品构型名本身不能确定坐标。 |
| 轴距与坐标 | 本研究把“轴距”操作化为任意两电机中心的**最大平面距离**。明确单位 mm、画布比例尺、机头方向；保存各中心的归一化坐标。设计原点为机架几何中心；实测重心另需质量数据。无尺度校准的生成图只报告画幅相对尺度。 |
| 相邻机臂夹角 | 在几何中心依机头标定的顺时针顺序，量相邻轴心射线的间隔；一圈合计 360°。输出中心选用机架中心或标明四点质心估计，不能混用。这个角不等于桨叶绕桨毂的分布角，也不等于电机安装倾角。 |
| 臂展比例 | 本文建议用 W/L，即电机轴心的左右跨度／前后跨度，排除桨尖。涉及现有代码中“前后／左右”时先取倒数。跨拓扑相对水平再除以该拓扑基准 W/L。 |
| 臂长 | 设计坐标的径向长度为机架中心到电机轴心；可见的实体臂长为臂根参考点到电机轴心，两种需分别标点。对称等长 X 架的径向长度随对置轴距确定。如要研究实体机臂长，须定义臂根点并固定或记录机身边界。 |
| 桨组构型 | 区分每副叶数、桨径、展开/收纳状态、是否共毂、共面/共轴、转向与安装倾角。当前四旋对照固定四电机 × 每桨三叶＝12 叶，完全展开，理想等分约 120°；实际图按可辨、明确不符、遮挡/不可判记录，不能补数。5 英寸、0°来自旧参数设置，用于几何推演；P03 发送文字未指定它们，后续若主张两组都控制了这两项，须共同明写并核对导出。 |
| 设计语义与工艺 | 显性目标按部位操作，如相机嵌入/外露、臂根从主体宽截面向臂段过渡、深浅色分件或哑光/高光表面。另记材料与工艺假设。装配分件缝与模具分型线是不同概念；壁厚、内筋、内部走线、材料牌号、加工参数和结构强度不能由效果图直接证明。机壳轮廓、截面、CMF 是否可变要按每道任务明确。 |
| 图像条件与评议 | 固定视角、机头、画布、比例、分辨率、照明、后端、模型身份、附图角色和修改次数。正交俯视测几何，补充产品视图读部件整合；独立生成的两视图不能自动当同一实体。生成图不是尺寸真值、空气动力学或制造性能测试。 |

## 四旋 X 架组合的几何复核

约定前侧张角为 α，相邻角交替为 α、180°−α、α、180°−α，四个电机同平面、到布局中心等距。设最大对置轴距 D，桨盘直径 d，则径向长度 r=D/2，W/L=tan(α/2)，最小桨盘净距为 D·sin(min(α,180°−α)/2)−d。换成前后不等臂、H 形、非共面或共轴时应由实际坐标与安装关系分别求解。正净距只说明理想二维桨盘未相交。

| 顺时针相邻角（°） | W/L | 最近两轴心距（mm） | 理想桨盘净距（mm） |
|---|---:|---:|---:|
| 90 / 90 / 90 / 90 | 1.000 | 176.78 | +49.78 |
| 75 / 105 / 75 / 105 | 0.767 | 152.19 | +25.19 |
| 60 / 120 / 60 / 120 | 0.577 | 125.00 | −2.00 |
| 45 / 135 / 45 / 135 | 0.414 | 95.67 | −31.33 |

表中 D=250 mm、d=5 英寸=127 mm。作者列出的最后一组 45/135/45/45 合计 270°；末行是按对称交替推定的候选修正，尚无依据称它是唯一解释或行业标准。在该桨径与轴距下，末两行仅作不相容例。若确需该角度，应在设计整批之前统一重选轴距或桨径，不能只为某一组改桨。

**建议的优先级。** 先用一个合法基准检查旋翼可读性，再做分档响应。若沿用既有候选横/纵相对跨度比 0.85、1.00、1.15，等长四旋 X 基准的对应前侧角约 80.73°、90°、97.98°，在上述二维假设下三档净距均为正。旧批的像素轴径、输入后端与任务不同，这里只是水平映射，不继承旧结果。一次只选角度或跨度比作为操纵量，另一个从坐标反算。跨构型共同条件与人评门槛在正式生成前单独冻结；两份应用任务的差异不能单独归因为旋翼数。
