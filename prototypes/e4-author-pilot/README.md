# C1 航拍四旋翼设计工作台

把同目录的 HTML、CSS、JS 和 reference.png 放在一起，用 Edge 或 Chrome 打开 [index.html](index.html) 即可试配。自由试配可点选机架构型、拖动轴距、比较相邻夹角，切换到「部件」和「色材」选机身、臂根、相机、分件与表面。机架示意、W/L 尺寸、夹角、实际导出图与完整提示词联动。「默认」「手选」「配置值」「任务固定」随规格保存。选择“留白”将该部位的未定事项写入提示词。当前覆盖日常随行航拍四旋。

配对预试可从右上入口打开。直接给设计者使用时打开 index.html?mode=study，按主持人分配选择两场顺序。两组的共同任务和参考图附在页内。S 在本页点选部件与色材、封存规格，已导出的兼容版本也可载入。S 沿用 250 mm、等角 X、红点与机架线的共同布局；自由试配可改变这些参数。D 由设计者直接撰写提示词，实际交接包只送原句。两组都可点选或补充目标、保持项和依据，自述缺失留空。设置、操作、选稿和交接分别留有记录。

主持人负责登记实际后端、实发请求、回执与返回图。每场计 15 分钟主动操作，最多封存 9 次，可回选此前收到的图。模型等待、人工交接、技术暂停按可取得的时间戳记录。旧浏览器中已封存的稿件与记录沿用其原设置。试配页被看过会在同标签页启动的预试中记录，正式场次宜用独立的参与者浏览器配置直接进入预试。

已通过本地 Edge 桌面与窄屏检查、两场模拟、旧文件导入、回选、计时核算与导出检查。浏览器测试使用模拟回执，无真人答卷及模型调用。作者完成双场预试、核实真实交接与计时后才进入三位外部设计者的配对场次。

## 复现

工作台可直接打开。E 盘主工程通过 [入口补丁](native-entry.patch) 接入，是独立的离线入口。[试配模块源码](native-source/src/design/c1Selection.ts) 与本轮使用的 E 盘编译模块同时保留。重建时在 native-source 下放入 public/c1-pilot/reference.png，安装 esbuild@0.25.4，执行 `node src/design/c1Bundle.mjs`，将 public/c1-pilot/selection.js 与本页放在同级。改样式请编辑 selection.css。宿主集成测试用 `node smoke.cjs <含 index.html 的目录>`，需要 Playwright Core 与 Edge，可在 PLAYWRIGHT_CORE 指定安装路径。
