# C1 作者预试工作台

从 E 盘配置器首页点“两种方法作者预试”。参与者在同一浏览器完成两场，选择分配的任务顺序。主持人填写同一后端标识。此页离线登记和导出，由主持人执行封存请求。源文件可与 index.html、style.css、session.js、reference.png 放在同一目录离线打开。

- **D 自由文字**　作者直接填写提示词。封存交接包只携带原句，图像列表为空。
- **S 配置器**　在 E 盘原应用选“四旋、部位规格 S、正俯视、文字与参考图”，确认后将导出的请求 JSON 载入此页。作者预试用相同任务布局，选红点与机架线，取消叶尖和方向标记。工作台复核实际提示词与输入图的摘要；若修订使用外观父图，只接受本场已返回的图。参与者看到的共同布局与实际送入后端的图像分别记载。
- 两组都写目标、保持项和依据，主持人交接包使用实际封存输入。每场主动操作 15 分钟，最多 9 个封存位置。已确认失败可继续，结果未知时保留记录并结束或回选。可锁定任何有返回图的尝试。
- 打开、阅读、编辑、审图和选择按工作台阶段计时。封存至回执呈现、技术暂停从主动时钟中扣除。提交、模型开始与结束时间依据真实回执填写。记录不足的子时段留空。主持人应在可展示原图时立即登记，否则“首次可见”有人工交接偏差。
- 两场均可导出 JSON，同一浏览器可恢复已封存记录，当前标签页刷新保留文本草稿；未封存的文件须重选。计时始于任务开始，离开需先点技术暂停。PNG 及回执由主持人据实填写。匿名编号即可。

**验收进度。** Edge 浏览器离线模拟已覆盖从 E 盘正常导出规格、S 导入图文摘要、D 纯文字、9 次上限、一次失败后继续、回选第 2 稿、暂停／刷新恢复、双场导出和计时核算。仍缺作者本人两场预试及实发后端的时钟、请求与回执核对，正式设计者场次 0。两种方式的差异包含图像输入与结构化填写两项，三人配对结果适于描述个体差异与使用过程。

## 在有 E 盘工程的设备复现

已在作者的 E 盘工程实际接入。另一台设备可在同版工程根目录应用 [入口与夹角输入补丁](native-entry.patch)，把本目录的 index.html、session.js、style.css、reference.png 放入 public/c1-pilot，再执行该工程的 build。回归脚本使用 Playwright Core 和 Edge，从构建后的配置器主页进入两种方法，生成的回执均为模拟记录。

```shell
node smoke.cjs <配置器的dist目录>
```
