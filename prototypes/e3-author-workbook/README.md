# E3 作者造型工作簿

在 E 盘配置器中打开“E3 作者规格与选稿”；单独下载本目录时，Windows 可双击 `start.cmd`，再在浏览器访问 http://127.0.0.1:8765/ 。页面从同一目录读取字典和已有图片，运行期间保留本地服务窗口。

先分别填写 A/B/C 的词对目标、依据和所选造型档位。九个位置可导入真实候选，并登记参考图、实发提示词和回执。待九张都写下取舍理由后，选一张作为父图；继续时记录修改参数、目标部位和保住的部分，最多两次修订，可回退或锁稿。用“下载工作簿”保存图像原字节、版本关系和理由，之后可重新导入。缺失证据记为“未核”。

“载入已有九张开发原图”只用于熟悉工作簿。原件、参考图和实发提示词已逐张对齐。其三轮 H3 开发图独立归档；正式 E3 的三方向各三张仍待后端确定和作者规格确认。此工作簿不提交生图任务。
