# E3 作者造型工作簿

## 打开

复制整个 e3-author-workbook 文件夹到本机。Windows 双击 start.cmd，再在 Chrome 或 Edge 中打开 http://127.0.0.1:8765/ 。需要本机已有 Python 3。macOS、Linux 或其他端口也可以在此目录运行下列命令，结束时按 Ctrl+C。

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

在原配置器的开发服务中也可打开 /research-guides/e3-author-workbook/ 。页面只读取本地附件，无需模型、账号、Node 安装或网络服务。工作簿保存在主动下载的 JSON 中。换电脑后启动同一页面，点“打开工作簿”选择文件。

## 一次作者操作

1. 在三个方向各填词对目标与依据卡号。依据来自个人判断时写明，缺失可写“未核”。选择部件档位，可查看本次编译文字。C 的臂材质可选同色哑光或外露碳纹。外露碳纹会更换固定 CMF 句。B 从 250 mm 开始，320 mm 留作可选工作档。
2. 进入“九图选稿”。点击“载入已有九张开发原图”可查看配置器历史开发归档 1A 至 3C，各方向三张。点击图片可下载原始文件。每格也可导入自己的 PNG/JPEG（每张上限 12 MB），登记来源、实发词、请求、种子、回执及实际参考图。缺失字段直接记“未核”。工作量较大时可随时下载已有进度。
3. 逐张写取舍，选一张作父图。此时三张规格卡、九份理由和九个图位固定。父图 SHA-256 由实际图片文件字节计算。历史图保留“历史开发图”身份；当前规格卡描述作者希望发展的方向。生成时的输入以各图实际回执为准。
4. 在“修订与锁稿”选择一个参数和新档位，填写理由及其余部位保留情况，附真实父图编辑后的图片，再按“记录修订”。每次记录含父版本、父图 SHA、子图 SHA、档位变化、编译词与实发证据。按回执填写实际编辑通路。最多两次，回退也保留历次事件和次数。选择“停止本轮”或填写理由后“锁定终稿”可结束。锁稿 SHA 供后续 E5 交接。
5. 点“下载工作簿”。导出含原图和实际参考图字节、三方向及各修订的规格和定位图快照、编译词、逐图实发词、父子链。载入时重算图片摘要并核对版本顺序。“记录修订”之前的临时修订表单不会进入导出。

## 实现与来源

- PR #69 的本地合并提交为 `0fe15ad`，依据 `docs/roadmap-20261114.md` 第 0、3 节。词句使用 round-2 的 v1.2 形态字典及 E3 v1.3 臂材质增量。
- form342-core.js 是原配置器 `src/design/design.ts` 的 layoutFor、drawGuide 和 `src/design/versions.ts` 的 imageAsset、download 的独立浏览器包。其余 HTML、CSS 和 JS 为可直接修改的 E3 源码。
- archive 取自 `Freeloop993/paper/evidence/section421-minimax-review/`。载入时按其 manifest 核九张原图文件 SHA、实际定位图 SHA，以及请求体中实发文字的 UTF-8 摘要。历史文本副本读取时统一 CRLF/LF 后与请求原文比对。历史实发文字不由当前方向的编译词推定。
- 结果只保存在当前内存和用户下载的 JSON。页面可核对文件字节、父子选择与记录一致性；手工填写的来源、原图是否确由所述请求生成、外部编辑是否真的使用指定父图，仍由作者对实际请求和回执核实。
