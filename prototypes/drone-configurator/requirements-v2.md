# 五页签配置器：优化后的界面需求（第一轮）

2026-11-17。本文在[最初的功能需求](original-design-brief.md)基础上，按[接手说明](claude-interface-brief.md)、[配置器研究方案](../../planning/configurator-research/README.md)和[独立复核](../../planning/configurator-research/independent-review.md)重写界面一侧的要求。每条后面注明本轮是否已经做到；实测结果见[交接报告](review/20261117-round1/README.md)。

## 1. 设计者在这里做什么

为日常随行航拍四旋翼准备一次概念设计的输入：选定构型和尺寸，看清展开状态下的顶视布局，核对将要发给模型的文字和点线图，然后导出。任务要交代清楚，造型决定留给人。

| 编号 | 要求 | 本轮 |
| --- | --- | --- |
| R1 | 保留机架、动力、机身、起落架、配件五个页签，以点选、色板、滑块和数值微调为主；自定义文字只用于补充委托或说明某次修改 | 已做 |
| R2 | 任何时候都看得到：当前选了什么、图和文字怎样随之改变、哪些造型决定仍然留白 | 已做（宽屏三栏同屏；窄屏示意吸顶，其余下滑可见） |
| R3 | 能中途改主意：单项清除、撤销上一步、全部重置；清除后回到默认值或留白 | 已做 |
| R4 | 模型服务停用时界面仍完整可用，并明确标出停用状态 | 已做 |

## 2. 每一项选择的四种状态

| 状态 | 含义 | 例子 |
| --- | --- | --- |
| 任务固定 | 本任务不变的条件，始终写入提示词 | 四个电机；展开正交顶视、机头朝上；相机朝机头前方 |
| 默认值 | 设计者还没动过，沿用程序缺省 | 对角轴距 250 mm、每轴 2 叶、不加护圈 |
| 你的选择 | 设计者明确选过或改过 | 构型改为宽 X、臂宽 20 mm |
| 留白 | 造型项尚未决定，不写入提示词 | 机身轮廓、顶盖分件、臂根过渡、机臂材料、相机安装、主色、表面处理 |

| 编号 | 要求 | 本轮 |
| --- | --- | --- |
| R5 | 每一项在页签、当前选择清单和导出里都带同一个状态 | 已做 |
| R6 | 造型项的缺省一律是留白；模板不得替设计者决定外形、颜色或材料 | 已做 |
| R7 | 护圈、颜色、碳纤维纹理只有在明确选择后才出现在提示词里；界面给出可核对的自检 | 已做（另有 864 种组合的自动扫描） |
| R8 | 用户画像不再用来推定颜色、材质或护圈 | 已做（主界面移除画像；旧代码保留未用） |

## 3. 几何：一组轴心驱动全部输出

| 编号 | 要求 | 本轮 |
| --- | --- | --- |
| R9 | 屏幕示意、相邻夹角、点线条件图、导出坐标和提示词布局句共用同一组轴心 | 已做 |
| R10 | 同一设计轴距下，真 X 与宽 X 的 W/L 不同，图、读数和导出都能看出来 | 已做（1.00 对 1.30） |
| R11 | Deadcat 显示并导出四个可辨轴心 | 已做 |
| R12 | 每种构型的画法写明依据；缺厂商或图面依据的标成设计者输入 | 已做（几何定义／实验档位／设计者输入三类） |
| R13 | D 的定义写在界面上：两条对角电机中心距的均值；同时给出任意两轴最大距 | 已做 |
| R14 | W/L 可以单独调（宽 X、伸展 X、H 型），刻度上标出实验档位和图面量测值作对照 | 已做 |
| R15 | 桨盘重叠、机身盖住电机等明显不合理的组合给出提示，但不拦截 | 已做 |
| R16 | 按相邻夹角直接输入布局（桌面版曾有） | 未做，留待后续 |

| R17 | 航拍相机朝机头前方；镜片不得画在机背上 | 已做（提示词有固定句，示意图只在机鼻处标位置） |
| R18 | 顶视可被遮挡的部件要让设计者知道“它在、只是看不见” | 已做：顶视用虚线标出相机和起落架位置，可切换「只看顶视可见」；另有侧视示意画出相机视线、机身高度、机臂厚度和离地高度 |

## 5. 需求依据与设计意图

| 编号 | 要求 | 本轮 |
| --- | --- | --- |

## 8. 本轮没有纳入、需要另行安排的事项

1. 父图登记（图号、机头端、改哪个部位、保留什么）和候选并排比较。
2. 三种文本的一致性提示（编译原文、设计者改后的文本、实发文本）与版本链。
3. 尝试编号、计时、请求回执等配对试验所需的记录。
4. 农业植保六旋翼入口。状态里保留了六轴几何，五页签界面本轮只做四旋。
5. 机身宽/D 的单因素条件图（是否需要宽度标记，见独立复核第 2 条）。
6. 相邻夹角直接输入。
