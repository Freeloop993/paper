# 界面设计说明

2026-11-18。这一版从作者原来的页面重新出发：保留它的样子和用法（顶栏、白色卡片、蓝色强调、五个页签、左边调参数右边看预览、一页往下滚），在此之上只加研究真正用得到的东西。上一轮把来源、状态和核对信息全部摊在页面上，三栏各自滚动，字小、标签多，比原版难用；这一版把这些收了回去。

## 这个界面在研究里做什么

论文的方法是一条线：设计者把想法整理成规格，配置器把规格变成条件图和文字，模型出图，设计者再取舍和修订。配置器负责前两步，对应第 3 章的意图转译与参数表达、第 4 章 4.1 的应用原型。

它的使用者有两种：作者自己做方案；以及配对试验里的外部设计者，每场只有 15 分钟主动操作时间。所以首要标准是第一次打开就能上手，其次才是信息完整。

## 页面顺序就是方法顺序

| 页面区块 | 论文里对应的环节 | 设计取舍 |
| --- | --- | --- |
| ① 设计意图 | 3.3.1 词对目标；3.2 证据卡 | 词对做成一按即选的两端按钮，可以都不选。评论依据放进侧边抽屉，平时不占地方。原版的“用户画像”会替设计者带入颜色和材质，不再使用 |
| ② 部件参数（五个页签） | 3.4.2 构型变量与造型档位 | 页签、滑块和原版一致。每个页签上半是尺寸与构型，下半是“造型（可以不指定）”。造型项的名称和档位取自论文表3.6 与附录 A |
| 预览 | 3.4.1 布局表达；3.4.3 条件图 | 顶视是论文量测和评议用的视图，所以是默认视图。「条件图」直接显示将要导出的那张图。四个比例是研究关心的工程量：W/L、桨径 ÷ 轴距、机身宽 ÷ 轴距、机身长 ÷ 宽 |
| ③ 确认与导出 | 3.3.3 规格的人工确认；3.5.1 条件输入 | 配对试验约定结构化一组“实发已确认的文字与参考图”，所以导出前有一处集中核对：左边文字，右边规格卡 |
| 造型规格卡 | 3.3.2 表3.5 | 字段按论文规格卡排列：使用任务、设计意图与依据、构型、已定造型、自由项 |

## 几个具体问题的处理

**俯视看不到的相机。** 航拍相机朝机头前方，俯视时被机鼻挡住。顶视示意在机鼻处用紫色虚线和朝前的箭头标出它；「侧视」画出相机、视线、机身高度、机臂厚度和起落架。相机怎样安装由设计者选，或不指定。提示词里有固定的一句说明镜头朝前、机背不出现镜片。

**不把外形锁死。** 机身只给长宽高。轮廓不指定时，示意图只画斜线虚框；条件图里始终没有机身。不指定的造型项不写进提示词，在规格卡里列为“自由项”。

**“紧凑”怎么落地。** 用户评论里说得最多的是小巧和便携。界面允许把“紧凑”选为意图，并在「机身」页把机身宽 ÷ 轴距、机身长 ÷ 宽摆在滑块旁边，方便尝试。是否真的显得紧凑要靠出图后的评议，界面上只写到这一步。

**数值从哪里来。** 滑块下方的小按钮是研究登记的实验档（W/L 0.70／1.00／1.30，轴距 250 mm）。真实机型的数值收在参数名旁边的 ⓘ 里，点开才显示，并注明是手册图面量测的便利样本。

**改了什么能看见。** 预览下方有一行“刚才：……”，可一步撤销；提示词里刚改动的句子标黄。逐句来源和模板检查默认收起。

## 收起来或拿掉的东西

| 上一轮放在页面上的 | 现在 |
| --- | --- |
| 每个参数旁的状态标签和可见性标签 | 拿掉。改过的参数显示「重置」；看不到的部件在说明里提一句“可在侧视里查看” |
| 25 行的“当前选择”清单 | 换成规格卡 |
| 带前后对照的大块改动说明、模板自检 | 换成一行“刚才”和标黄；自检收进「逐句来源」 |
| 三栏各自滚动 | 一页往下滚，预览随页面停留 |
| 展开在页面里的证据卡面板 | 侧边抽屉 |
| 刻度线上的厂商值、量测值图例 | 收进 ⓘ |

这些信息没有丢：每项选择的状态、数值来源、证据卡的采纳记录、提示词逐句来源和模板检查结果都在导出的规格 JSON 里。

## 这一版没有做的

父图登记与候选并排比较；尝试编号、计时与回执；编译原文、改后文本与实发文本的比较；植保六旋入口；按相邻夹角输入布局。这些都要等模型服务接入或配对试验的记录约定落实后再做。
