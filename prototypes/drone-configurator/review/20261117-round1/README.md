## 二、照着做一遍（复现步骤）

用解压后的离线包或 `npm run dev` 均可。每一步后点页头的「导出三件」。

1. 打开页面。点「查看需求依据」，在搜索框输入“小巧”，只剩 E001 一张卡，可看到原话、对象、状态和限定。
2. 点 E001 的「采纳为依据」→「撤销采纳」→再点「采纳为依据」。每次看「依据」一行和「刚才的改动」：参数与示意图都不变。
3. 在「由你提出目标」里点「紧凑」。提示词新增第 2 句。导出，记为 01。
4. 点示意图上方的「记为对照」，在「机架」页签点「宽 X 型」。导出，记为 02。
5. 点「Deadcat 型」。数一下示意图里的红点是否四个，各在什么位置。导出，记为 03。
6. 臂宽点「10 mm」，导出，记为 04；再点「20 mm」，导出，记为 05。
7. 把 E001「撤销采纳」，导出，记为 06。
8. 点「全部重置」，搜索框改成“防水”，出现“没有匹配的证据卡”；在「自己写的意图」里写一句话，导出，记为 07。

留存的导出件就是这八步的结果。Codex 复做后，可以把自己的导出目录交给 `python3 crosscheck.py`（把文件按步骤放进 `exports/`）或 `npm run replay <目录>` 比对。

### 4. 模板有没有加入未选的护圈、颜色、碳纹

七份导出的提示词全文里都没有。检索方式有三处：界面自检、导出 JSON 里的 `template_audit`、`crosscheck.py` 对 TXT 全文的独立正则检索。“No propeller guards.”是任务缺省的否定句；描述随附点线图的那一句含 red、blue，指的是图上的点和线，不计入。另在 864 种选择组合上自动扫描：三者只在对应选项被选中时出现（`npm run verify`）。

接手时的旧提示词在同样条件下带有 “aerodynamic propeller guards for safety”、“brushless motors with propeller guards”、固定的 “carbon fiber arms” 和缺省色号 `#8a9095`，臂宽 10 与 20 的文字完全相同。本轮实测复现过这些问题后才改。

## 四、还没有验证、或者需要人来确认的

**没有验证的。**

1. **真人使用。** 没有任何设计者用过这版界面。是否“随时看得清”只是我对照截图的判断。
2. **模型响应。** 提示词和点线图没有发给任何模型。臂宽写进了文字，不代表生成图会变；论文 4.1.3 节记过，写入文字的臂宽在早先试验中没有体现在图上。
3. **真实下载。** 应用内置浏览器不落盘下载文件。留存的导出件是在点击「导出三件」时截取页面生成的原始字节得到的。请在普通浏览器里实际点一次导出。
4. **「自己写意图」按钮。** 点击后光标确实落在输入框里，但自动化紧接着的输入没有写进去；直接点输入框再输入是正常的。需要人手试一次。
5. **截图不是录屏。** 截图由脚本把留存的配置读回离线包后拍摄，其中“刚才的改动”是脚本重放的同一项改动。实际操作过程的依据是各步的 `screen.json`。
6. **其他环境。** 只在 macOS 的 Chrome 158 上跑过。Windows、Edge、Firefox、Safari 和触屏都没有试。
7. **无障碍。** 只加了基本的角色与标签，没有做读屏或键盘走查。

**我替作者先定下、需要确认的。**

| 决定 | 我的选择 | 备选与影响 |
| --- | --- | --- |
| 设计轴距 D 的定义 | 两条对角电机中心距的均值，另导出最大两轴距 | 桌面版按最大两轴距缩放。Deadcat 上两者不同：D 均值 250 时最大距 257.68；按最大距 250 时均值 242.55（与研究方案所记一致） |
| 宽 X、伸展 X 的缺省 W/L | 1.30 与 0.70，即研究登记的宽、窄档，可调 | 桌面版用 ±58° 与 ±32°，相当于 1.60 与 0.62，没有出处 |
| 条件图尺度 | D 归一到 600 px，与已登记条件图相同 | 桌面版是固定的每毫米像素数；归一后改轴距不移动条件图里的轴心 |
| 提示词文字 | 新写的一套英文句子，短语取自附录 A 的 v1.6，但去掉了开头的 compact、相机句里的颜色词和固定配色句 | 这不是 E3 用过的字典。正式出图前需要作者审这份文字并另行冻结 |
| 用户画像 | 从主界面和提示词里移除 | 旧画像会带入黑灰配色、碳纹和护圈 |
| 造型项缺省 | 全部留白（原先材料缺省为碳纤维，主色有缺省值） | — |
| 起落架缺省 | 保留作者原来的“低矮滑撬/支腿，40 mm”，标为默认值 | 消费航拍机多数没有独立起落架，是否改缺省由作者定 |
| 目标词对 | 论文表3.4 的四组，不排先后 | 作者尚未确认把“紧凑”调为首要目标 |

**本轮没有做的。** 父图登记与候选并排比较；三种文本的一致性提示与版本链；配对试验的计时与回执；植保六旋入口；机身宽/D 的单因素条件图；按相邻夹角输入。清单见[需求 v2 第 8 节](../../requirements-v2.md)。
