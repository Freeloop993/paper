# E4 四旋翼 D/S 离线工作台

双击 `index.html`，用 Edge 或 Chrome 打开。静态文件可以整目录复制，无需构建或本地服务器。此包供软件演练，内含一张既有布局参考，所有新记录标为 `offline_rehearsal`。

## 一次配对演练

1. 主持人填演练编号、已分配的顺序、共同后端标识与时限。支持协议的四种 A/B、D/S 顺序。第一场结束后再开始第二场，两场间隔由主持人掌握。
2. 两组看到相同的任务简报、对应任务卡和同一份参考 PNG。D 用一个自由文字框。S 选机身平面形、臂根、机鼻、顶盖与臂材质，并登记词对目标、部位、保持项与依据。S 封存的 JSON 保留参数原值、语义记录和源字典编译文本，选外露碳纹时改用相应 CMF 句。
3. 封存输入后，可下载本次输入 JSON 与原图交给外部操作者。封存只记录一次机会，本页不调用后端。操作者可登记实际回执号或原件定位、脱敏回执说明、实发请求位置、实际操作和服务时间。成功须关联回执定位和返回 PNG，软件记录其摘要、尺寸与原字节。失败、结果未知和确认未调用分别登记。未取得依据的调用数保留未知，实际后端缺失时保留空值。
4. 初稿成功后可锁定、放弃或修订一次。两组可查看同一场自己的初稿、回选初稿或均不提交；失败、未知仍占已封存的位置。锁定时填写理由，超过共同截止时间记为未锁定。截止时已有请求在外等待，可补记这一位置的回执。场后填写原五题，第五题可留空。
5. 已封存的步骤自动存在该浏览器的 IndexedDB。刷新可恢复。尚在编辑框中的内容到封存、保存或锁定才写入。每场可随时导出当前场 JSON，两场结束可导出完整配对记录（含登记的 PNG）。两个交付目录各有相同源码，浏览器对不同文件路径的本地存储处理可能不同，整次演练请用同一入口。

## 记录口径

- `sealed`、`recorded` 分别是本地封存输入和登记回执的时刻。外部服务的开始、结束只在有原件时抄录。确认调用数来自操作者登记，文件封存次数单独统计。任何回执未登记或次数未知时，`totalCalls` 为 null。
- `elapsedToDecisionMs` 从开场到锁定、均不交或超时，含等待；场后问卷另记时间。`handoffToEntryMs` 是该窗口内从封存到回执登记的间隔，含人工交接，不等同服务端执行时间。`nonWaitingToDecisionMs` 为其余时段，不是键鼠活跃时长。
- 问卷逐字来自采集协议。前四题复用主持人在开始时填入的冻结档位，两场相同。协议所引条文未列具体刻度；未提供时存原始回答，不赋数值或推断评分。第五题空白存 null。
