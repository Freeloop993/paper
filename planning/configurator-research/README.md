# E 盘配置器与论文研究方案

本方案供设计者、开发者及论文复核者共同使用。以 11 月 17 日方向分支的 5b94644 为本次核对点。核对了作者开题第 6–7 页、Claude 的方向清单与 #1、E 盘早期汇报图 3–5、主程序及旧检索服务、已有读数和 C1 演练入口。下文的界面及实验改动均为工作安排，逐项写明已有材料。

## 本研究要回答的问题

为日常随行航拍四旋翼设计一张展开正交顶视概念图。在匹配的委托、相同后端和设计机会下，采用结构化配置与直接提示词，各要多久才出现第一张技术达标图？两种方式锁定的终稿，各自能否传达事先声明的外观意图，并维持规定的几何？两次判定各自绑定图号。四旋为主例。农业植保六旋用于探查方法适用范围，观察药箱、喷洒部件与六轴机架的关系。B2 单独作为设计深化成果。

需要沿同一设计尝试回答三个问题。① 实际生成图中的几何是否达标。② 隐去方法和目标标签后，评者感受到的紧凑程度及造型协调性如何。③ 为获得第一个达标候选，设计者操作了多久、尝试了几次，最终交付哪张图。能追溯决定是系统功能；能判断设计流程相对收益需要真人配对试验。

## RAG 的位置与边界

旧项目提供了从评论片段建索引、根据参数查询并给提示词提供上下文的实现。E 盘 design_filtered_comments.json 实测含 5,614 个非空片段、3,603 个不同的非空 comment_id。旧 loader 将评论 ID、商品描述、片段类型和片段序号保存为元数据，查询设置里 top_k 为 3。当前 Python 初始化关闭，initialize/query/context 三个接口返回 503，五页签主界面的生图按钮也停用。旧服务包含把检索片段送文本模型改写的代码。历史文件存在只能说明当时设计了这项能力。早期汇报中的画像比例属于展示材料。

建议的第一版把检索放在设计简报旁，平时折叠，点击“查看需求依据”才显示。默认优先展示已经审读、与机体造型有关的证据卡，并显示来源编号、原意、商品和使用情境、适用及限定条件。设计者选“采用为目标”或忽略，自定的目标也可以保留。机型比例范围另从厂商规格与合格顶视量测取得。以“小巧，方便携带”为例，人可以将它转为“展开时看起来紧凑”，再比较两档机身宽/D；证据卡本身给不出比例数值，更不能替设计者指定机壳形状。六旋的药箱和喷洒部件需要对应植保资料。

先离线对账，确认旧片段 ID、商品范围和片段文本能否连到已审读的 228 条及证据卡。存稳定对应键、版本、来源和冲突，无法唯一对应的保留待核。旧检索的相似度表示匹配程度；候选排序或召回次数不代表需求权重。对返还依据的检查应包括命中同一任务及部位、同一评论尽量不重复、玩具/配件排除、原文确实支持建议，以及没有合适证据时允许空结果。比较设计方式时，两组共用同一版本需求简报；哪些检索和改写在场内可用须在预试前写入两臂协议。第一版可以直接显示已核卡片；动态检索经验证后再进入工作流。

### 旧库与现用证据的实际对账

源码还显示，旧上下文接口最多发前三条查询，每条只带回首个来源片段。loader 把原片段写在 source_part，而接口拼接“原始评论”时读取 source_comment_part；前端送进改写器时又只保留片段内容。恢复服务前应让每条证据从检索到 UI 都带同一个证据键，保留对象、商品、状态和原句定位；相同字段用同一接口约定。检索应优先按设计任务和部位查证据，避免先由“摄影爱好者”推定颜色或用途、再搜索支持这一推定的评论。

在本机将旧库的原评论片段字段与 7,443 条结案文本逐条比对。旧 comment_id 和结案表的 text_id、original_record_ids 直接交集均为 0。只去首尾空白，228 条保留文本中有 1 条匹配；统一兼容字符（NFKC）并去掉空白后，有 109 条匹配，另 119 条未匹配。按后一规则，全部 7,443 条中有 3,480 条找到候选。匹配的单位是文本，有相同文本的商品与来源仍需核对。这次没有测检索的召回率或排序准确率。[复算代码](check_rag_sources.py) · [两种口径的汇总](rag-source-counts.json)

共享仓库已有 36 张公开证据卡，其中 15 张来自旧资料、21 张来自补充材料，和 228 条的分母不同。例如 E003–E005 讨论 Neo 2 与包、口袋的适配；界面应显示其对象及使用条件，允许设计者据此选择随身携带的设计任务。要判断展开时的视觉紧凑感，应交给匹配比例图与盲评。具体机身宽/D 数值应引用实测档案并标出算式。用户研究、工程设计判断和设计结果因此各有可核对的凭据。[公开证据卡及限制字段](https://github.com/Freeloop993/paper/blob/5b94644db936f81b40bb2ec8672721dce570c26f/evidence/semantic-cards/cards.csv)

## 操作、记录与验收顺序

1. **坐标和文本**。沿现有布局函数核对所有构型，再接入主预览与下载。比较等宽和宽 X 的实值并反读 PNG。导出的提示词只改布局，手选的 CMF 保持一致，留白项由设计者保留。默认双叶是本次航拍任务条件。顶视可遮挡前视镜片，能判的端位和不能判的朝向分记录。
2. **证据到决策**。做一条可还原的操作记录，从证据卡编号、采纳/拒绝、目标、参数来源和数值，追到参考图版本、已确认文字、实发请求，再追到原图和读数；未采纳也可继续设计。新接入一个模型时，先验证送出的文字、图及实际工作流与确认件一致。开发失败和分母全部保留。
3. **路线确认**。A3/A8 离线复测和测量校准、A2 真机范围 → A4 开发 → 冻结方法、档位、容差、失败处理、校准函数 → A5 新种子确认。A4 草案至多 24 **次调用**，包含两段法的中间图，与最终设计图数分别登记。已发布的容差与历史结果保持原口径，不能看到确认结果后逐张修到命中。
4. **回图与回退**。按同一目标追踪原图、放大细节、修改后与锁稿图。独立分判目标是否改变、其余部位是否保持。若通过后处理保证遮罩外不变，计入工具效果。父图和最终成果按版本标注，六旋单列可行性记录。
5. **公平比较与解释**。作者先实际完成两种方式；每人每场 15 分钟主动操作、至多 9 次机会，分开计主动操作、转交和模型等待。全场多图作为同一位设计者的重复尝试。场次从简报开始，首次达标按预先规定的盲判回溯到回图时间，限时未达也进分母。另报终稿是否达标、盲评紧凑感和造型协调性。三对数据报告逐人差值、任务和先后顺序，作为小样本设计实践证据。

## 独立复核后补入的开发验收

1. **统一量纲与轴距定义。** 四旋的机身宽/D 与 d/D 主读数采用两条对角轴距的均值，六旋类比取三对对置轴距的均值。另存任意两轴最大距、对置轴距最大值及厂商口径。设计控件如按最大两轴距缩放，应明确显示并同时导出均值。Deadcat 示例中最大两轴距 250 mm，平均对角距约 242.55 mm。T20 同一组点按平均或最大对置轴距所得 d/D 为 0.495 或 0.451。旧数据按对应口径保留，新批在出图前冻结分母、趋势和容差。相邻档为 0.10 时，应检验“恒定 0.50”这个反例。0.70/1.00/1.30 是 W/L 实验探测档；首批 6 款图面量测中四旋仅 4 款，不足以称为行业典型范围。
2. **增加机身宽/D 的单因素开发，先做离线输入验证。** 当前点线图只定位轴心、连接线和可选叶尖，A4 位置表只改 W/L。先固定四轴、旋翼、机身长度、画幅、视角和 CMF，分别编译两档机身宽/D；优先检验原点线图加明确宽度文字。若文字不足，另登记疏松宽度提示（如左右两个范围标记），不指定外壳轮廓；有可见标记时检查是否残留到输出。核对规范化输入，并在同种子配对回图上独立量机身宽和轴距。记录壳体边界不可判、比例未变、比例确实变动但未被读作紧凑三种情况。A5 的机身比例确认以这项开发的结果为依赖，新增模型调用另行登记。
3. **从正常主界面检验控件。** 真 X/宽 X 在同一设计轴距下测出不同 W/L；Deadcat 输出四个可辨轴心；机臂宽从 10 改到 20 mm 时，显示、JSON 和模型实际接收的指令体现这一差别。五页签的最终提示词目前漏掉 arm_width_mm。固定项、默认、明确选择和自由项贯穿同一参数记录。
4. **确定正式场次到底测什么。** 当前 C1 将两组固定为 250 mm 等角 X，只能开展固定布局下的机鼻/臂根试做。为回答整套设计系统的问题，先将两张匹配任务卡都加上可实际调整和量测的比例目标，采用同样的技术达标定义。在正式紧凑感任务中，两种方法收到同一目标一极；自由试配仍允许其他意图。每次设计机会区分候选数、实发调用数、内部中间图和实际可见时间。当前演练包成功回执只接受一次调用；选用两段法时须先验证一张候选两次调用及中途失败的存档。保留完整候选和退出记录，分别报告 3 人的配对表现及顺序。

一次试做用同一个尝试编号关联“任务版本 → 人选的目标与依据 → 设计值/自由项 → 实发文字、参考图摘要与模型版本 → 返回时间及原图摘要 → 匿名量测 → 人的保留/回退/接手 → 锁稿图号”。输入轴心是目标，屏幕与导出图共用它；输出轴心要在返回图上重新测。选择器、几何导出、返回图、判读与计时分别有依据时，该尝试可以从头复核。当前恢复版主程序还没有跑出这样一条实机记录。

配对试验拟在两组的同一份简报提供相同需求依据，两组均从首次显示简报开始计时。交互式检索先用于任务准备，若正式场内只开放给 S，应记录为整套系统的一部分。默认独立计两个结果：所有尝试盲判几何和任务部位，据此回算首次技术达标；终稿另由独立真人评价紧凑感与协调性。只有对每次候选都有按同一标准取得的语义判定，才可计算“首张同时技术与语义合格的用时”。没有匹配评价的尝试保留缺失。对未达标的配对报告截止时间、尝试数与结局，不能用零分钟或只统计成功者。
