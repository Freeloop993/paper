# 文献来源对账与方法依据

把一项研究写进论文时，先按研究问题找到对应的动作，再从记录回到作者原页。第三章可从评论需求整理、证据检索和带出处的回答入手。第四章用真实操作和版本记录研究部件编辑及方案取舍。第五章要在实际回图上量测、独立评价，并检验方法换到另一构型后的适用范围。

## 如何使用资料

| 想查什么 | 文件及其口径 |
| --- | --- |
| 全部来源中哪些值得跟进 | [逐项相关性导航](relevance-index.csv)的 790 行包括旧导航的 775 行及此次首次匹配到的 15 项。标题匹配生成的“阅读路线”仅用于分流。能否引用要读同一行的证据来源、具体判断和页码。其中 642 行仍只有目录来源，包含 1 行需排除的内部记录。 |
| 搜索会话推荐了哪些，同一篇是否重复 | [来源对照](reference-crosswalk.csv)以“来源中的一项”为单位。两轮正式阅读清单有 11＋10 项。另有 18 份留存初筛 PDF，其中 3 份与正式清单中的 ArchiSet、Make It Count、SketchConcept 字节相同。其余 15 项中，IdeaBlocks 和 Hybrid Layout Control 命中旧导航，另 13 项此前未匹配。搜索引擎曾展示且未被留存或入选的页面不在该数内。 |

## 与论文方法如何衔接

| 环节 | 原文实际支持的做法 | 本研究的操作与待检验之处 |
| --- | --- | --- |
| 把用户原话整理成有条件的证据 | 航拍机研究区分功能与感性需求，再通过专家判断建立需求到特征的对应。参阅 W0001、A08；评论语义抽取另见 W0018。[历史方法卡](../../advisor-20261118/literature/method-cards.csv) | 分开存原话、对象、折叠或展开状态、研究者解释与待验证的造型假设。给出想要“塞进小包”的评论时，应能查出收纳需求。把它换成某个机身宽度需工程资料及后续量测。 |
| 检索与生成各自留痕 | Lewis 等区分外部可检索知识、检索模块和条件生成。所读论文图 1 与第 2 节给出了查询、返回文段及生成之间的数据通路。[NeurIPS 2020 原文](https://papers.neurips.cc/paper_files/paper/2020/file/6b493230205f780e1bc26945df7481e5-Paper.pdf#page=2) | 对每次查询存储适用条件、检索版本、返回的证据 ID；有生成时额外保留真正发给生成器的 ID 和应答引用。仅检索模式可单独测试。 |
| 检索结果有可比较的基线 | BEIR 将语料、查询和相关性判断统一，使用包括 BM25 在内的多种检索方法比较排序结果。参阅第 3.3–4 节。[BEIR 原文](https://datasets-benchmarks-proceedings.neurips.cc/paper_files/paper/2021/file/65b9eea6e1cc6bb9f0cd2a47751a186f-Paper-round2.pdf#page=5) | 先固定匿名来源和题目分组。对有证据题核 top-k 是否命中并排在前面；对模糊题核是否追问，对无证据题核是否错误引入建议。逐题列出失败情形。 |
| 回答中的每一项引文能回查 | ALCE 分开评估答案陈述有无引文支持，以及列出的每一项引文是否相关，另有人工逐句对照。见第 3.3 节、图 3 及第 6 节。[ACL 原文](https://aclanthology.org/2023.emnlp-main.398.pdf#page=4) | 对有模型回复的条件，逐条看“这句话由哪张卡支撑”“同一句混入了哪些无依据的尺寸或偏好”。研究者提出的假设需标明身份，待真实生成保存相应记录后评估。 |
| 设计者限定局部、保留和拒绝建议 | IdeaBlocks 把属性、探索方向和范围做成可重复使用的单元；DesignTrace、GenAlign 又提供设计历史及部件属性的实现先例。见 KB-S03 及 A03、B00。[IdeaBlocks 作者版](https://arxiv.org/pdf/2507.22163v4#page=7) | 用户先确认目标和部件，预览改动后再采纳、拒绝或撤回，系统记录决定理由和对应规格。是否降低操作负担应用真实场次检验。 |
| 回图分别检验目标变化和非目标保持 | Kim 等在图 2、4 展示固定相似度与上下文评判的差异。查 KB-S07 和 SR-Edit 的 A06 原页。[CVPR 原文](https://openaccess.thecvf.com/content/CVPR2025/papers/Kim_Preserve_or_Modify_Context-Aware_Evaluation_for_Balancing_Preservation_and_Modification_CVPR_2025_paper.pdf#page=5) | 用同一中性任务先比平面四旋与平面六旋，分别记录目标改变、非目标保持和可判性。独立量测与独立感知评议分开。通用图像编辑论文没有提供多旋翼比例阈值。 |

18 项补查记录中，5 项可限定用于方法论，13 项保留为背景。Lewis 已在 W0759 建过历史卡；这里补查了检索与生成的分工。若扩展到更大模型、向量索引或重排器，需要另行比较质量与成本。Treellis、Req2CAD 仍缺本地可核的对应 PDF，资料库保留作者项目页和 DOI。搜索会话中的系统描述、历史目录和检索排序本身，都不能充当本项目实验效果。
