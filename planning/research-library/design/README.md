**如何检索。** 例如问「小包收纳能推出多宽的机身」，应先检索折叠状态与对应证据。D-C-MINI4 给出整机外包络的一个实例；机身主体宽度和实际包内可用尺寸要另行提供。问「六旋是否都要有药箱」，可并列 D-C-T20 与 D-C-H520E，查到农业和工业检查各自的任务背景。与审美或效率有关的问题，应回到匿名评议与配对记录。来源字段与取舍记录用于说明证据适用的范围。

**来源复核。** A1 沿用 11 月 17 日台账中登记的来源层级，保留此前仅从厂商网页存档转录的情况。2026 年 11 月 18 日对 A1 和 A2 的 31 个不同登记入口测试了连接与文件前缀。29 个返回 PDF 或 HTML，Autel 商城当时限流，Nileworks 手册地址遇到 TLS 错误。DJI Neo 系列尺寸另指向台账列出的正式规格页。地址可访问只表明可追索，原页复读范围以上表选读项为准。S900 与 T20 等手册采用已归档 PDF 重新渲染核图，没有复制厂商图片。

**量测如何复算。** 对已知机头方向的手册图，将所有轴心沿机身纵向及其正交方向投影，以两个方向的最大值减去最小值，计算 W/L。T30 的机头朝图左，直接对图片宽高作除法会交换结果。用于试填的两张工作台展示件另记图像横纵跨度，只说明该位图如何读，不能直接作实物正顶标定或独立评议。用 Python 3.10+ 在项目根目录运行以下命令，可逐条复算 15 套坐标、核对两张展示件的文件摘要，检查卡号和来源字段。

~~~sh
python planning/research-library/design/verify_design.py
~~~

本轮新增人体场次、独立读者和模型调用均为 0。既有角度图、历史回图和产品手册各保留自己的材料类型。一个型号码可以有多个状态卡，一张图也可以出现于数张方法卡。
