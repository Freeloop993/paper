## 实验路线与参与角色

1. **研究依据和离线复核。** 准备语义文献与数据、构型资料、模型输入、四旋与六旋原件以及盲态取点材料。按来源分别记录作者决定、软件走查、模型真实执行、独立 AI 和真人判读。
2. **系统实现与验收。** Claude 在 PR #75 或后继版本实现[系统规格](system.md)。Codex 用同一提交的源码、正常界面及实际导出验收。冻结系统版本、输入词典和评分协议；后续更改记录影响的场次。
3. **作者真实预试。** 沿用[两份既有任务简报和计时约定](../../evidence/20261117-research-update/method/paired-pilot.md)。同一后端、可比任务和资源上限；结构化和自由提示各完成一场。每场至多 9 张、主动操作 15 分钟，单列人工交接与等待。保留候选全表、时间事件、回执及作者取舍。运行失败的场次保留实际状态。
4. **四旋主研究与六旋应用。** 完成实际设计路线的独立复测、局部编辑的目标/保持分项评价；作者完成 B2 三视图或简模、主要尺寸、折叠和色材。六旋应用复用已有记录并补方法与真人抽判。C3、感知评议和新增构型试验分别报告。
5. **同条件跨构型探索。** 先用统一中性简报和四旋参照，预先冻结任务、输入通路、视角、模型、配对种子和判读方式。计每种条件的计划位置、提交、实收、不可判、构型正确、变成四旋、其他错误。共轴加同方案的侧/斜视及同视角对照，保留顶视本身看不到的层。四个种子的探索只作描述；八旋宽长比深度批须在预试中确认可读、尺度稳定，并单独登记。新增视图、补跑和复用基准分别计数，GPU 预算以真实计时和作者决定为准。
6. **数据核验后写全文。** 对应研究问题逐项核对成功、反例、缺失、独立性和作者决策。数据不足的环节按实际范围收束。结果为负也完成相应研究问题；未开展的环节单列。
