## 一、一页结论

**题目要证明的事。** 设计者能把用户语义和工程比例写成一份可编辑的规格，生成结果在这些参数上可量测、可判读，设计者在有边界的修订中掌握取舍，最终方案能被不知情的人读出设计意图；与自由提示相比，这套做法有可量化的收益或代价。

## 二、论文主线

### 2.1 研究问题与论证链

论证是一条链，每个研究问题检验其中一环：

```
用户评论 ──(RQ1)──> 规格（语义词对 + 工程比例 + 造型档位）
                       │
                       ├──(RQ2a)──> 布局比例是否命中        量测
                       ├──(RQ2b)──> 造型档位是否出现        判读
                       └──(RQ2c)──> 修订是否改对且保住其余   判读
                                         │
                            设计者取舍、回退、人工完成（第四章）
                                         │
                       ┌──(RQ3)──> 与自由提示相比的时间、合格率、质量（E4）
                       └──(RQ1′)─> 不知情的评议者能否读出设计意图（E5）
六旋翼（RQ4）只做可行性探测：同一流程换一种构型，哪些环节仍然成立。
```

研究问题保持现有四问，但每一问对应的证据要改成上图的一环一证。现在的第五章按实验编号排，读者看不出哪个实验检验哪一环；重写时按环节排。

### 2.2 贡献（正面写，三条）

1. **方法：一份把用户语义与工程比例放在同一张规格里的参数化生成流程。** 配置器把规格编译成条件图与固定短语，每一次生成都能追溯到规格、输入和种子。与 Chen 等（2026）同样从评论出发的航拍无人机研究相比，本文多了两件事：工程比例进入条件图并在输出上量测；修订有边界、有回退记录。
2. **实证：两条生成通路对工程比例的服从程度不同，而且偏差有方向。** 部件图经 ControlNet 时，布局比例几乎原样传递；参考图编辑通路只做到同向响应，偏离目标的方向朝着真实产品的比例（见 2.3）。这条结论对设计者有直接用处：要精确比例，得用哪条通路、付出什么代价。
3. **评价协议与设计证据：** 把“目标是否改对”“其余是否保住”“是否看得见”分开检验，判读者档案与读数误差可查；在此协议下给出一个完整的四旋设计案例，以及 3 名外部设计者的配对对照结果。

第 3 条的后半部分取决于 E4 与 D1 是否完成。若 E4 结果是“没有差别”，同样可以写，只是贡献表述改为“效果与代价”。

**最接近工作的比较** 写进 2.6 节，用一张逐维度比较表（输入、控制方式、评价、人的角色），候选文献见文献补充文件。

### 2.3 一个新发现：模型的布局偏差朝向真实产品

Codex 11 月 17 日在 10 款消费四旋的厂商手册顶视图上量了 W/L（展开态、机头朝上的横纵轴心跨度比，单次知情读数）：

| 来源 | W/L |
|---|---|
| 真实消费四旋（10 款） | 1.16—1.52，中位约 1.39 |
| 本文实验档位 | 0.70、1.00、1.30 |
| 设计规格（E3、B2） | 1.00 |
| 点线图通路的实际输出（36 张） | 目标 0.70 → 约 0.98—1.03；目标 1.00 → 约 1.11—1.16；目标 1.30 → 约 1.28—1.36 |
| E3 设计稿（27 张，目标 1.00） | 中位约 1.07—1.13，14/27 在 ±0.10 内 |

真实产品没有一款接近 0.70，也没有接近 1.00 的；模型在目标偏离常见比例时往宽处偏。可以检验的解释是：**编辑通路的布局受模型先验约束，目标落在真实产品范围内时命中，落在范围外时被拉回。** 这比“窄档失败”更有信息量，也给出了改进办法：

- 档位按真实产品的分布重新设定，例如 1.15、1.35、1.55（具体数待 A2 扩样后定）【待议 Q2】；
- 布局桥接（A4）同时试“目标在范围内”和“目标在范围外”两种情形，直接检验这个解释；
- 设计规格里的 W/L 1.00 是否有意为之，要在第四章说明理由，否则改为真实范围内的值【待议 Q2】。

### 2.4 “紧凑”是语义与工程接上的地方

- 评论里最主要的诉求是小巧（228 条中 43%）、便携（29%）、轻（21%）；第二编码中“紧凑—舒展”的一致性也最高（κ＝0.60）。
- 8 款实拍的紧凑感评分有明显差别：Neo、Neo 2 中位 2（偏紧凑），Air 3 中位 6（偏舒展）。这说明紧凑感读得出来，而且随产品变化。
- 已量到的 3 款中，机身宽与对角轴距之比（PV02）Neo 0.234、Mavic 3 Pro 0.211、Air 3 0.208，方向与紧凑感评分一致，但 3 个点不能下结论。

所以“紧凑”有可能用比例参数表达：机身宽与对角轴距之比、机身长宽比、d/D。检验分两步：真实产品上看比例与紧凑感评分是否相关（S5 第一步，需要更多机型与评议者）；生成图上只改比例，看评议者是否觉得更紧凑（S5 第二步）。【待议 Q1：是否把“紧凑”恢复为首要语义目标】
