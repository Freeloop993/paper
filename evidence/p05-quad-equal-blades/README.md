## 本次单张验证

日常随行航拍四旋，方形轴位、250 mm 对置轴距、5 英寸双叶桨、0° 安装倾角、正交俯视。E 盘配置器使用现有轴位为每副桨计算两个相反方向、半径 63.5 mm 的叶尖点，方向垂直于机架中心指向桨毂的连线。八个青色叶尖与四个红色轴心均由配置器按同一比例尺导出。桨形的共同要求写明等半径和对应叶宽一致，机身轮廓与臂根曲面由模型设计。真实调用为对话内置生图一次。
