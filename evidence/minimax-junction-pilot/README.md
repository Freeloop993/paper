## 回查 #19 和 PR #66

[#19 留言](https://github.com/Freeloop993/paper/issues/19#issuecomment-6843041348)所说的 0 张是当时的文档交接状态。到 [#66 的 519821e](https://github.com/Freeloop993/paper/tree/519821e830f3223e73bc9cbea598f314b4a58081/evidence/p2-spec-cards)，MiniMax 已完成 P2 首轮 9 张。A-2 机头朝下；A-3、C-3 可见多余桨叶。A-1 与 B-1 的机鼻轮廓有宽窄差别，仅凭那条弧线不足以把两种相机安装方式区分开。C-1 的夹持座与分缝清楚，独立方形前模块很容易读作另一块盖板。P2 仓库中有匿名映射，未见完成的独立答卷。历史 G3 的一份真人答卷另有归属。

- **文字和评分遗漏。** A、B 都要求舱藏在鼻内、臂根无接缝，共用开头还把 B 也写成 compact。A 的原 P 条目不检查相机，B 只查宽度与臂长。出现“轴位准、机身窄”并不能给相机舱或臂根得分。三处应分别登记可见／相反／不可判，保留 P2 原判据。
- **参考图与参数。** P2 的输入是同色背景上宽 24 px 的 X 和半径 24 px 的圆座；它给了臂宽与端座的视觉线索。提示末尾 `No text, lines or markings` 与前面的接缝要求有歧义。固定双叶文字未保住所有叶数；请求与图均没有叶尖位置或桨径数值，规格表的 d/D 没有完整传给模型。P2 写的 127/250 实为 0.508。新探索用 125/250 明示 0.50；这是本批的取值。
- **用户早期提示。** 按“X 构型、角度和跨度、机身、材料、部件、照明”依次编写是可复用的写法。80 cm 曲率、30 cm 轴距等属于输入意图，单幅渲染不能验证实物毫米数。以前共同检查过的同一张并排图，本次重新收到且 SHA 相同。蜂窝格栅、顶置天线和 LED 固定进三案会引入另一个设计任务。四旋任务仍是日常随行航拍，正式视图为正交顶视。
- **方向草案本身。** C 同时改变外壳、分件、臂根与相机，且同时改变两组词对。能归类到 C 不能证明是哪个部位或哪组语义起作用。B、C 的若干取值来自设计者提案。P1 确有 T2/G5 两个参数化预设，欠缺的是围绕本任务的完整设计证据。

## 能量到哪一步

**B 的两次局部修订。** 同一父图、完全相同的编辑请求。第一次出现从长罩尖端收回机身的双侧边线，罩内是暗色舱冠；第二次罩口更宽，罩尾接上了整块上盖。两张均可辨四副双叶与长渐缩臂根，未见完整朝上的圆镜片。它们的开口都有些像座舱，罩体是否过深仍需作者判断。与 C 的外置支座相比，B 的重点落在纵向导流罩如何收回机身。此处的光学部件仅作外观设定。

**建议作者比较的三个节点。** [A / mount](mount/A-ray/original.png) 的宽圆肩与浅凹鼻口、[B / 局部修订一](B-local/B-edit-1/original.png) 的长罩与渐缩臂根、[C / mount](mount/C-ray/original.png) 的可见承座与分件相机舱。B 经父图修订，A/C 为生成候选，这组三图只供讨论；全部 20 张均留档。作者尚未选择或锁稿。

对 pod 三张在 400 px 等比预览上点估四轴和八个叶尖。W/L 约 A 1.011、B 1.000、C 0.994；d/D 约 0.539、0.457、0.494；各图最大单副叶长相对差约 8.8%、5.9%、4.7%。像素估读误差数像素，属于知条件初读。原坐标在各自 `exploratory-reading.json`。这些数只对应 pod 三张，其余批次未据此打分。画幅占比与中心偏移不用于筛除图。
