## 文件与复核方法

- [新增参数 CSV](a1-model-specs-extension.csv) 前 19 列沿用原表列名，后续列保存拓扑、尺寸原文、统一单位、部分尺寸、测量状态和哈希。CSV 使用带 BOM 的 UTF-8 编码。
- [逐机复核摘要](verification-summary.md)列出八款各状态的读数、页码和计入条件。PDF 页序自 1 起算，另有印刷页码时分别登记。
- [来源清单](sources.csv)用完整 URL 连接参数表的主来源和补充来源。本机可离线核验 10 份[厂商资料来源](sources.csv)，含 5 份 PDF、3 个规格网页和 2 张产品图。网页哈希对应当次保存的 HTML 字节。网页中的外链图已在用于判定拓扑时另行归档。Nile-JZ 的手册能从官网 URL 的索引正文核到具体字段，本机直连未取回完整 PDF，清单保留该缺口。
- 用 PowerShell 在本目录执行下列命令可核对每个本地来源。最后一列应全部为 True。

```powershell
Import-Csv .\sources.csv | Where-Object 本地文件 | ForEach-Object {
    $actualHash = (Get-FileHash -LiteralPath $_.本地文件 -Algorithm SHA256).Hash
    [pscustomobject]@{ 文件 = $_.本地文件; 一致 = ($actualHash -eq $_.SHA256) }
}
```

## 尺寸和重量的取值

完整三维共 10 行，部分维度共 6 行。Hylio、Joyance 两款及 DJI 共 4 款具有完整的两态三维。只有 Hylio 的两态都明确排除桨叶。其余三款之中，Joyance 两款的表格均未交代是否计桨，DJI 两态的含桨口径不同。Garuda 和 Nileworks 各有完整展开尺寸，折叠只确定平面两向。TTA 两款只有机架的局部尺寸，两态均缺至少一向。植保六旋虽已覆盖 10 个型号，按具体状态和桨叶口径筛选后可用数会下降。

“外包络尺寸”只填完整的三维标称值。同一行的“官方长/宽/高”只填可以指认方向的值。Hylio 的英寸规格没有写轴序，三维原序和换算值均保留，定向列留空。Joyance 原序为宽、长、高。Nileworks 把宽、长和液剂箱配置高度分项列出。缺值使用空单元格。“普通或对角轴距”保留手册用词，只有原文明确支持才进入旧表的“最大对角轴距”列。机身主体长宽也未由外包络代填。

重量列保留限定符。对于上限、净重、不含电池整机质量、标准起飞质量，应按“重量口径”筛选。另有参考重量时保存在“其他官方重量”。单位换算采用 1 in = 25.4 mm、1 lb = 453.59237 g、1 kg = 1000 g。Hylio 整机重量换算至整数克。换算位数不代表测量精度。

所有记录都是厂商标称。Garuda 折叠平面尺寸来自图内已有尺寸标注，Joyance 的产品图只用于辨认六臂各一桨。实测外包络、重量、轴距和桨径均留空，状态为“未测”。

## 去重与候选取舍

以厂商和型号为单位，按大小写、空格和连接符归一化后对照原表，再人工核对同系列名称。Joyance 两款分别有 20 L 与 30 L 的独立规格页、不同整机尺寸、重量和各自的产品图。TTA 两款分别有独立手册，对角轴距为 1290 和 1700 mm。同一产品的国家站、语言、手册版本和配置均不另计。此次未增加 Mavic 地区变体。

另外两组官方资料虽能给出尺寸，但不足以进入本次整机样本。

- Frogs Sekar Agri SA16L、SA20L、SA30L 分规格列为 Hexacopter 并列 6 套动力系统。该页提供系列主图，本轮没有逐个容量确认六根分立机臂的布置。SA16L 的 X8 出现在电机型号栏。SA10L 所列 Quadcopter 与旋翼数 6 互有冲突。[Frogs 分型号规格](https://www.frogs.id/en/products/sekar-agri/)
- Hongfei HF F30 的页面售卖机架套件。表中把 2153 mm 同时列作“臂桨展开”第一维和最大对角轴距，随页图又用 Ø2153 表示电机位置所在圆。整机配置及桨尖外廓无法一致复核，留在候选记录中。[Hongfei 规格与三视图](https://www.hongfeidrone.com/6-rotor-hexacopter-drone-airframe-kit-with-carbon-fiber-frame-product/)
