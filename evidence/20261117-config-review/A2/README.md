### 叶尖判读与复算

1. 先看原裁图，为每个已确认归属的叶尖指定局部窗口中心（`window_centers`）。以该点为中心向四边各取 18 px，超出裁图的部分截断。按 Pillow 灰度 L ≤ 96 筛出深色轮廓像素，选其中距该轴心最远的像素为叶尖。距离相同时按行从上到下、行内从左到右取首点。原始取点窗口和所得 A、B（`tips`）均按同一顺序入表；重渲染校验时重新执行选点。该规则取叶尖深色外缘，其余部位仍沿用原来的线中心读数。
2. 每轴计算 AB、HA、HB、HA + HB、H 到 AB 中点的距离、H 到直线 AB 的垂距及 ∠AHB。垂距等于向量 HA 与 HB 的叉积绝对值除以 AB。各量从原点计算，保留折叠桨的实际图面姿态。数字接近 180° 可检查配对方向，半径和与两尖距的差反映两种取径口径在该图上的差异。
3. `prop_d_mean_px` 是该机所有桨的 AB 均值。`d_over_D_mean` 是主读数，用 d 除以对置轴距均值。`d_over_D_max` 用同一 d 除以对置轴距最大值。逐轴点位、两条或三条对置轴距均可追溯，计算采用舍入前的值。

## 读点与计算

1. 用 Poppler `pdftoppm 26.07.0` 按 576 dpi 等比例渲染指定 PDF 页为 RGB PPM，1 PDF pt 对应 8 px。按点表记录的整页像素框裁切，左、上含边，右、下不含边。保留原页朝向。裁框左上像素为 (0,0)，x 向右，y 向下。整页点 = 裁框内点 + 裁框左上角。页号从 1 开始。
2. 在网格叠图及局部放大图上逐点读整数像素，以线条中心作边界。机身记录四个支撑点（前、后、左、右），足以复算图面长宽；数据没有稠密轮廓或面积。四旋的 FL、FR、RL、RR 是机体自身的左前、右前、左后、右后，T30 保留原图 M1–M6 编号。
3. 令机头方向为单位向量 f=(fx,fy)，机体右向为 r=(−fy,fx)。每个轴心 p 的横向、前向坐标分别为 p·r、p·f。W 为全部轴心横坐标极差，L 为前向坐标极差，W/L 为二者之比。四旋机头均向页上，T30 向页左。梯形布局的 W 取极差，前、后排未作平均。
4. 对角距采用二维欧氏距离。四旋 D 取 FL–RR 与 FR–RL 两条距离的算术平均；六旋附例另算三对对置电机。CSV 同时列每一条距离、均值与最大值。PV02 的分母使用四旋的均值 D。
5. 机身长 Bₗ = (前点 − 尾点)·f，机身宽 Bｗ = (右点 − 左点)·r。**PV01 = Bₗ / Bｗ，PV02 = Bｗ / D。** 两端可处在不同横截面。轮廓取图上可辨的主体，排除机臂、桨、护圈及外置相机。缺少必要点时，涉及该点的结果留空，JSON 用 `null`。
6. 同一裁图内的距离取比；全程未换算毫米，未用厂商外包络填入主体尺寸。CSV 的六位小数便于逐行核算。图示是否工程等比例、线宽带来的点位误差及判读者间差异均未定量验证。
