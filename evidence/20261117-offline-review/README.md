## N2 · 作者招募、独立填写

收集目标为三份来自不同评者的有效独立答卷。第一批三人，若有人提前看过标记图、条件或他人结论，单列其答卷，可补招，累计最多联系五人。各人独自读完相同的 12 张，在看到答案前确定这个安排。样本量用于小范围核对，不估计一般人群的识别率。正式 v1.2 基准、外露承座和多块顶盖各四张。每图先分别读左上、右上、右下、左下四处臂根，再读顶盖。三个以上臂根同类时按该类计；不足三个单列混合或不可判。沿用每人逐档命中至少 3/4 且基准误判至多 1/4 的口径，并列报告各评者分子、分母，保留分歧和看不清。不同任务的 3 份配对评图和 3 份逐图评议单独报告。

发给评者的文件只有离线 HTML；每位评者的顺序在本机随机化，允许回看、续填、放大和导出 JSON。保留原 RGB，无损 WebP 已与原 PNG 解码像素逐张比较；仅去除元数据。研究者对应键本地保管，收件前不发布。请勿向评者转发此研究者说明。
