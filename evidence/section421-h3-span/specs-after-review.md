# 4.2.1　三张方向规格卡 · 复核后工作版（待作者签署）

本节记录同一随行航拍四旋翼任务的三个造型意图与各自的顶视读法。作者保留 B 的曲面过渡，认为新版 C 不如旧版；具体原因由作者保留。Claude 逐图复核时知道条件，观察来自五张原图的拼图。这次没有增加独立评者。[Claude 逐图记录](https://github.com/Freeloop993/paper/issues/36#issuecomment-6858488056) · [两组开发原图和实发规格](README.md)

| 字段 | A　独立圆舱、短肩 | B　连续曲肩、向臂外延 | C　切角壳、可辨承座 |
| --- | --- | --- | --- |
| 任务与观察位置 | 日常随行航拍，正交顶视、机头向上 | 同 A | 同 A |
| 设计者要表达的部件关系 | 中央舱在平面上保持独立，机臂靠近舱边时经短肩收窄 | 沿机身侧面能顺着同一条曲面追到自由臂段，保持作者认可的连续性 | 云台由鼻部两侧耳座夹持，臂插入可读的承座，顶盖有分段 |
| 相机判读 | 鼻端可见部分仍在壳前缘以内 | 同 A；不能凭露出的一小片深色区区分 A/B | 观察前伸模组和两侧支撑与同一机鼻壳的连接；缺证据记不可判 |
| 臂根判读 | 看壳侧边缘在哪里收向臂中段 | 看平滑肩面沿臂延伸到哪里。终点只估得范围时保留待判 | 看实体搭接的台阶、唇边或槽壁；深色带或横线本身不足以证实承座 |
| 开发图实收 | A250 为圆舱和短肩；壳体与肩部区分较清楚 | B300 整体拉开。B250 肩面向外铺开，但蓝线穿过臂根；短肩与长渐缩的独立响应待判 | 旧 C：承座、夹持关系、盖板分段、四副双叶可见。新 C：前端显外挂、盖缝淡、四副三叶 |
| 保持项与开放项 | 三方向均保持 True X、每轴双叶、无护圈、前向相机、正顶视；5.2.1 统一同色，E3 设计可选臂材质。桨叶外形、曲率、接缝走向与电机座可由设计者探索 | 250/300 的开发对照用于提出轴距候选。正式规格是否放开 250 mm 保持项，须更新并签署 [PR #68](https://github.com/Freeloop993/paper/pull/68) 后决定 | 保留旧 C 的形态关系；作者已允许 E3 可选外露碳纹。5.2.1 仍用同色，只比较形状。机身长宽比与臂宽不写成可复现的造型命中 |
| 依据与证据性质 | 设计者判断与配置器部件档位。紧凑意向不能当作评者已辨认 | 作者反馈、Claude 知条件对照。舒展意向待独立感知评议 | 作者对两版整体的判断；耳座、分段与材质取舍为 Claude 复核建议，尚待作者确认 |

短肩和长渐缩在开发记录中保留描述；正式响应字典统一归入“无缝”。轴距只是紧凑程度的候选几何代理。臂材质采用 v1.3 两档，适用范围见[作者在 #3 的决定](https://github.com/Freeloop993/paper/issues/3#issuecomment-6858641894)及[路线图 PR #69](https://github.com/Freeloop993/paper/pull/69)。

镜头水平朝前属于任务规格。顶视只记录机头位置、是否越出壳边、是否确见错误镜面，遮挡时记录不可判。四轴点线图表达布局，不指定壳和桨叶轮廓。开发样图与规格演变可在 4.1.3 追溯；4.2.1 保存方向定义与取舍理由。4.2.2—4.4 等 E3 正式候选、作者取舍、版本修订与锁稿。几何响应的数值与独立读数进入 5.2，语义是否被人感知归到 5.3。

**复核后的下一步**：3.4.2 的八张 H3 只测试机鼻可读性和壳长／轴距。几何差异即使达标，也不足以宣称紧凑与舒展已在人群中得到验证。未选择第 4 章父图。
