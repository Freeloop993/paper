# 更正版 E2 的轴心位移复核

两张父图、六张结果均为 1024 × 1024。逐张核对父图和结果图的 SHA-256，实际提交的节点图与各自冻结请求的 JSON 内容一致。图像顺序没有旋转、配准或缩放。

在原尺寸局部放大图上取每副桨中心帽或中心螺帽的中心。同位置欧氏位移除以父图两条对置轴距中较短的一条，表中仅列四轴最大值。人为取点可能产生数像素差异，零表示落在同一读数像素。作为敏感性检查，假设每个中心的二维定位误差不超过 3 px，对分子加 6 px、分母减 6 px；该假设不是实测的读者间误差。

| 结果图 | 归一最大位移 | 误差假设下上界 |
|---|---:|---:|
| E2R-C1-B-parent | 0.0000 | 0.0087 |
| E2R-B2-A-parent | 0.0000 | 0.0087 |
| E2R-B2-A-layout | 0.0201 | 0.0290 |
| E2R-B2-B-parent | 0.0000 | 0.0087 |
| E2R-C1-B-layout | 0.0316 | 0.0406 |
| E2R-C1-A-parent | 0.0000 | 0.0087 |

读数者已知条件。四张父图编辑在这一单项均低于登记界值 0.05。两张点线图只作描述性对照。盲读者 R、T 在六组均逐轴记录双叶；单独的真人答卷未收集轴心坐标。轴位保持与设计修改达成都应逐项报告。

逐轴坐标与两条轴距见 readback.json，中心标记见 hub-overlay.png。
