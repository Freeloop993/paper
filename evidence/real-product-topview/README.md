# T05 真实产品顶视照片来源

[来源登记](sources.json)列出已核验的不同型号、摄影者、作品页、许可和原图摘要。当前四张均为展开状态的消费级航拍四旋实拍，姿态依成片判断。可观察电机顶面、两侧臂根及机鼻相机模块，拍摄角度未标定。Parrot ANAFI 可见镜片，Mavic 3 Pro、Neo 和 Neo 2 可辨相机模块外壳。后两款带护圈，记录形态属性时保留这一差异。

目标为 8–10 个不同型号。四张为已收原件，统一 60% 占幅、白底、去字标的评议刺激图仍待制作；正式评分人数 0。两张图库近顶视候选型号待辨或与已收样本可能重复，另行筛选。厂商与新闻照片中，GoPro Karma 的图片尚缺实拍与改作许可证据；一张 Skydio 2 的前后电机间距透视明显；一张 Mini 3 的相机与高反光罩难以区分。这三张未纳入。

衍生图须对应原件逐一记录裁切、缩放、去品牌操作、作者与许可。Parrot 图的适用范围为非商业用途，改作传播须遵循其署名与相同方式共享条款。仓库保存来源与摘要，评议者另收匿名刺激图。
