## 二、发什么、怎么收

**发哪两个文件。** 在本目录运行 `python3 build_pages.py`，`dist/` 里会生成两个文件，各约 19.6 MB：

- `四旋翼取点-H1.html` 发给第一个人
- `四旋翼取点-H2.html` 发给第二个人

一人一个，不要两个都发给同一个人，也不要让两人互相看。两个文件里是同样的 24 张图，编号和顺序不同。文件比较大，建议用微信或 QQ 的文件传送，邮件附件可能超限。**不要把本库的地址给对方**：对应键和已有的读数都在库里。

**可以直接转发的话：**

> 想请你帮忙做一件量位置的小事，大约 30 到 40 分钟。附件是一个网页文件，用电脑上的浏览器（Chrome 或 Edge）打开就行，不用联网、不用装东西。里面有 24 张无人机的顶视图，按提示在图上点出电机中心和机壳的几个边缘。中途可以关掉，下次用同一个浏览器打开会接着做。请一个人独立完成。点完以后页面会让你下载一个结果文件，把它发回给我就可以了。

**找什么人。** 没有见过这些图的生成设置和已有读数的人；有没有设计背景都可以，页面会记下来。S5 里做第二位判读者的那位可以再请，只要没看过这批图的读数。

**回件。** 对方发回 `quad-points-H1-….json`（或 H2）。下载不了的话，对方可以把页面上那段 `A8C1:` 开头的文字粘贴发回，存成一个 `.txt` 文件，效果一样。

## 三、回件到了以后

```sh
python3 to_csv.py <回件.json 或 .txt> <私有目录>     # 写出 <私有目录>/H1/response.csv 和 reader.json
```

转出的表与发放包里的空表列名、图号顺序、编码完全一样。三份表（AI、H1、H2）和 `PRIVATE-key.csv` 放在同一个私有目录下，再运行已有的评分：

```sh
python3 -B ../a3/calibrate.py score <私有目录>
```

评分程序不许把结果写在本库的公开目录里，私有目录要放在库外。`reader.json` 里是作答者自报、起止时间、每张用时和留空的点数，供判读者档案表用。

`to_csv.py` 会拒收三种情况：回件不是出自登记的页面；有图没点完；留空的点没写原因。

## 四、页面和原发放包的差别

没有改的：24 张图是包里 PNG 的原字节；顺序是包里 `response.csv` 的顺序；取点规则是包里 `instructions.txt` 的规则，换成了白话。

页面替作答者做的：

- **坐标自己出。** 点哪里就记哪里，原图整数像素，不用读数、不用打字。右边有 5 倍放大镜，方向键可以一像素一像素地挪。
- **横线自己画。** 规则要求左右缘取“四轴 y 均值四舍五入所在的水平线”与机壳的交点。四个电机点完，页面画出这条线，并把左右缘的点吸到线上。
- **规则里的硬约束当场拦住。** 左上右上点反、下端点到上端上面、右缘点到左缘左边，页面会提示，不改不能进下一张。这三种情况原评分程序会整表拒收。
- **定不了要写原因。** 规则要求留空的点说明原因，页面不写不让留空。电机不全时，规则要求左右缘留空，页面自动留空并写上原因。
- **示意图只点四个点。** 4 张黑底的点线示意图只有四个红点，页面只问这四个。哪 4 张是示意图，是制作时从对应键里查的；页面里只有“这张是示意图”这一个标记，没有原图文件名和生成条件。

**一处限度。** 屏幕够大时（窗口宽 1440、高 1070 以上）画布按原图 1:1 显示，点哪个像素就是哪个像素。笔记本屏幕上画布缩小显示，单次点击可能偏 1 个像素，要靠放大镜和方向键对准。S5 里用同一种页面的第二位判读者，电机中心与我相差的中位数是 2.7 个像素。

## 五、软件走查

```sh
python3 build_pages.py        # 重做两个页面，并核对 packs.json 里登记的摘要
node qa.mjs <输出目录>         # 46 项
```

走查用 `a3/points.csv` 和 `guide-pixels.csv` 里已有的坐标当已知答案，在 H1 页面上把 24 张点了一遍：导出的坐标与点下去的一致；吸附、拦截、留空、方向键、撤销、刷新后续做都按上面说的工作；页面没有发出网络请求；导出的文件和粘贴的文字转出同一张表；这张表连同模拟的 AI、H2 两张表被 `calibrate.py score` 接受，三组对照都算了出来。走查产生的数只用于检查软件，不是判读数据。

页面只用标准库生成，重做出来逐字节相同。[packs.json](packs.json) 登记了两个页面和两个源发放包的 SHA-256；`dist/` 不进库。模板改过以后用 `python3 build_pages.py --register` 重新登记，已经发出去的版本不要再改。
