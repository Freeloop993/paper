## 图面口径与机身读数

1. 保留原图显示方向。原点在左上，x 向右、y 向下，点序 TL、TR、BR、BL。对这批机头向上或向下的顶视图，反向不改变跨度。两侧均值公式为 `[(xTR−xTL)+(xBR−xBL)] / [(yBL−yTL)+(yBR−yTR)]`。对角轴距 D 为 TL–BR 与 TR–BL 两条欧氏距离的均值。
2. E3／B2 的新轴点由知条件 Codex 会话在等比网格图上估点，折回 1024 原图，在局部窗口以灰度环的近似对称性定位候选，再查看 80 × 80 原像素叠点，按可见桨夹中心帽或中心螺钉修正。桨叶遮挡、帽形细节、轴帽与下层座圈不同心使像素级重复性仍待盲测。WLQ 的正式复算沿用存档轴点，本次核图没有增加一个读者分母。
3. 机壳取中央固定壳体的上、下缘投影，排除外挂机舱与阴影。以靠近四轴平均 x 的纵截线生成候选，Pillow 灰度 L < 222，用原图局部放大复核；第一、三轮 C 方向在壳体与相机舱交界处人工定界。第二轮 C1、C2、C3 的前舱及尾端嵌件归属不清，壳长及依赖它的比值留空。B2 朝下的外挂相机在壳长之外。
4. 为避开四臂的连体根部，本轮选用**四轴平均 y 处的固定截面宽**。取最接近的整数行，在该行量包含中央壳体中线的连续灰度 L < 222 区间，保存左右端点并查看叠图。表中 `pv01_section` 为壳长／截面宽，`pv02_section` 为截面宽／D。A2 的手册点表按各图可追踪侧线取支撑点，两种宽度与全壳最大宽的对应关系仍待同图双标。若研究问题要求最大壳宽，应重新标注侧线。
5. E3 三轮的 `pv01_section` 中位分别为 **2.500（9/9）、2.856（6/9）、2.906（9/9）**，`pv02_section` 为 **0.232、0.246、0.242**（各 9/9）。B2 低调版壳长 420 px，截面宽 169 px，两个比值为 2.485 和 0.242。各项单列可测分母，未测不填零。

## A8 校准已有多少证据

**历史盲读。** 11 月初有六张解析图、两套隔离 AI 视觉标注。已核对两份标注 SHA-256、六图字节与真值点。依历史点序重新配对，四轴逐点欧氏误差的均值分别为 **0.240、0.260 px**，归一到各图两对角距均值后为 **0.000454、0.000495**。六例的图面轴心 W/L 真值都为 1.00，两套点表按极差均读为 1.00。它们能检查清晰解析图上的定位，0.70、1.30 档与实渲染壳缘仍待覆盖。[历史真值与读点](prior-calibration.csv) · [逐例误差](prior-calibration-scores.csv)

**本轮条件图算法核对。** 在实际输入 PNG 的四象限各取纯红 RGB(255,0,0) 像素质心。每个红点保存像素数及 x、y 坐标和。三张 WLQ 条件图实得 W/L **0.700154、1.000000、1.299407**，E3 原点线图为 **1.000163**。这是实际栅格标记的参照值；观察者校准回件仍为空。条件图能校轴心与 W/L，机壳边界需要带壳体真值的材料或真人同图对照。[像素计数与坐标和](guide-pixels.csv) · [条件图复算](guide-check.csv)

**待执行的独立取点。** 已按同组 64 个研究案例制备私有空白包，H 版只作造型重复核查。独立 AI 包含全部 64 个案例；两名真人各量同样的 **20/64（31.25%）**，分别取主批 4、扩展 7、E3 三轮 3＋3＋2、B2 低调版 1。WLQ 在目标档内抽取，各层据图像摘要固定排序。每人另含同样的 4 张条件图，各包独立匿名编号、随机顺序，去除元数据并核对 RGB 像素。这个抽样方案用于本轮待收校准。

获授权的研究者从[私有阅读库](https://github.com/Freeloop993/paper-reading-room)查收正式材料。只向读者提供其专属包和包内 `instructions.txt`。记录模型与构建号（或真人读图工具版本）、日期、既往曝光、实际取点法与不可判原因。研究者在全部回件锁定后保存原表摘要、复核盲态再揭键；提前见过目标、键或旧点者单列。评分列出每位读者的条件图逐点误差、W/L 偏差，以及 20 张重叠图的 AI–H1、AI–H2、H1–H2 差异。缺一轴则该图 W/L 缺测，仍保留原分母。仅凭当前材料尚无法估计新读者误差或批准新的命中容差。

## 在本地复算

Python 3.9+ 的标准库即可从 CSV 校验全部发布指标。第一条命令只读，比对逐行结果；第二条在有意更新源点后重建派生 CSV。

```sh
python -B recompute.py
python -B recompute.py --write
```

私有制包另需 Pillow。第一个路径指向已有原始 PNG 的归档树，含三档 WLQ、三轮 E3、B2 低调版和四张条件图；版次通过 SHA-256 核对。第二个路径须为公开目录以外的新目录。两名真人及独立 AI 完成各自的 `response.csv` 后，在封存副本上执行评分。程序会拒绝无缺测说明的空白答卷。研究者对应键、原图、回件与评分明细均留在私有目录。

```sh
python -B calibrate.py prepare "/archive/originals" "/private/a8-packets"
python -B calibrate.py score "/private/a8-packets"
```

[复算脚本](recompute.py) · [匿名制包与校准评分脚本](calibrate.py)。软件验收使用独立临时目录的模拟坐标检查缺点、分母及三组配对；上述真人与 AI 回件计数只反映实际记录。
