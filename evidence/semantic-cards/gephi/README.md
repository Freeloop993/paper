# 作者早期的两张共现网络图

留作 3.2.1 的描述性插图。归档保留作者导出的 PNG 原字节。两个网络分别涉及消费评论和商品参数词。单独的高频词或一条连边无法说明用户偏好哪种造型。

| 原图 | 可核实的材料 | 语料与处理边界 |
|---|---|---|
| [评论网络](comments-network.png) | 原名 `Untitled.png`。“无人机、飞行、操作、稳定、拍摄、客服”等中心或邻近节点与“评论-行特征词--共词矩阵.xls”词表相符。矩阵有 137 个词。 | 项目保有“评论数据爬取”目录和分词文本。`comment.txt` 有 1300 行，其中 1280 行非空。用于生成此 PNG 的独立评论数、去重口径及各平台的实际占比无记录。 |
| [商品参数网络](product-parameters-network.png) | 原名 `Untitled2.png`。“避障、返航、电机、液晶、大号”均可在“参数信息-行特征词--共词矩阵.xls”中查回。矩阵有 188 个词。Gephi 工程另有同名“参数信息”工作区。 | 作者在 [#19](https://github.com/Freeloop993/paper/issues/19#issuecomment-6826226433) 确认语料来自商品详情页参数。用于该网络的商品数，以及标题、卖点或规格字段各自的贡献无记录。 |

**分词和共现。** 保存了分词结果及两套矩阵。原分词软件版本、词典、停用词、共现单位或滑窗长度、最终制图过滤阈值均无记录。配套的矩阵转边脚本只导出上三角且权重大于 0 的非自环边，可核实该脚本的筛选条件。原图与这一脚本的执行回执无记录。

**布局。** “无人机评论.gephi”存有两个工作区。工作区 1 的布局属性为空。工作区 2“参数信息”保存时选择 Fruchterman–Reingold，面积 10000、速度 1、重力 10；另存有 ForceAtlas2 属性。最终 PNG 导出时所用布局、迭代次数及当时的阈值无记录。上述数值只描述工程保存时的状态。
