# 评论语义证据卡与第二编码

[cards.csv](cards.csv) 为 36 卡、35 条来源的短引文与解释。E003 与 E004 同源，分别谈小包与口袋，应一起阅读。卡以既有方向有目的地抽取；卡数、来源数和人次是不同单位。

每条原引文均已在旧语境审读表中逐字匹配，全文 SHA-256 与原卡一致。公开来源键和记录号是稳定替代码，作者本地保留对照。表中的类别和极性是对短引文的工作编码，历史解释保留原卡措辞。多数记录未说明整机是否展开。收纳尺寸、使用感受与测量值在写作时分列。

## 给 Claude

按 [T05 入选规则](../../docs/protocols/semantic-to-E3-spec.md) 逐组核对不同来源、反例、可见部位与状态。E001 评价机身小巧，E003 的小包描述是收纳语境；不能把后者直接当作展开状态轮廓证据。E016 是把外挂件收入机身的愿望。E011–E015 中出现“简洁”的短引文未指明何处产生这种感受。词对与可见部位的联系须保留不确定性，最后由作者确认。

## 给第二位编码者的独立材料

40 个随机位置中，35 个采自入卡来源，5 个干扰项从 7,443 簇排除重合后按 [预先登记的种子](https://github.com/Freeloop993/paper/issues/29#issuecomment-6822747911) 抽取。两段同源短引文放在一行，中间的 […] 表示删节。两类均用原文短片段。完整原评、用户名和链接留在本地。答卷只含盲编号、短引文和空白栏，单独分发；本目录及映射不提供给编码者。

目前第二位真人提交数为 0。待回收后逐项报告一致、分歧、无法判断，由作者裁定并留存理由。

## 复算

[export.py](export.py) 读取原方向证据卡 JSON、语境审读 JSONL、去重语料 JSONL，导出公开卡表、独立盲表及私用对照键。参数名为 `--cards --contexts --clusters --delivery --key`。私用键须与编码者材料分目录保管。
