## 请优先核这几处

1. **相机装在哪一端、镜头朝哪一个方向？** L1 控制臂同时写了 “front up” 和 “distinct dark camera window”。先看 C 的四张及闭源四张，分记机头端、外露的是云台壳还是镜面、顶视是否有足够线索。接口收到 “front up” 可核实，二维图无法给出镜头光轴真值。
2. **哪些措辞使材料都像一种灰塑料？** L1 要求 “matte neutral gray shell” 和柔光。请用同种子的 P1/P2 看外壳、臂根、电机与桨叶是否出现可辨的粗糙度或高光差异，并记录相机有没有随之变好。两者同时改了正负提示词、安装描述与光照，差异只能归于整套简报。
3. **究竟是哪类控制让 X 线进入外壳、轴圈留在错误位置？** A/B 是同设置的条件图对照；D/E 是同种子、同浮雕图、同 CFG，仅控制终点从 1.0 换到 0.5（保存前缀随图号改变）。A/C 同时改 CFG 和窗口，不能据此单独归因。K 在同一种条件图、同档位和种子下可以比较强度、终点，其图上红圈供阅读，核验缺陷用无叠加原 PNG。
4. **能否据此选设计方案？** 请在图号后分别写轴位、双叶、相机姿态、臂根连接和材质表现。开发调参仅用于决定下一轮设置。两档与单种子不足以支持普遍设计规律；几何合格本身也不足以支持第四章的产品设计质量。
