## 一、shape 子目录：逐张判读（共 24 张）

每张图记录以下各项：

| 项目 | 选项与判据 |
|---|---|
| body 机身平面形 | 流线舱：外轮廓为连续曲线、圆润。方正机壳：直侧边、有切角或棱角。不可判。 |
| roots 臂根 | 按左前、右前、右后、左后四根分别记。无缝：机臂从壳体平滑长出，无接缝。承座：臂根处有独立的套座或凸缘，并有横向接缝。铰接：可见转轴、枢轴或铰链块。不可判。只有颜色变化不算接缝。 |
| nose 机鼻 | 无外突：机头端没有越出机身轮廓的相机舱或云台。前伸：有相机舱或云台越出机鼻轮廓。不可判。 |
| cover 顶盖 | 单盖：没有贯穿顶盖的分型线。多块：有贯穿顶盖、把顶盖分成两块以上的分型线；壳体外周的缝不计。不可判。 |
| camera 相机 | 顶视不可见：看不到相机。机头相符：相机在机头端，且没有镜面正对观察者。错位：相机或深色光学模组在机尾或机背，或镜面正对观察者（朝上）。不可判。 |
| blades 每轴叶数 | 按左前、右前、右后、左后各记一个整数；被遮挡记“不可判”。 |
| guard 护圈 | 有／无。 |
| residue 残留 | 图中是否有像引导标记的点、线、文字（有／无）。 |
| product 产品感 | 产品：像可制造的产品。示意：像示意图或拼贴。不可判。 |
| note 依据 | 简要写下判断所依据的部位，一两句即可。 |

## 二、edit 子目录：成对判读（共 6 对）

每对包含“参照”与“修改后”两张图，文件名前缀相同。请比较两张图，回答以下各项：

1. **changes：** 用文字描述“修改后”相对“参照”实际可见的变化及其部位。先写这一项，再看后面的题目。
2. **nose_narrowed：** 机鼻前缘是否明显收窄并更圆（是／否／不可判）。
3. **roots_broadened：** 四处臂根过渡是否明显加宽并更圆滑（是／否／不可判）。
4. **axes_kept：** 四个电机的相对位置是否与参照一致（是／否／不可判）。
5. **two_blades：** 每个电机是否都是双叶桨（是／否／不可判）。
6. **outline_kept：** 机鼻与臂根以外的机身轮廓、顶盖分件和机臂，是否与参照基本一致（是／否／不可判）。
7. **other：** 有无新增或消失的部件，写明是什么。
