# 给 Claude 的档位复核 · 第一轮

1. **可保留的变化句。** 方正机壳、带枢轴的折叠铰接、前伸云台均有 3/3 目标命中。前伸云台的三张中，一张相机朝向可见相符、两张朝向不可判。可确认的是可见外突及支撑。多块顶盖 2/3 达到本轮门槛，留作候选；一张不可判，基准单盖也有可读性问题。
2. **先处理基准。** S0 的机身形均为 pod，但臂根为 socket、socket、U，上盖全 U，相机类别也全 U。S2 承座 2/3 与 S0 自发出现承座的 2/3 相同。该档达到命中门槛，但缺乏有无承座的区分证据。优先只修“无缝”基准句，让壳到自由臂段的表面连续可见；检查“浅色壳、深色臂”的颜色边界是否被看成装配缝。下一版读码可要求真实缝隙／搭接边证据，须先登记，既有读数保留。
3. **相机和上盖分别处理。** inside 原词要求顶视仅见平滑的机鼻，与“必须辨出模组才判 inside”的读法冲突。优先请作者／Claude 裁定是否把顶视响应命名为“无可见外突／可见前伸”，把真实内嵌与镜头朝向另列为不能由顶视确认的结构属性。单盖若保留，下一轮只改为外周可追踪的一条闭合装配缝，让饰线、反光不充当面板边界。不要为了判读而在顶视硬画镜头正面。
4. **臂宽保留为待验证的图像变量。** 四臂相对宽均值 3.98%、5.32%、5.91%。10→15 的差超过档内离散；15→20 的差为 0.60 个百分点，小于较大档 SD 的 0.81 个百分点。输入目标相对宽分别为 4%、6%、8%，成图高档未达到输入比例。9 张中 5 张有制图残留，15 mm 三张全有。多数明确读到红点；其中 G-w15-2 还出现蓝叉。优先检验输入标记的显眼程度，可试低对比度点线，维持轴心、宽度比例和档位。图上残留不等于所有图都受蓝线干扰，去掉红点和改蓝线请分开验证。
5. **机身比例先解决量测。** 9 张里只有 G-r1.8-2 的壳宽可独立读取（长 311 px、宽 140 px，比值 2.22）。其余八张主要是肩部与壳体连成一面，长度可估、主壳净宽不可判。该轴无法检验三档排序。下一轮可先利用现图试定位一个可复现的宽度截面、独立复测；若使用固定中段截宽，须给新指标另命名并冻结，不能据它回填本轮最大宽。中央灰框保留为诊断输入，尚无转正式的依据。

本轮未执行下一轮变更。修句、改图层或修改可观察定义分别登记。12 档 × 3 的小样本用于定位可辨与不可辨的部分；在正式论文中应分别报告“目标有命中”“与基准能区分”“其他部件保持”和“整体门槛”。
