# 顶视产品图独立读图说明（单人次 AI 读数）
输入仅为无元数据、随机编号的 1024×1024 RGB 图。仅凭图中可见的像素判读。可使用放大、像素剖面、网格标尺或边缘辅助，在同一图上核实测点。不可见或边界无从分辨时填 null 或 U，并在 note 写原因。不要从其他图补读。局部化与阈值只帮助定位，不把亮暗变化直接当作接缝。
每图输出一行 JSON（readings.jsonl），字段如下。四项向量顺序永远是屏幕左上、右上、右下、左下。坐标原点左上，单位为原图像素。斜置图采用实际机身纵轴，严重透视到不可量时留空。
- id：图像文件名去扩展名。body_plan：pod（主要连续曲线）、box（直侧＋可见切角）、U。arm_root：seamless（壳臂连续无接缝）、socket（承座＋横缝）、hinge（铰接并有可见枢轴）、U。至少三根能判同档才给整图该档。折线或黑色装饰自身不足以判铰接。
- camera：inside（模组确可辨且边界在机鼻内）、projecting（可辨云台向前越过鼻壳且有侧支撑）、U。相机看不见时，camera=U。camera_v2：consistent（可见且与前向水平安装相容）、invisible（无可辨模块）、wrong（明确错位或整面光学镜头朝上）、U（看见疑似件但位置/朝向含混）。机头顶面深色片本身不足以判错；不得推定内部安装。
- cover：single（一条明确的盖缝勾出连续主盖）、multi（装配缝实际分出至少三块顶盖面板）、U。散热槽、反光、装饰线、相机边界均不计；若同时似合两档，只有明确分出三块才记 multi。
- shell_L, shell_B：主机壳沿纵轴的最大投影长、垂直纵轴的最大宽，排除相机、机臂、肩部凸耳、阴影；壳臂平滑一体时取可连续追踪的机身外边界，困难即 null。hubs：四个桨毂中心 [x,y]。widths：各臂从壳侧出口到毂心的可见自由段中点，沿臂中心线的垂线量两实体边之间距离；排除阴影和桨叶，遮挡不外推。以原始像素记录约测整数，可在 note 标记不确定。blades：逐毂真实可追踪桨叶数或 null；不从相邻毂推断。
- guard、residue 各为 yes/no/U。残留指独立的定位点、线条或灰色底框等制图标记被画进结果，产品的灰色外壳本身不算。quality：product（部件有可辨的体量、连接与材质，整体可读成实体产品）、middle、diagram（以平面块线表达）。note：简短的可见证据或不确定性。
已提交的盲读不得根据揭盲结果重标；这是单个 AI 的盲读，无真人或评者间一致性数据。
