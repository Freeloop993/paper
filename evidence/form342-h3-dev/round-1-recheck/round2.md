# 第二轮执行差异 · 现图复核版（未出图）

依据为 [Claude 在 #1 的裁定](https://github.com/Freeloop993/paper/issues/1#issuecomment-6855011376)，对应第一轮封存提交 2f34714。下述方法用于开发轮，未开始正式采集。

| 对象 | 第二轮处理 | 顶视可核的证据 |
|---|---|---|
| 壳与臂 CMF，全部条件 | 实发固定行替换为 `Matte light grey shell and arms in one continuous colour, dark grey motors, black propellers.` | 改变壳臂色界。只有生成后才知道同色能否改善无缝与承座的区分。 |
| S0 无缝、S2 承座、S3 铰接 | 三个臂根词句均沿用 v1.1。每根分开记录，三根及以上同档才赋整图类别。 | 无缝要看得到壳→肩→臂的连续表面。承座要有可辨承接结构和真实缝隙、台阶或搭接边。铰接还要有可见枢轴。仅有色界、被上盖遮挡时保留不可判。 |
| 机鼻外突，S0 与 S4 | 保留两句相机规格。顶视这一列改名为机鼻外突。另留原相机错位观察列，不能用新码取代。 | 完整轮廓可见又无模组或支架伸出→无可见外突；能辨出模组和支架伸出→前伸；有不明突出、遮挡或裁切→不可判。无外突满足顶视目标；隐藏组件的存在及安装、镜头轴线无法由此验证。 |
| 基准单盖 | 实发档位句替换为 `A plain top cover with no seams crossing it.` | 顶盖可读且没有跨顶面装配缝→单盖；至少两条真实缝分出三块及以上→多块；恰有一条跨面缝、疑似装饰或无法追踪→不可判。外周一圈不计。 |
| 方正、流线、铰接、前伸与多块 | 相应档位原句保留。单项变化与第二轮自己的 S0 比较。 | 首轮命中能支持候选档位的小样本响应。基准的共同两句已变，跨轮改善不能由此单独归因 CMF 或上盖文字。 |
| W 臂宽 | 10、25 mm 各三张；双端中心距与输入比例固定，线宽约 24、59.4 px；淘汰 15/20 mm 三档比较。 | 四个自由臂中段的宽度均值除以同图两对角毂距均值，报告均值、样本 SD 和制图残留。 |

| 机身长宽比 | 停止 G-r 三档生成，第二轮不画中央灰框；保留描述量。 | 既有最大净宽方法与新的 L/B50 分列。不得填补首轮原缺失值。 |

**第二轮 36 张的分母**。S0–S5 ×3=18；W 两档 ×3=6；L 四条件 ×3=12。每轮需单独一份冻结。质量/护圈等任何一列全同，按 Claude 要求在封存前提交人工确认并附逐图可见证据，若未取得则列待确认；不把自动导出的常量当有效逐图判定。

**计划中的门槛**。S0 的无缝、单盖、无外突各 ≥2/3，S0 误读成承座 ≤1/3；S1–S5 各目标 ≥2/3。另需整轮至少 30/36 同时满足四轴皆双叶、无实见相机错位、可读成实体产品。W 和 L 不决定开 GPU。W 两档均值差须超过两档中较大的样本 SD，标记残留 ≤1/6。L 要降低残留且不降低 S2、S4 命中率。金额、GPU 与正式批次仍按各自授权。

**冻结前需 Claude 确认的 L 组对照**。第一轮没有 W25，且跨轮更换了 CMF、单盖词与读法。建议预先登记第二轮同条件常规图 S0/S2/S4/W25（共 12 张）作为主比较，旧轮有对应项的 S0/S2/S4 只作旁证（首轮三组合计残留 1/9；S0 和 S4 各自已经是零）。比较两套参考图 12 张的总残留，另分别检验 S2 和 S4 命中，无同条件的 W25 不借用 W20。两套都零时按“减少”的原文无法证明更好。W25 原附句称 “blue bars”，L-W25 却为深灰线。建议两侧都把同一句中的 “blue bars” 改为 “bars”，或按原文两侧均保留并登记颜色矛盾。前者是第三处**条件说明**更改，不能擅自当作 Claude 已批准的两句字典变更。L 对比度同时改变两色，不单独归因某一色。
