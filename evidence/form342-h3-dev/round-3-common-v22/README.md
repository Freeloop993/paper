逐轴双叶 7/8。揭盲后对照原图可见，S0-1 每轴有三片黑叶；朝向中央机身的浅色构件是机臂。K-4 机尾的独立黑色模组露出两侧支点和中央开口，盲读者据此判为机尾错位。其他七张中，三张未见可辨相机，四张有线索但方向待判，本读者能确认安装朝向正确的为 0/8。八张均被这一名 AI 读作产品图；这项只记录呈现形式，不是作者对设计质量的认可。

按[第二轮的组合算法](../round-2/score.py)复算，逐轴双叶、没有实见相机错位、呈现为产品图同时成立的有 6/8。其中三张相机不可见、三张待判。此数只描述原图，不能当作相机正确率或正式试验的通过率。

第一次与本次的机鼻读数有一处分歧。S0-2 原读为前伸，新读者看到黑边与细框，判为待判。两次观察分别保留。原登记的 S0 两轮合计仍为 4 无外突、1 前伸、2 待判。原坐标算得两组壳长均值分别为 345.0 与 402.5 像素；壳长／对角毂距的均值分别为 0.5514 与 0.5228，未过 K 判据。表中 W/L 按[四轴横纵跨度算法](../../../experiments/r0-e0-e1/summarize_e1.py)计算，只作描述。
