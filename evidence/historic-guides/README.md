# 旧控制图与真实执行图
旧主实验 C1 有 3 档、每档 3 次。9 个请求图均与对应 prompt_id 的成功 history 图一致，3 张控制图的 SHA-256 与原运行包的 input-receipt.json 一致。图中画双叶桨形、轴心小圈和有宽度的臂段，中央用白色多边形遮掉臂段，机壳边界未描线。三个机壳目标因此仍影响臂段内端位置，原提示词亦列机壳比例。桨盘的外圆未画。请勿将这个结果解释为“闭合八边形轮廓使旧 C1 命中轴位”。

S1 的 2 个种子×L/F 共 4 个请求亦与各自成功 history 对应，frozen 与实际输入 PNG 字节相同。L 仅画四点，F 另画闭合切角机壳。两批都用相同 Qwen-Image 2.1 Fun Union BF16，权重 SHA-256 为 1f9dea8384ba167084f39f624908f1dbf2ea8a223bb4a8108a77dafa9b55bfe1。从输入经 1024² 等尺寸缩放、Canny 0.4/0.8 进入控制器，C1 强度 0.7、S1 强度 0.35、作用区间都是 0—1。原件和 13 个执行图的逐项字段保存在本目录。
